# Winning Post 10 2026 — 자동 방침 및 로테이션 운용 원칙
갱신: 2026-10-18

## 3관 사이 경주 충돌 및 통합형 처리 (2026-10-16 사용자 우선순위)
- **복수 3관 동시 도전 자체는 금지하지 않음.** 봄 고마 3관 + 가을 고마 3관처럼 서로 다른 3관 목표마의 경주 기회를 불필요하게 빼앗지 않고 일정·적성이 맞으면 **한 마리로 여러 3관을 함께 노리는 로테이션도 적극 검토**한다. 별개의 3관 루트가 충돌하여 다수 말에게 각각 3관을 도전시킬 기회가 줄어드는 경우에만 분리를 우선한다. 이 운영 선택을 모든 중복 3관 시도에 대한 일률적 금지로 해석하지 말 것.
- 3관 필수 관문은 바꿀 수 없으므로 관문끼리의 불가피한 중복은 예외 허용하되, 가능하면 다른 3관 노선과 전체 목표가 크게 겹치는 별도 노선의 신규 채택을 피한다.
- 3관 필수 경주가 아닌 보조 경주의 중복은 원칙적으로 제거한다. 다른 3관과 많이 겹치는 후보 노선은 억지로 통합하거나 무조건 확정하지 말고 **보류**한다.
- **TC-EU-FM 유럽 암말 마일 3관: 보류.** 영국·프랑스·아일랜드 암말 3관과 필수 경주 일부가 겹치므로 출주표는 참조용으로 보존하되 우선 사용 대상에서 제외. 보류는 삭제·폐기·최종 부결을 뜻하지 않는다.
- 현재 작성 9종(유럽 7 + 홍콩 2) 중 **사용자 확정·인게임 저장 8종, 유럽 암말 마일 TC-EU-FM 보류 1종** (2026-10-16).

## 주요 승리·세트 업적 우선 검토 (2026-10-16 추가)

- 현역마 로테이션을 정할 때 **최근 5전 + 현재 능력/적성 + 화면의 `主な勝鞍`(주요 승리)**를 함께 확인한다.
- `主な勝鞍`에 특정 3관·세트 업적이 이미 표시되어 있으면 같은 업적을 다시 따는 것을 최우선 목표로 반복하지 않는다.
- 반대로 해당 업적이 없고, **연령·성별·출주 자격·거리 적성상 도전 가능하면 미획득 3관/세트 업적을 우선 목표 후보로 올린다.**
- 3세 한정 클래식/암말/더트/각국 3관은 해당 연령에서만 검토하고, 고마 대상 3관·시리즈는 4세 이상 현역 강마도 계속 검토한다.
- 3관 외에도 게임이 `主な勝鞍`에 별도 세트 승리로 기록하는 **춘추 제패류·시리즈 제패류 등**이 있을 수 있으므로, 화면에 확인되는 미획득 특수 성적은 일반 GⅠ 분산 출주보다 우선 검토한다.
- 예: 사용자가 언급한 `春秋マイル制覇` 같은 특수 성적. **이 예시를 전체 목록으로 간주하지 않는다.** 실제 적용은 게임 화면/확인된 자료에 존재하는 업적만 대상으로 한다.
- 단, 미획득 업적이 있다고 해서 무조건 도전시키지 않는다. 최근 5전이 현저히 부진하거나 쇠퇴가 명확하면 기존 자동 전환 기준을 우선한다.
- 추천 순서: **미획득 3관·세트 업적 가능성 → 기본 56종 중 해당 목표를 지원하는 프리셋 → 사용자 제작 3관/R2 로테이션 → 개별 수동 → 자동 방침**.
- 같은 말이 여러 미획득 업적을 동시에 노릴 수 있으면, 일정 충돌·거리 적성·다른 소유마와의 경합을 비교해 한 해 목표를 정한다.

## 소유마 간 경주 중복 최신 원칙 — 2026-10-18

- **무패 기록 보호가 걸린 말이 아니면 소유마끼리 같은 경주에 출전해도 중복 회피를 우선하지 않는다.**
- 소유마 간 매치업 자체를 가치 있는 경쟁으로 보며, 양쪽 모두 무패가 아니라면 원칙적으로 그대로 출전시킨다.
- **무패 유지 목표마는 예외적으로 보호**한다. 해당 말의 무패 기록을 편하게 이어가기 위해 같은 소유마 경쟁자를 다른 경주로 돌리거나 취소할 수 있다.
- 현재 대표 예외: **심볼리 루돌프**. 무패 유지가 최우선이라 같은 소유마 경쟁자는 가능하면 제거한다.
- 따라서 아래의 과거 ‘소유마끼리 불필요한 경쟁 회피’ 원칙은 **무패 보호가 없는 일반 말에는 강제 적용하지 않는다.** 기본 로테이션/3관 분산은 일정·업적 최적화용으로 참고하되, 같은 GⅠ에 소유마가 겹친다는 이유만으로 자동 분리하지 않는다.

## 현역마 전체 배정 최적화 원칙 (2026-10-16 추가)

- 말별 로테이션은 **개별 최적화가 아니라 소유 현역마 전체 배정 문제**로 판단한다.
- 이미 다른 소유마에게 배정한 기본 로테이션·3관 목표·특수 세트 목표를 반드시 확인한 뒤 다음 말을 배정한다.
- 같은 기본 로테이션이나 같은 핵심 GⅠ 세트를 여러 말에게 중복 배정하는 것은 **명확한 이유가 있을 때만 허용**한다.
- 강마가 여러 마리라면 서로 다른 3관·춘추 제패·시리즈·기본 프리셋·R2 로테이션으로 분산하여 **소유마끼리 불필요하게 경쟁하지 않게 하고, 기본 프리셋 미사용 경주도 넓게 소화**한다.
- R2 9종을 만든 목적은 단순 보존이 아니라 **기본 56종으로 커버되지 않는 GⅡ 이상 경주를 실제 현역마에게 배정하기 위함**이다. 적성이 맞는 말이 있으면 기본 프리셋과 반드시 비교한다.
- 추천 절차: **이미 배정된 말/목표 확인 → 미획득 주요 승리·세트 목표 확인 → 기본 56종 전수 대조 → R2 9종 전수 대조 → 필요 시 개별 수동 → 자동**.
- 동일 로테이션 중복보다 다른 적합 루트가 조금 낮은 등급이더라도, 시리즈 제패·경주 분산·적성·현재 전력을 종합해 더 가치가 있으면 분산안을 우선할 수 있다.

## 수동 로테이션 우선순위
1. 3관 후보 최우선. 모든 종류의 3관을 대상으로 우선 배치.
2. GⅠ 우승 경력이 많은 고마에 기본 제공 로테이션을 우선 배치.
3. 모든 지역(일본/유럽/미국)의 **기본 제공 로테이션에 없는 GⅡ 이상 경주 활용을 우선 목표**로 커스텀 로테이션 제작 후 배정. **GⅢ 출주는 금지 대상이 아니며**, 적성·일정 연결·실용성과 출주 수 확보에 도움이 되면 보조 경주로 자유롭게 편입한다. ‘미사용 GⅡ+ 우선’과 ‘GⅢ를 절대 포함하지 않는다’는 서로 다른 기준이다.
4. 나머지는 자동 방침.

주의: 3순위에서는 '기본 로테에 있지만 올해 해당 프리셋을 배정받은 말이 없어 실제로 비는 경주'는 **절대 계산하지 않음**. 이를 계산하면 매년 수동 관리가 늘어나기 때문. 전체 기본 로테 수집이 완료될 때까지 미사용 여부는 미확정.

## 외부 작성 로테이션 검토 기준 및 사용자 목표 (2026-10-16 수정)
- 사용자가 제공한 [일본 고마](https://note.com/akatsuki0720/n/n0604ab4b02a1), [미국 고마](https://note.com/akatsuki0720/n/n333fc9080804), [유럽 기타](https://note.com/akatsuki0720/n/ne558b7228fc9) WP10 2026 공략의 작성 로테이션을 검토할 때, **GⅢ가 포함됐다는 이유만으로 탈락 처리하지 않음**. 빈 중상 소화와 전체 일정 완성도가 우선.
- **외부 공략 작성자의 실제 로테이션에 적힌 방목 주수는 일단 존중**. 사용자의 한 실패 사례를 근거로 다른 작성자의 모든 1주 방목을 임의 변경하거나 출주 불가라고 단정하지 않는다. 해당 일정의 실게임 검증 유무는 불명확할 수 있으므로 '작성자 경험상 운영안'과 '우리 세이브에서 검증됨'은 구별. 사용자 인게임 경고가 나타나면 그 구간만 재검토.
- **봄 고마 3관 + 가을 고마 3관을 한 마리로 노리는 고마 왕도형**은 가치 있는 운영 선택지. 3관 전체 노선 간 경주 경합과 다른 말의 독립적 기회가 실질적으로 발생하는지, 실제 출주 조건을 보고 판단.
- 사용자는 1983년 **심볼리 루돌프로 무패 9관을 목표**로 함. 이 목표를 일반 마필의 획일적 연간 일정에 끼워 맞추지 말고 필요시 전용 로테이션을 별도 구상. 구체적 9개 대상 경주와 완주 가능 여부는 목표 자체와 구분하여 확인.
- 이번 수정은 **기존 승인·인게임 저장된 8개 3관 로테이션이나 보류 중인 TC-EU-FM 일정표를 임의 변경하지 않는다**.

## 수동 관리 종료 / 자동 방침 전환
- 3관 도전에 실패하면 해당 3관 수동 로테이션을 즉시 폐기하고 자동으로 전환.
- 3순위 커스텀 로테이션 적용마는 **3경기 연속 6착 이하(전광판 밖)**일 경우 즉시 자동으로 전환. 5착 이내가 끼면 연속 횟수는 초기화.
- GⅠ 다승마 역시 3경기 연속 전광판 밖이면 쇠퇴로 취급하여 자동으로 전환. 일시적 부진 여부를 일일이 심사하지 않는다.
- 자동 전환한 말은 해당 연도에는 원칙적으로 수동 로테이션으로 되돌리지 않고 다음 연도에만 재평가.
- 수십 마리를 운용하므로 개별 수동 관리 가치에 대한 별도 정성 평가를 반복하지 않음.

### 자동 전환 배정

- GⅠ 다승마도 부진 기준 충족 시 마장/급에 따라 자동으로 전환.

## 판단 오류 방지: 근거 없는 가정 확산 차단
- 사용자가 게임에서 운용할 수 있다고 제시하고 확정한 설정은 구체적 반증이 없는 한 작업의 전제로 수용.
- 작업에 제공된 전제와 충돌하는 반례나 불가능성 가정은 **왜 의심할 이유가 있는지 먼저 검토**. 단지 상상 가능하다는 이유만으로 신규 문제나 확인 과제를 만들지 않음.
- 사용자 결정 / 인게임 확인 사실 / 외부 자료 / 모델 추론을 혼동하지 않음. 사용자의 설정 확정은 기록하되 모델이 직접 화면을 확인했다고 바꾸어 쓰지 않음.
- 실제 적용 중 구체적 오류가 발생하면 그때 원인을 확인. 가정만으로 확정된 작업을 미완료로 처리하지 않음.

## 3세 연말 정리 규칙
- **3세 시즌 동안 OP급 이상 경주에서 단 한 번도 1착하지 못한 말은 원칙적으로 연말 정리 확정.**
- 신마전·미승리전·1승クラス·2승クラス·3승クラス 승리는 이 생존 기준의 '유효 1승'으로 계산하지 않는다.
- **유효 1승:** 오픈전(OP/L) 또는 중상(GⅢ 이상) 우승.
- **예외 — 사온 말 1회 세이브:** 자가생산마가 아닌 구매마는 3세 연말에 위 정리 기준에 걸리더라도 **단 한 번만 세이브하여 4세 시즌까지 보유 가능**하다.
- 이 예외는 구매마의 늦은 각성·해외 적응 등 3세 성적만으로 판단하기 어려운 경우를 위한 유예이며, 자가생산마에는 적용하지 않는다.

## 신생마 보유·클럽·판매 규칙
- 앞으로 태어나는 자가생산마는 평가 순위로 강하게 선별한다.
- **직접 보유:** 사온 말 + 자가생산 평가 **`엄청난 거물`**.
- **클럽행:** 자가생산 평가 **`거물`**.
- **판매:** 그 외 자가생산마 전부.
- 평가 문구는 **`엄청난 거물` / `거물`**을 기준으로 적용한다.


## 신생마/자가생산마 선별 규칙 — 1983 연말 개정
- **초대형 거물(超大物)**: 평가자 표식과 무관하게 **직접 소유**.
- **거물(大物)**:
  - 河童木(캇파키)와 美香(미카)가 **둘 다 ◎(쌍마루)** → **직접 소유**.
  - 둘 중 하나라도 ◎가 아니면 → **클럽행**.
- **꽤나 좋은 느낌(けっこういい雰囲気)**:
  - 河童木(캇파키)와 美香(미카)가 **둘 다 ◎(쌍마루)** → **클럽행**.
  - 그 외는 원칙적으로 매각.
- 그보다 낮은 코멘트는 원칙적으로 매각.
- 1982년생 사마렉스쨩82는 화면상 河童木=◎, 美香=◎이므로 **거물+쌍마루 → 직접 소유** 조건을 충족한다.


## 고마 경주마 현역 유지 기준 — 2026-10-18 추가

- **경주마로 남길 가치와 번식마로 남길 가치는 분리해서 판단한다.**
- 상금벌이 목적을 제외하면, **유럽 GⅠ을 이길 현실적 경쟁력이 없는 고마를 단순 GⅡ/GⅢ 상금벌이용으로 계속 현역 유지하지 않는다.**
- 번식/혈통 가치가 높더라도 경주마로서 경쟁력이 부족하면 현역 유지 사유가 되지 않으며, 필요하면 은퇴 후 번식으로 전환한다.
- 이미 하락세·쇠퇴가 명확하거나 다음 시즌 GⅠ 승산이 낮은 말은 적극적으로 은퇴 후보로 올린다.
- 반대로 사용자가 특정 말에 대해 `現役` 유지 결정을 직접 내린 경우, 그 결정이 일반 기준보다 우선한다.

## 혈통 보존용 사료마 추천 기준 — 2026-10-19 추가

- 후대의 특정 목표마를 확보하기 위한 혈통 보존 추천은 **그 목표마의 직계 어머니(1세대 모마)**일 때만 원칙적으로 추천한다.
- 목표마와 사이에 딸/손녀 등 **2세대 이상 중간 암말이 끼는 경우**, 현재 씨암말 보유공간을 소모하면서 미리 확보하지 않는다. 나중에 더 가까운 직계 어머니가 등장하면 그 말을 사는 쪽을 우선한다.
- 예: **콜로라도 댄서 → 두바이 밀레니엄의 직계 어머니**이므로 혈통 보존용 추천.
- 예: **메지로 몬토레 → 메지로 프란시스 → 모리스**이므로 메지로 몬토레는 '모리스 때문에'는 추천하지 않고, 나중에 메지로 프란시스를 직접 확보하는 쪽을 우선한다.
- 같은 이유로 판타스틱 파인드처럼 목표마까지 여러 세대가 필요한 암말은 후대 목적만으로는 추천하지 않는다.
- 단, 해당 말 자체가 경주마 성능·번식 평가 등 다른 독립적인 이유로 충분히 가치가 있으면 그 이유로는 별도 추천할 수 있다.


## 연도별 구매 추천 수 제한 — 2026-10-19 추가

- 매년 신마/사료마 구매 추천은 **지역별로 수말 1두 + 암말 1두만 기본 추천**한다.
  - 일본: 수말 1두 / 암말 1두
  - 유럽: 수말 1두 / 암말 1두
  - 미국: 수말 1두 / 암말 1두
- 후보가 많더라도 관리두수 증가를 피하기 위해 기본 추천 수를 늘리지 않는다.
- 단, 기본 1두씩만 추천하면 놓치기 아까운 **명백한 필구급 예외**가 있을 때만 추가 추천한다.
- 예외는 단순히 '좋은 말'이나 '무지개찰'이라는 이유로 붙이지 않는다. 세대 내 절대체급이 매우 높거나, 직접 소유 가치가 압도적이거나, 사용자의 핵심 목표상 놓치면 손실이 큰 경우에 한정한다.
- 추가 추천 시에는 **왜 기본 1두 제한을 깨는지 이유를 반드시 설명**한다.
- 후대 혈통만을 이유로 한 추천은 별도 혈통 보존 기준(직계 어머니 원칙)을 따른다.

## 우마무스메 등장마 전지역 체크 — 2026-10-20 추가

- 연도별 신마/역사마 추천 시 **일본마뿐 아니라 유럽·미국 등 해외마도 우마무스메 등장마인지 반드시 확인**한다.
- 성능 추천과 별개로, 해당 출생연도의 우마무스메 등장마가 있으면 **지역에 관계없이 별도 표시**한다.
- 사용자가 실제로 우마무스메에서 알고 있던 구세대/원년 등장마는 누락 방지 우선도가 특히 높다.
- 해외마라도 우마무스메 등장마라면 반드시 알려주며, 성능이 평범하더라도 컬렉션/애착 판단은 사용자가 결정할 수 있게 이름을 숨기지 않는다.
