# カラスブルック (카라스 브룩) - 1982 로테이션

- 4세 수말 / 잔디 중심 / 거리적성 15~22 / 성장형 늦음
- 주요 포인트: 東京巧者, 환경변화×, 정신력 D, 건강 A
- 해외보다는 국내 중심 운용

## 확정 로테이션
- 4월 1주 / 오사카배 / 잔디20 / GⅠ
- 6월 1주 / 야스다 기념 / 잔디16 / GⅠ
- 야스다 기념 뒤 5주 방목
- 10월 1주 / 마이니치 왕관 / 잔디18 / GⅡ
- 10월 5주 / 천황상(가을) / 잔디20 / GⅠ
- 11월 3주 / 마일 챔피언십 / 잔디16 / GⅠ

## 비고
- 야스다 기념, 마이니치 왕관, 천황상(가을)의 도쿄 연전을 통해 東京巧者 활용.
- 오사카배의 자가마 3두 겹침은 허용.
- 천황상(가을) → 마일 챔피언십은 중2주지만 연간 출전 수가 적고 건강 A라 감수.
