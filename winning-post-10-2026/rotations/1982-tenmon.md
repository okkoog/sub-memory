# テンモン (텐몬) - 1982 로테이션

- 4세 암말 / 잔디 중심 / 거리적성 15~25
- GⅠ 무승, GⅠ 2착 2회
- 주요 포인트: 根幹距離, 牡馬混合, スプリンターボ, マイルギア
- 연초에 완결형 로테이션으로 고정. 중간 성적에 따라 일정 변경하지 않는 방향.

## 확정 로테이션
- 3월 1주 / 나카야마 기념 / 잔디18 / GⅡ
- 4월 4주 / 마일러스 C / 잔디16 / GⅡ
- 6월 1주 / 야스다 기념 / 잔디16 / GⅠ
- 이후 5주 방목
- 10월 1주 / 마이니치 왕관 / 잔디18 / GⅡ
- 11월 3주 / 마일 챔피언십 / 잔디16 / GⅠ
- 12월 2주 / 홍콩 마일 / 잔디16 / GⅠ

## 비고
- 홍콩 마일은 레이스 적성 '高い'지만 연말 완결형 일정에 포함.
- GⅠ 첫 승을 노리되 GⅡ를 전초전/실전 확인용으로 적절히 배치.
