# リーゼングロス (리빙글로스) - 1982 로테이션

- 3세 암말 / 잔디◎ / 거리적성 14~22
- 5전 5승 무패, GⅠ 2승
- 주요 포인트: 大舞台, 環境変化○, 負けず嫌い
- 무패 유지 중에는 자가마와의 정면대결 회피 우선
- 오크스 24는 거리 밖이므로 일본 암말 3관 대신 해외 암말 GⅠ + 추화상/엘리자베스 여왕배 노선

## 확정 로테이션
- 1월 2주 / 페어리 S / 잔디16 / GⅢ
- 5월 2주 / 프랑스 1000기니 / 잔디16 / GⅠ
- 6월 3주 / 프랑스 오크스 / 잔디21 / GⅠ
- 7월 2주 / 벨몬트 오크스 초청 S / 잔디20 / GⅠ
- 이후 5주 방목
- 10월 3주 / 추화상 / 잔디20 / GⅠ
- 11월 2주 / 엘리자베스 여왕배 / 잔디22 / GⅠ

## 비고
- 벨몬트 오크스 초청 S는 레이스 적성 '高い', 나머지는 '最適'.
- 추화상만 보쨩과 2두 중복이므로 리빙글로스를 고정하고 보쨩 쪽을 다른 경기로 이동.
