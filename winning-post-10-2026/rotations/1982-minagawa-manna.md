# ミナガワマンナ (미나가와만나) - 1982 로테이션

- 4세 수말 / 잔디 중심 / 거리적성 19~33 / 성장형 늦음
- 주요 포인트: 超長距離, 乾坤一擲, 정신력 A+, 건강 A, 환경변화○
- 장거리 특화 운용. 프레스토우코우와 일부 정면대결 허용.

## 확정 로테이션
- 3월 4주 / 한신대상전 / 잔디30 / GⅡ
- 5월 1주 / 천황상(봄) / 잔디32 / GⅠ
- 천황상(봄) 뒤 2주 방목
- 7월 4주 / 굿우드 컵 / 잔디32 / GⅠ / 영국
- 굿우드 컵 뒤 3주 방목
- 10월 4주 / 영국 롱디스턴스 C / 잔디32 / GⅠ / 영국
- 영국 롱디스턴스 C 뒤 2주 방목
- 12월 4주 / 아리마 기념 / 잔디25 / GⅠ

## 비고
- 2월 4주 다이아몬드 S(잔디34)는 레이스 적성이 '高い'라 차선책으로만 검토했고 최종 제외.
- 한신대상전과 천황상(봄), 아리마 기념에서 프레스토우코우와 겹칠 수 있으나, 말 자체의 적성과 장거리 특화를 우선해 허용.
