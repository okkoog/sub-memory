# WP10 2026 — 일반 커스텀 로테이션 전면 리셋 인수인계서 (GPT-5.6용)

**작성: 2026-10-16 / 사용자 지시로 즉시 적용.**

## 최상위 지시

이 프로젝트에서 **3관 목적 로테이션 이후에 만든 모든 일반 커스텀 로테이션은 전부 폐기하고 처음부터 다시 제작한다.**

- 폐기 대상에는 `NEW-JP-MID`, `NEW-US-DIRT-MID`처럼 사용자가 인게임에서 실제로 구성할 수 있었던 노선도 **포함**한다.
- 두 노선이 게임에서 등록 가능했다는 사실은 역사적 검증 기록으로만 남기며, 새 설계에서 우선권·예외·씨앗 로테이션으로 취급하지 않는다.
- 과거 일반 9종의 경주 조합, 방목 주수, 추천 판정, 중복 검사 결과, 남은 경주 수 계산은 **재사용 금지**.
- 과거 자료를 보고 “일부만 고쳐서 살리는” 방식으로 작업하지 않는다. **0에서 재설계한다.**

## 절대 보존 대상 — 건드리지 말 것

다음 3관 관련 일정은 이번 리셋 대상이 아니다.

1. [유럽 3관 중심 연간 로테이션](triple-crown-annual-rotations-v1.md)
   - 사용자 확정·인게임 저장 6종 유지.
   - `TC-EU-FM` 유럽 암말 마일 3관은 **보류 상태 유지**.
2. [홍콩 3관/단거리 3관 확장 2종](triple-crown-hk-extensions.md)
   - 사용자 확정·인게임 저장 완료 상태 유지.
3. 따라서 **확정 8종 + 보류 1종**의 상태를 새 일반 로테이션 재설계 때문에 변경하지 않는다.

## 리셋 원인

이전 일반 로테이션 제작에서 구작 WP10 GⅡ 자료가 2026판 정보처럼 섞였다.

대표적으로:
- `サンタマリアS`: 과거 설계에서는 **5월 1주 GⅡ**로 잘못 사용. 사용자 게임에서는 **4월 3주 GⅢ 더트1700m**로 직접 확인.
- `フォートローダーデールS`
- `ロイヤルヒロインマイルS`
- `パンアメリカンS`

이 때문에 “구 마스터에 존재함 → 정상 경기”라는 자기검증이 발생했다. 새 작업에서는 **492경주 인게임 정본 외 자료로 GⅠ/GⅡ 날짜·등급을 보충하지 않는다.**

## GⅢ 사용 원칙

사용자는 처음부터 **GⅢ를 금지하지 않았다.**

- 기본 목적은 기본 제공 로테이션에 포함되지 않은 GⅡ 이상 경주 활용.
- 그러나 일정 연결, 적성, 출주 수 확보에 도움이 되면 **GⅢ 사용 가능**.
- 단 GⅢ는 492경주 정본의 범위 밖이므로, 사용할 경우 **WP10 2026 인게임 화면에서 직접 확인된 GⅢ만 확정 사용**한다.
- 현재 직접 확인된 예: `サンタマリアS` — **4월 3주 / GⅢ / 더트1700m / 미국**.
- 구작 GⅢ 일정이나 현실 경마 일정만으로 게임 주차를 확정하지 않는다.

## 새 일반 로테이션을 다시 만들 때의 순서

### 1단계 — 492경주에서 기본 56종 사용 경주를 다시 차감
- 일본 27 / 유럽 16 / 미국 13 = 게임 기본 프리셋 56종.
- 기본 프리셋 파일은 기존 수집본을 사용할 수 있으나, **경주명 별칭을 492 인게임 표기에 맞춰 정규화**한다.
- 종전 `default-rotation-unused-g2plus.md`의 270개 결과를 가져오지 말고 **492 기준으로 처음부터 집합 차감**한다.

### 2단계 — 확정 3관 8종의 보조 경주도 차감
- 이미 사용자 저장 완료한 3관 8종이 사용하는 경주를 중복 방지 집합에 포함.
- `TC-EU-FM`은 보류이므로 실제 적용 집합과 구분해서 관리.
- 3관 필수 경주는 새 일반 로테이션에서 빼는 쪽을 우선한다.

### 3단계 — 새 미사용 경주 풀 확정
- GⅠ/GⅡ/JpnⅠ/JpnⅡ의 실제 남는 수를 새로 집계.
- 지역·마장·거리·성별·연령 조건으로 묶을 수 있도록 분류.
- 이 숫자를 확정하기 전에는 “미사용 몇 경기”라고 추측하지 않는다.

### 4단계 — 일반 커스텀 로테이션을 0부터 설계
사용자 운영 원칙:
- 한 로테이션 **연 6~7전 정도**를 기본 목표.
- GⅡ 이상 미사용 경주를 우선 활용.
- GⅢ는 필요하면 사용 가능.
- 기존 기본 프리셋과 불필요한 경주 중복을 피한다.
- 확정 3관 8종의 보조 경주와도 가급적 중복하지 않는다.
- 한 신규 로테이션끼리도 선택 경주 중복을 피한다.
- 거리 적성·성별·연령·마장 조건을 실제 대상마가 소화할 수 있게 구성.
- 연말 마지막 경주→다음 해 첫 경주까지 **연간 반복 경계**도 검사.
- 해외 이동·방목 일정은 근거 없이 임의 실패 판정하지 말고, 실제 게임에서 문제가 확인된 구간만 수정.
- 외부 note.com 로테이션은 **운영 아이디어 참고용**으로만 사용하고, 경주 존재·등급·주차의 근거로 쓰지 않는다.

### 5단계 — 사용자 승인 전에는 확정하지 않음
- 후보 → 검토 → 사용자 승인 → 인게임 저장 순서.
- “등록 가능”과 “실제 출주 성공/우승 검증”을 구분.
