# WP10 2026 — 1두 복수 3관 목표 가능성 검토

상태: **일정 구조상 검토**, 실제 게임에서 동일 말의 복수 3관 동시 인정을 검증한 것은 아님. 현재 등록 검토 중인 7종 연간형을 임의 대체하거나 같은 관문을 공유하는 변형 로테이션을 추가하지 않는다.

## 기존 기본 1번 일본 고마 왕도는 두 개의 3관을 모두 포함
- 봄 고마 3관: 4월1주 大阪杯 / 5월1주 天皇賞（春） / 6월2주 宝塚記念.
- 가을 고마 3관: 10월5주 天皇賞（秋） / 11월4주 ジャパンC / 12월4주 有馬記念.
- 일본 기본 1번은 10월1주 毎日王冠까지 포함하므로 **봄과 가을 3관 전체 목표 + 연 7전**을 만족한다. 별도 신규 로테이션 필요 없음.

## 제안 B: 아일랜드 암말 3관 + 유럽 암말 마일 3관 동시 목표
필수 경주 합집합은 5개이며, 아일랜드 1000기니를 공유한다:
- 아일랜드 암말: 5월5주 愛1000ギニー → 7월3주 愛オークス → 9월2주 愛セントレジャー.
- 유럽 암말 마일: 5월1주 英1000ギニー → 5월5주 愛1000ギニー → 6월4주 コロネーションS.

## 제안 C: 영국 암말 3관 + 유럽 오크스 3관
- 5월1주 英1000ギニー, 6월1주 英オークス, 7월3주 愛オークス, 8월5주 ヨークシャーオークス, 9월3주 英セントレジャー.
- 필수 5경주 뒤 10월4주 コンセイユドパリ賞 GⅡ(2200m)를 추가하면 연 6전. 하지만 8월5주 요크셔 오크스→9월3주 영국 세인트레저 약 3주로, 부담과 1600~3000m 거리폭이 커서 실전 타당성을 높게 평가하지 않는다.

## 운용 규칙 조정 검토 사항
현재 확정 규칙은 3관 실패 시 즉시 자동 전환이다. 복수 3관 동시 목표는 **한쪽 3관에 실패해도 다른 쪽이 아직 살아 있을 수 있다**. 복수 3관용 로테이션을 실제 채택한다면 “모든 병행 3관이 불가능해질 때 자동 전환” 등의 예외를 사용자에게 확인해야 한다. 동의 없이 정책을 바꾸지 않는다.
