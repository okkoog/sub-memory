## 1982년 인게임 GⅠ·GⅡ 492경주 집계의 범위 검증 (사용자 보고, 2026-10-16)

- 사용자 1982년 세이브에서 경주 검색 조건을 GⅠ·GⅡ로 지정하자 **492경주** 표시. 인게임 실측값으로 기록. 별도 외부 사이트에서 재현됐다는 주장은 하지 않음.
- 기존 GitHub 마스터는 **493행**, 등급별 **GⅠ 248 / GⅡ 221 / JpnⅠ 12 / JpnⅡ 12**. 경주명 493개는 마스터 내부 문자열 기준 고유.
- **사용자가 재확인: 해당 게임 필터에는 JpnⅠ·JpnⅡ도 포함됨.** 따라서 **493과 492는 동일한 등급 범위**이며, 이전 Jpn 포함 여부의 양자택일 가설은 **종료**. 더 이상 같은 질문으로 사용자에게 필터 확인을 요구하지 않는다.
- **범위가 완전히 동일한 경우라도**, 사용자 현재 게임에서 찾지 못한 4개는 마스터에 있으므로 최소 4개의 마스터 전용 경주가 존재. 이때 마스터 493, 인게임 492이면 **게임 전용 경주도 최소 3개** 존재한다. 즉 순차 '1개 차이'는 서로 다른 종류의 오류를 상쇄한 결과일 수 있음. 미발견은 현재 필터·1982년 검색에 한정한 사실이며 2026판 영구 삭제로 확정하는 뜻이 아님.
- 본 조사 이전 단계의 잘못된 마스터 행을 **492에 맞추려고 임의 1행 삭제하지 말 것**. Jpn 포함 여부는 사용자가 답했으므로 해결됨. 남은 문제는 1982년 게임 목록과 마스터 항목의 **실제 집합 차이**를 찾아내는 것. 지역·월별 소집합과 경주별 2026판 출처를 이용해 추적하되 마스터의 493을 진짜 목록이라고 가정하지 않는다.
