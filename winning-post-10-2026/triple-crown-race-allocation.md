# WP10 2026 — 3관 우선 배정 뒤 잔여 GⅡ+ 가상 집계

계산 기준: [GⅡ 이상 기본 프리셋 미포함 목록](default-rotation-unused-g2plus.md) 270행에서 [유럽 3관 신규 7종](triple-crown-annual-rotations-v1.md) 및 [홍콩 확장 2종](triple-crown-hk-extensions.md)에 들어간 경주를 한 번씩 제외. **사용자 승인 전 설계안 기반의 시뮬레이션일 뿐, 실제 배정/최종 소진된 경주를 의미하지 않음.**

## 결과
- 기본 프리셋 미포함 GⅡ 이상: **270개 행**
- 신규·확장 3관 9종에 배정한 미포함 경기: **30회 출주 / 실제 경주명 28개**. 2회 중복은 다른 3관의 필수 관문인 영국 세인트레저와 아일랜드 1000기니 때문.
- 9종 그대로 채택한다는 조건에서 남는 커스텀용 미포함 GⅡ 이상: **242개 경주**.
- 잔여 마장: **잔디 160 / 더트 82**.
- 잔여 등급: **GⅠ 73 / GⅡ 163 / JpnⅠ 1 / JpnⅡ 5**.
- 주요 지역: **미국 118 / 프랑스 28 / 영국 29 / 호주 22 / 일본 중앙 17 / 일본 지방 6 / 아일랜드 8 / 캐나다 4 / 독일 3 / 홍콩 3 / 두바이 3 / 사우디 1**.

## 커스텀 기획 순서(향후)
1. 3관 노선에 필요한 경주 사용 확정 → 기본 프리셋 원본 유지/조정 결정.
2. 잔여 242개는 **후보 풀**로 분류: 2세 전용, 3세 전용, 고마 연령별 / 잔디·더트 / 거리대·성별·지역.
3. 서로 동일 경주를 크게 공유하는 일반 로테이션을 다수 생성하지 않는다. 개별 후보 6전 이상 적성과 연간 운용성을 우선.
4. 두 개의 마스터 별명 중복 제거(메이커스 마크 마일, 맥 다이어미다)를 반영한 수치.
