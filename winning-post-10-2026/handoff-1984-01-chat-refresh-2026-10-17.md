# Winning Post 10 2026 — 1984년 1월 채팅 갱신 인수인계

작성일: 2026-10-17  
게임 내 시점: **1984년 1월 1주**  
목적: 기존 채팅이 길어져 새 채팅으로 이동할 때, 여러 파일을 다시 훑다가 과거 상태를 최신 상태로 오인하는 일을 막기 위한 **최신 우선 인수인계 문서**.

> 새 채팅에서는 이 문서를 먼저 읽고, 세부 능력·과거 전적이 필요할 때만 `horse-data-master.md`, `game-event-log.md`, `current-game-state.md`, 각 로테이션 파일을 추가 조회한다.
>
> **우선순위:** 최신 사용자 직접 보고 > 같은 시점 화면 > 최신 정정/확정 이벤트 > 이 인수인계 > current-game-state > horse-data-master > 과거 추천 > 추론.

## 1. 가장 중요한 응답 원칙

- 사용자가 새 사실을 알려줬는데 기존 기록에서 확인되지 않았던 내용이면, **원래 알고 있었던 것처럼 맞장구치지 않는다.**
  - 예: 노스 가스트의 1983 두바이 시마 클래식 우승은 사용자가 뒤늦게 직접 알려준 정보였다.
  - 올바른 반응: “아, 그 1승은 기존 정보에서 확인되지 않아 무승으로 판단했다. 이제 새 정보로 반영하겠다.”
- 오래된 추천이나 과거 화면을 최신 상태보다 우선하지 않는다.
- 자동 운용마의 `次走`는 게임 자동 배정이다. 사용자가 직접 짠 수동 일정으로 해석하지 않는다.
- **출주 가능성/등록 여부를 선제적으로 재확인하지 않는다.** 사용자가 물었을 때만 확인한다.
- 여러 소유마의 자동 일정 충돌을 일일이 미리 검사하지 않는다. 핵심마와 같은 경주가 잡히면 사용자가 **당일 취소**한다.
- 2세는 연초 정보가 부족하므로 지금 능력 입력/로테이션 평가 대상이 아니다.

- 일본 31두

- 현 2세 신규 잔존: 일본 8 / 유럽 4 / 미국 4 = **16두**

현재 입력 작업 순서:
1. 3세 전원 최신 정보 입력 및 로테이션 배정
2. 4세 이상은 과거 정보가 남아 있다는 전제로 **능력 화면 중심 갱신**
3. 2세는 정보가 열릴 때까지 보류

**일본은 현재 3세 + 4세 이상 로테이션 배정까지 완료. 다음은 유럽 3세부터 시작.**

## 5. 1983 연말 정리 규칙과 실제 처리

### 3세 연말 생존선
- 3세 시즌에 **OP/L 또는 GⅢ 이상 우승이 최소 1회** 있어야 기본 생존.
- 신마·미승리·1승·2승·3승 클래스 우승은 생존 판정용 유효승으로 보지 않음.
- **비자가생산 구매마**는 기준 미달이어도 1회에 한해 4세 시즌까지 세이브.
- 별도 예외: **카라스 킹**은 1983년에 3전밖에 안 뛰어 표본 부족으로 1년 더 세이브.

### 1983 연말 은퇴

- 노쇠/하락 등: 밤부 아틀라스 / 카라스 폴리시 / 하기노 톱 레이디 / 코난 루비 / 카라스 브룩

## 6. 신생마 보유 / 클럽 / 매각 최신 규칙

**이 절이 최신 규칙이며 과거의 단순 ‘거물=클럽’ 규칙보다 우선.**

- **초대형 거물(超大物)** → 무조건 직접 소유
- **거물(大物)**
  - 河童木(캇파키) + 美香(미카) 둘 다 ◎ → 직접 소유
  - 그 외 → 클럽행
- **꽤나 좋은 느낌(けっこういい雰囲気)**
  - 캇파키 + 미카 둘 다 ◎ → 클럽행
  - 그 외 → 매각
- 그보다 낮은 코멘트 → 원칙적으로 매각

예시:
- 사마렉스쨩82 = 거물 + 캇파키◎ + 미카◎ → 직접 소유

### 새 현역 유지 판단
- 상금벌이 목적을 제외하면, **유럽 GⅠ을 이길 현실적 경쟁력이 없는 말을 경주마로 계속 남겨둘 이유는 거의 없다고 판단**.
- 경주마 현역 유지와 번식/혈통 보존은 별도 판단. 번식 가치가 있어도 현역 경쟁력이 없으면 은퇴 후 번식으로 전환 가능.
- 사용자가 은퇴 화면에서 직접 `現役`으로 남긴 말만 유지하고, 나머지 `引退` 선택마는 대대적으로 은퇴.
