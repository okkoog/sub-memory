# Winning Post 10 2026 진행 메모

기준 시점: **1982년 1월 1주**

이 문서는 ChatGPT 대화가 바뀌거나 컨텍스트가 끊겨도 현재 세이브의 판단 기준과 진행 상황을 복구하기 위한 보조 메모다.

## 기본 판단 기준

- 게임은 **Winning Post 10 2026**.
- 평가액만으로 말의 가치를 판단하지 않는다.
- 번식마 보존은 실제 경주 성적, 산구 성적, 혈통 희소성/보존 가치, 역사적·기념 가치, 실제 배합 시뮬레이션 결과를 함께 본다.
- **리니어 퀸, 테스코 가비처럼 전적이 좋은 말은 번식 효율과 별개로 남겨두고 싶어 한다.**
- 희귀 혈통은 보존 가치가 있을 수 있으므로 단순 평가액보다 우선할 수 있다.
- 직접 소유가 가능한 강한 말은 직접 관리 우선. 남는 말은 클럽행.
- 신마는 먼저 육성 코멘트로 급을 나누고, 같은 급 안에서 마장/거리/형제 성적 등을 비교한다.

### 육성 코멘트 등급
- `超大物の風格を感じます` = **초대물**
- `大物の雰囲気を持っています` = **거물**
- `けっこういい雰囲気を持っています` = **꽤나 좋은**
- `いい雰囲気` 계열 = **좋은**
- `正直強調材料はありません` = **강조할 재료 없음**

## 사용자 작명 규칙

- 사용자가 직접 붙인 이름에서 대체로 **카라스~ = 수말**, **~쨩 = 암말**.
- 화면의 牡/牝 표기가 명확하면 화면을 우선한다.
- 과거 이미지 판독 오류를 고집하지 말 것.

- 구성: 小倉牝馬S GⅢ 2000 → 방목3주 → 阪神牝馬S GⅡ 1600 → ヴィクトリアマイル GⅠ 1600 → 방목10주 → アイルランドT GⅡ 1800 → エリザベス女王杯 GⅠ 2200 → ターコイズS GⅢ 1600.
- 목적: 이미 보유한 牝馬3冠·阪神JF에 이어 **牝馬GⅠ完全制覇** 미획득분을 노리는 것. 과거 시리즈 정보상 牝馬3冠 후 エリザベス女王杯와 ヴィクトリアマイル이 완전제패의 핵심 잔여 관문이 될 수 있으므로 두 경주를 모두 포함하는 기본 6번이 가장 직접적.
- 기본 6번의 GⅢ 2전은 급 하향 목적이 아니라, 해당 특수 업적을 노리는 연간 프리셋의 전초·마무리 구간으로 사용.
- 현재 확정 배정된 하기노 톱 레이디(古馬マイル), 카라스 블랙(サマー2000 수동), 프레스토우코우/노스가스트/미나가와 만나의 핵심 경주와 직접 충돌하지 않음.


## 텐몬
- 5세 암말 / 잔디◎ / 거리적성 14~26 / 성장형 빠름.
- 통산 16전 9승 / GⅠ 1승 / GⅡ 4승 / GⅢ 2승.
- 최근 5전: マイラーズC GⅡ 1착 → 安田記念 GⅠ 1착 → 毎日王冠 GⅡ 2착 → マイルCS GⅠ 2착 → 香港マイル GⅠ 9착.

- 최근 홍콩마일 9착 하나를 제외하면 4전 연속 2착 이내라 여전히 GⅠ급. 자동/GⅡ 전용 하향 대상 아님.
- **추천: 유럽 기본 7번 `古牝馬マイル`.**
- 구성: 3월3주 クールモアクラシック GⅠ 1500 → 4월3주 クイーンオブザターフS GⅠ 1600 → 방목6주 → 7월3주 ファルマスS GⅠ 1600 → 방목2주 → 9월2주 メイトロンS（愛） GⅠ 1600 → 10월2주 サンチャリオットS GⅠ 1600.
- 이유: 하기노 톱 레이디가 일본 기본 4번 古馬マイル로 春秋マイル制覇를 노리고 있어 일본 마일 왕도 중복을 피해야 함. 텐몬은 根幹距離・マイルギア・정신 S+를 가지고 있어 해외 암말 마일 GⅠ 노선이 잘 맞음.
- 유럽 기본 7번은 전 경주가 1400~2600m 적성 안이며, 최근 주력 거리 1600~1800m와 정확히 맞음.
- R2-EU-MILE은 전부 GⅡ라 현재 GⅠ 1착·2착 전력에 비해 급을 낮추는 선택이므로 후순위.
- 유럽 기본 6번 古牝馬中距離도 적성상 가능하지만 2000~2400m 비중이 높아 최근 마일 실적 및 マイルギア 활용 면에서 7번보다 우선도가 낮음.
- 현재 확정 배정된 노스가스트(EU1), 하기노 톱 레이디(JP4), 짐 앤드 찬(JP6), 카라스 블랙(サマー2000 수동), 미나가와 만나(국제 장거리 수동)와 핵심 경주 직접 충돌 없음.

## 코난 루비
- 5세 암말 / 더트◎ / 잔디× / 거리적성 15~29 / 성장형 빠름.
- 통산 18전 12승.
- 최근 5전: エンプレス杯 JpnⅡ 1착 → 帝王賞 JpnⅠ 4착 → 日本テレビ盃 JpnⅡ 1착 → JBCレディスクラシック JpnⅠ 1착 → 東京大賞典 GⅠ 5착.
- 주요 승리: JBCレディスCL / 川崎記念 / プロキオンS / エンプレス杯. 春秋ダート制覇 표시는 없음.

- **추천: 일본 기본 7번 `古馬ダート`.**
- 구성: フェブラリーS GⅠ 1600 → 川崎記念 JpnⅠ 2100 → かしわ記念 JpnⅠ 1600 → 帝王賞 JpnⅠ 2000 → 방목6주 → 南部杯 JpnⅠ 1600 → JBCクラシック JpnⅠ 2000 → チャンピオンズC GⅠ 1800 → 東京大賞典 GⅠ 2000.
- 이유: 코난 루비는 春秋ダート制覇가 아직 표시되지 않고, 이 프리셋은 フェブラリーS + チャンピオンズC를 같은 해에 포함해 해당 세트 업적을 직접 노릴 수 있음.
- 일본 기본 9번 古牝馬ダート는 JpnⅡ/Ⅲ 중심이고 JBCレディスクラシック도 이미 우승해 현재 전력과 미획득 업적 관점에서 우선도가 낮음.

- 현재 확정 배정된 다른 소유마와 더트 핵심 경주 직접 충돌 없음. **코난 루비가 일본 古馬ダート 노선을 선점**하는 것으로 이후 배정 시 충돌 회피.

## 카라스 벤처
- 4세 수말 / 잔디◎ / 더트× / 거리적성 18~30 / 성장형 빠름.
- 통산 11전 3승. 주요 승리: 鳴尾記念.
- 최근 5전: 京都新聞杯 GⅡ 2착 → 小倉記念 GⅢ 5착 → 新潟記念 GⅢ 8착 → チャレンジC GⅢ 3착 → 鳴尾記念 GⅢ 1착.

- 현재 화면 방침3(잔디 GⅢ 자동)에서 **R2-JP-MID 수동 로테이션으로 승격 추천**.

- 적용 후 3경기 연속 6착 이하이면 기존 규칙대로 즉시 자동 방침으로 전환. 현재는 승격 도전 가치가 있음.
