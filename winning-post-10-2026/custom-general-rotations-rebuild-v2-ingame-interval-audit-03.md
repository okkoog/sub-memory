# WP10 2026 — R2 9종 수정 후 간격 감사 03

**기준: 2026-10-16. 1차 인게임 간격 확인 뒤 5개 노선을 수정했고, 사용자 인게임 반영까지 완료.**

## 주의

- 기존 9종의 실제 화면 `間隔`을 바탕으로 불필요한 中1週를 제거했다.
- 새로 교체한 경주가 포함된 구간의 간격은 **기존 인게임 간격 규칙으로 계산한 값**이다.
- 수정안을 아직 사용자 게임에서 다시 입력해 화면 확인한 것은 아니므로, 아래 새 구간을 '인게임 실측 완료'라고 부르지 않는다.
- 실제 화면과 계산이 다르면 **게임 화면을 우선**한다.

## 전체 결과

- 수정 후 **9종 / 54전**.
- GⅠ 16 / GⅡ 37 / GⅢ 1.
- 기존 7개의 불필요한 中1週 문제 중:
  - R2-US-MARE 1곳 제거
  - R2-EU-SPR 2곳 중 GⅡ→GⅡ 1곳 제거, 1000m GⅠ→GⅠ 1곳 예외 유지
  - R2-EU-MARE 1곳 제거
