# WP10 2026 기본 제공 로테이션 조사 현황

작성: 2026-10-16

## 목적

기본 제공 로테이션이 사용하는 GⅡ 이상 경주를 식별하여 `g2plus-race-calendar.md`의 487경주와 대조하기 위한 근거 정리.

## 현재 확정된 사실

- 공식 Web 매뉴얼의 말 정보 화면 설명에 `古馬長距離` 같은 정해진 노선 로테이션을 선택할 수 있다고 명시됨.
- 로테이션 선택 시 방목도 자동 설정됨.
- 메인 기능 > 로테이션 메뉴에서 커스텀 로테이션 최대 50개 저장 가능.
- 기본 제공 프리셋을 바탕으로 수정 가능하다는 2026 설명도 있음.

## 미확정

- 게임 기본 제공 로테이션 전체 명칭/수량.
- 기본 로테이션별 정확한 경주명·주차·등급 구성.
- 기본 로테이션과 사용자 제작 로테이션의 1:1 대응.
- 따라서 **현재 기본 로테 소모 경주 수는 0으로 간주하는 것이 아니라 미확인**.

## 대조 규칙

1. 확인된 게임 기본 제공 로테이션만 '기본로테 사용' 처리.
2. 개인 블로그의 직접 만든 추천 로테이션은 별도 구분.
3. 등록 경주명은 487경주 마스터 캘린더의 원문 표기와 정규화하여 비교.
4. 실제 1982년 게임 화면에 나타난 스케줄을 최종 우선.
5. 확인되지 않은 경주의 사용 여부는 '미확인'으로 두며 '미사용'으로 단정하지 않는다.
