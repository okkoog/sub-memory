백사의 R18 텍스처 확장 1.4.0
Bai She's R18 Texture Pack 1.4.0

'백사의 전체 캐릭터 여성화' 모드를 위한 성인용 텍스처 확장팩입니다.
게임 로직을 변경하지 않으며, 텍스처만 추가합니다.

■ 포함 콘텐츠
- 반신 이미지 240장: 머리 꼭대기 아래 280px 지점에 맞춰 통일해서 자른 뒤 아래쪽 기준으로 정렬했습니다. 모든 캐릭터의 머리 위치가 동일합니다.
- 전체 이미지 240장: 종아리까지 보이는 전신에 가까운 구성입니다.
- 메탈슬러그 확장용 이미지 16장: '백사의 메탈슬러그 확장팩' 캐릭터에 적용됩니다.

■ 설치 및 사용
1. 이 확장팩을 설치하고 활성화합니다. 처음 사용할 때는 게임 모드 목록에서 한 번 확인해야 합니다.
2. '백사의 전체 캐릭터 여성화' 본편 모드 2.9.6 이상을 설치합니다.
3. 본편 모드 설정 → 백사의 R18 텍스처 확장 → 화면 → 'R18 확장팩 텍스처 사용'을 켭니다.
4. 같은 설정 화면의 '반신 모드' 스위치로 두 이미지 구성을 전환합니다.
   켜짐: 반신 이미지 / 꺼짐: 전체 이미지. 즉시 적용되며 게임을 다시 시작할 필요가 없습니다.

■ 메탈슬러그 확장
'백사의 메탈슬러그 확장팩' 설정에서 '일러스트 스타일'을 'R18 / R18'로 선택합니다.
앨런 오닐과 화성인 두 캐릭터는 이 확장팩에 성인용 일러스트가 아직 없으며, 여성화 버전 이미지로 자동 대체됩니다.

■ 주의 사항
- Portrait Studio(초상화 스튜디오)에서는 이 확장팩을 별도 이미지 공급원으로 표시하지 않습니다.
  본편 모드가 이미지를 일괄 공급해 서로 다른 두 이미지 세트가 충돌하지 않도록 합니다.
- 성인용 콘텐츠이므로 18세 미만은 이용하지 마세요.
- 저장 데이터를 수정하지 않으며 네트워크를 사용하지 않습니다.

■ 한국어 메타데이터 패치 적용
이 번역 폴더의 manifest.xml만 해당 원본 모드 폴더의 manifest.xml에 덮어씁니다.
원본 mod ID·버전·선행 모드·DLL 지정은 그대로 보존됩니다.
원본 R18TexturePack.dll과 이미지 리소스는 변경하거나 삭제하지 마세요.
README_ko.txt는 한국어 안내서로, 실행에 필요한 파일은 아닙니다.
