# 음란한 심우주: 암류 거래 1.6.4

원작자: 白银 / 확장 제작자: 扫地机

이 패키지는 **비공식 확장 모드**로, **lewd_meme 1.9.2 이상**을 함께 활성화해야 합니다. 현재 제작자가 확인한 버전은 1.9.2입니다.

이 모드는 모유 3종, 피로도와 가치 평가, 통 보관, 묘상 매입상, 거래 명부, 치안부 지선 이야기를 추가합니다. 기본 아이템, 캐릭터 포획, 행동, 임신 판정, 출산, 캐릭터 초상화는 원본 모드에서 제공합니다.

## 설치 및 업데이트

이 모드 폴더를 게임의 `Mods` 디렉터리에 넣고 선행 모드와 함께 활성화하세요. 업데이트 후 게임을 다시 실행합니다. 모드 폴더에는 `ShadowTrade.dll` **하나만** 남겨야 하며, 이전 `MidnightPawnRemake.dll`을 함께 두지 마세요.

모드 ID는 계속 `lewd_meme_remake`입니다. 네임스페이스, 아이템 ID, 기존 세이브 키도 유지했습니다. 이전에 생성된 캐릭터, 모유, 통, 명부와 진행 중인 이야기를 계속 사용할 수 있습니다. 이전 버전의 딸 관련 태그에는 원본 게임의 식별자가 자동 보완됩니다. 어셈블리 이름 변경과 이번 버전의 인터페이스 삭제는 외부 확장에 영향을 줄 수 있으므로 [개발 안내](docs/开发指南.md)를 확인하세요.

## 현재 정산 규칙

- 원본 모드가 행동, 임신 판정 및 생산을 먼저 처리한 다음 이 모드의 모유 세 종류를 추가합니다. 이 모드 모유 1개를 생산할 때 생산 구역에서 원본 신비한 모유를 먼저 1병 차감합니다. 병이 없으면 신비한 모유 통에서 사용 횟수 1회를 차감합니다. 둘 다 없어도 생산은 진행됩니다. 같은 종류의 통이 이미 있으면 거기에 수량을 바로 더하는 방식을 우선합니다. 취향은 텍스트 정보만 유지합니다.
- 밤이 시작될 때 피로도가 **90 이상**이면 해당 캐릭터의 그날 밤 행동, 양쪽의 생산, 임신 판정, 임신 기간 진행과 출산이 모두 중단되고 피로도는 5 회복됩니다. 과로 상태가 아니면 원본 정산이 그대로 진행됩니다. 피로도는 이 모드의 가치 평가에만 반영합니다.
- 촉수 본체, 결산 기능을 켠 묘상 상자, 알람시계 및 작동 중인 함정에는 공통 피로도 규칙이 적용됩니다. 그 외 위치에서는 매일 피로도 25를 회복합니다. 촉수 본체 레벨 1~10의 피로도 계수는 순서대로 **1, 0.8, 0.65, 0.5, 0.4, 0.3, 0.25, 0.2, 0.15, 0.1**이며, 11레벨부터 피로도가 누적되지 않습니다.
- 야간 정산 뒤 촉수 본체의 생산 구역 전체를 검사합니다. 정액 **8병** 이상, 이 모드 모유는 종류별로 **3병** 이상 있으면 자동으로 통을 만들 수 있습니다. 원본과 확장 모드의 신비한 모유는 합계 **3병**을 신비한 모유 통에 담습니다. 이전 재고도 포함됩니다. 새 통 생성 여부는 종류별 네 옵션으로 독립 제어하며, 이미 존재하는 통은 해당 옵션을 꺼도 계속 보충됩니다.
- 선택 옵션인 '침식 구역의 묘상 상자도 야간 정산 참여'는 기본적으로 **꺼짐**입니다. 켜면 상자 내부의 모든 보관 페이지를 확인하고 원본 반복 처리를 직접 호출합니다. 결과는 원본 보고서와 경험치에 반영되며, 촉수 본체의 주 묘상 구역이 비어 있어도 처리합니다.
- 처녀 상태 회피, 생산량 배율, 이 모드의 전용 야간 API 및 구역 API를 제거했습니다. 원본 야간 보고서는 유지하며 추가 모유와 재고 통 보관 내역은 별도의 아침 보고 로그와 암류 거래 메모에 기록합니다.
- 치안부의 규제 등급 보상은 이야기 진행 상태와 기존 등록 키를 기준으로 계속 적용됩니다. 배란 유도제는 Ⅰ급, 병·통에 담긴 정액은 Ⅱ급, 묘상은 Ⅲ급입니다. 처음 문을 열 때 기존 아이템에도 적용하고 이후 생성되는 아이템은 자동 등록합니다.
- 설명은 `docs/` 폴더에 모았습니다. 오래된 보고서나 예전 테스트 안내는 이번 버전의 설명서에서 중복 유지하지 않습니다.
