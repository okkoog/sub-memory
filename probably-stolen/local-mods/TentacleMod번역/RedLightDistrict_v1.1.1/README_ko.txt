홍등가 (Red Light District) v1.1.1 — 한국어 CSV 조회 브리지 DLL

■ 적용 대상
- 게임에서 사용할 원본 Red Light District v1.1.1 모드.
- 원본 DLL SHA-256: 4f4f20a00e4754302c53879bfaeb7a7503df10e2f05ff6ad3744be31088159f8
- 한국어 수정 DLL SHA-256: 2c1c579523058dca9d5e1a7b2ef7162fbdcca48e64be183a45df564d721cd100
- 기존에 214개 UI 문구만 직접 치환한 시험 DLL은 구형입니다. 외부 ko.csv 전체 번역을 적용하지 못하므로 사용하지 않습니다.

■ 설치 절차 (DLL과 CSV 둘 다 필요)
1. 게임을 완전히 종료하고 원본 v1.1.1 모드 폴더와 세이브 파일을 백업합니다.
2. 한국어 번역 파일에 포함된 RedLightDistrict.dll을 원본 모드 폴더의 동명 DLL에 덮어씁니다.
3. 함께 제공된 Localization/ko.csv를 같은 모드 폴더의 Localization 폴더로 복사합니다.
4. 원본 모드의 다른 파일(초상화, 사운드, 원본 리소스 등)은 유지합니다.
5. 게임을 재실행해 한국어 표시, 아이템·대사·저장 동작, 다른 모드와의 호환성을 직접 확인합니다.

■ 동작 원리
- 원본의 중국어 포함 IL 문자열 호출 3,619곳을 메서드명·IL 위치·원문으로 각각 확인한 후 고유 로컬키를 조회하도록 수정했습니다.
- ModLoader가 적재한 한국어 Localization 사전에서 ko 키가 존재하면 해당 위치에 한국어를 표시하고, 찾지 못하면 원문 중국어로 돌아갑니다. 파일 내용 수정은 게임 재실행 후 반영됩니다.
- 한국어 번역 원본 3,528키와 표시 전용 별칭 24키. 나머지 원본 91키는 저장 문자열, 정확한 이름 검색, 아이템 식별자 등 기능 보호를 위해 원문으로 유지합니다.
- 번역 DLL의 한국어 문자열은 외부 CSV에서 읽으므로 다음 번역 수정은 ko.csv만 변경하면 됩니다. 다만 처음 설치할 때는 반드시 **수정된 DLL과 CSV를 모두** 적용해야 합니다.

■ 검수 상태
- 전체 3,619개 키 대조, 원본 한국어 CSV 3,528개와 보호 원문 91개(표시 전용 별칭 24개 별도), 중복/누락 0개.
- 원본 1,617개 관리 리소스 바이트 동일; 수정 DLL을 다시 열어 CLR 타입·메서드 구조, 브리지 호출 수를 확인했습니다.
- 실제 게임(Unity/CLR) 실행과 세이브 호환성, 모드 로더의 브리지 실행 시점은 미검증입니다.
- 원본 모드의 파일과 원본 DLL은 GitHub 원본 폴더에서 수정하지 않았습니다.
