홍등가 (Red Light District) v1.1.1 — 한국어 DLL 정적 시험본

■ 설치
1. 원본 RedLightDistrict_v1.1.1을 먼저 준비하십시오.
2. 원본 모드 폴더를 백업하십시오.
3. 이 번역 파일의 RedLightDistrict.dll 및 manifest.xml을 원본 폴더에 덮어씁니다.
4. 모드 ID red_light_district가 하나만 활성화되어 있는지 확인합니다.
5. 모드가 요구하는 파일 접근 및 파일 기반 오디오 로딩 권한은 기존 설정을 유지합니다.

■ 번역/원본 보존
- 중국어 사용자 표시 문자열 중 IL 호출부가 화면 UI·도움말·툴팁임을 확인한 부분만 선택적으로 번역합니다.
- CJK 문자열을 모두 한꺼번에 치환하지 않습니다. 식별자, 파일 경로, 저장 키, 클래스·메서드 연계 이름을 보존합니다.
- 원본 152,970,752바이트 DLL은 번역 폴더 밖에서 그대로 보존합니다.
- 한국어 변경이 반영된 시험 DLL은 단독 실행 모드가 아니라 교체 파일입니다.
- 본 시험본에 포함되지 않은 대사와 진단 문자열은 중국어로 표시될 수 있습니다.

■ 확인 필요
- 정적 코드·리소스 보존 검사와 실제 게임 실행은 별개입니다.
- 이 DLL은 Windows/Unity/CLR 런타임, 게임 세이브, 다른 모드와의 호환성을 아직 검사하지 않았습니다.
- 원본에서 치안부/파일 접근 권한·network 권한을 요구하는 상태이므로 권한 요구를 임의로 제거하지 않았습니다.
- 게임 테스트에서 오류가 나타나면 백업한 원본 DLL로 즉시 복원하십시오.
