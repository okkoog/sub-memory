홍등가 (Red Light District) v1.1.1 — 한국어 Localization

■ 적용 대상
- 제작자가 외부 Localization 키 조회 기능을 추가한 v1.1.1 DLL.
- 기존에 DLL 내부 문자열을 덮어쓰던 한국어 시험 DLL과는 별도의 방식입니다.
- 저장소의 원본 DLL은 Git LFS 포인터이므로 이 ZIP에 DLL을 포함하지 않습니다.

■ 설치 방법
1. 게임에 로컬키 지원 기능이 포함된 최신 Red Light District 모드를 설치합니다.
2. 해당 모드의 Localization 폴더에 ko.csv를 복사하여 기존 파일을 덮어씁니다.
3. 게임을 완전히 종료했다가 다시 실행합니다.
4. 이 파일 하나만 바꾸는 방식이므로 모드 ID, manifest.xml, DLL을 변경할 필요가 없습니다.

■ 미완료와 검증
- 원본 cn.csv에는 서로 다른 호출 지점별로 3,619개의 키가 있습니다. UI 문구뿐 아니라 진단 로그, 식별자, 분기 판정용 문자열도 들어 있습니다.
- 최신 한국어 CSV는 3,512개 키를 번역하며 107개는 기능 보호 목적으로 중국어 원문을 사용합니다(미분류 검수 대기 0개).
- 번역은 확실한 문맥과 용도를 확인한 문자열부터 순차 반영합니다.
- 한국어 값이 없는 키 107개는 모드의 기존 중국어 원문으로 돌아가도록 설계됐습니다. 보관함 이름 비교 및 급식기·정수기 기존 세이브 설명 검색을 보호합니다.
- 인물 이름 비교/경로/저장 키/구조적 문자열은 무조건 한국어로 치환하지 않습니다.
- 사전 검증은 CSV 키, 서식 변수, 이스케이프/줄바꿈 일치와 파일 일관성을 확인합니다. 실제 게임 로드와 저장 파일 호환성은 별도 확인이 필요합니다.
- 정적 생성기에서 수정한 번역은 Localization/ko.csv에 병합하며 원본 cn.csv와 원본 DLL은 절대 수정하지 않습니다.
