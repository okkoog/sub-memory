홍등가 모드 — 인재 초상화 사용자 지정
================================

이 폴더에 PNG 이미지를 넣으면 해당 인재의 사용자 지정 초상화로 사용할 수 있습니다.

· 확장자를 제외한 파일명이 인재의 이름입니다. 예: 蛙娘.png → 인재 「蛙娘」.
· 같은 이름의 이미지는 모드에 내장된 동일 이름의 초상화보다 우선 적용됩니다(디스크 파일 우선).
· 이미지가 없는 인재는 모드 내부에서 자동 생성한 초상화 모음으로 대체됩니다.
· 이미지를 변경하거나 새로 추가한 경우 다음 게임 실행 또는 다음 인재 생성 시 반영됩니다.

※ 파일명과 인재 이름은 내부 일치 조건으로 사용되므로 임의로 한국어로 바꾸지 마세요.
