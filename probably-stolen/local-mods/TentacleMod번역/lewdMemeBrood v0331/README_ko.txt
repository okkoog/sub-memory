촉수 둥지 확장 (LewdMemeBrood) v0.3.31 — 외부 상호작용 대사 한국어화

■ 적용 범위
- 원본 mod ID: claude.lewdMemeBrood
- 파일: Content/interactionLines.json
- 표시용 상호작용 대사 135개 중 135개를 원문 내용과 1:1 비교해 한국어로 번역했습니다.
- 개발자용 설명과 읽지 않는 예시 2개도 한국어로 옮겼습니다.

■ 설치
1. 원본 LewdMemeBrood v0.3.31 모드를 설치하고 모드 폴더를 백업합니다.
2. 게임을 종료하고 번역 ZIP에 있는 lewdMemeBrood v0331/Content/interactionLines.json을 원본 Content 폴더에 덮어씁니다.
3. 기존 DLL, manifest.xml 및 다른 파일은 지우거나 변경하지 마세요.
4. 게임에서 촉수 사용/포식 대사와 저장·호환성이 정상인지 확인하세요.

■ 주의
- 대사 객체의 kind, tags, 변수 {name}, {tentacle}는 원본과 완전히 동일하며, 조건 구문 MAIDEN_BODY=萝莉 등의 중국어 태그는 게임이 정확한 문자열을 조회하므로 원문대로 유지합니다.
- 기능 보호용 태그가 중국어인 것은 대사 미번역을 의미하지 않습니다.
- ZIP은 번역 파일을 덮어쓰는 패치이며 원본 모드 전체가 아닙니다.
- 실제 Unity 게임 실행/메시지 표시 검증은 실시하지 않았습니다.
