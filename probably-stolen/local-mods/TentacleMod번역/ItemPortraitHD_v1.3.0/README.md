# 묘상 고해상도 초상화 관리자 ItemPortraitHD 1.3.0

`lewd_meme` 캐릭터 아이템에 128/256 해상도의 고해상도 텍스처, 완전한 4×4칸 점유, 투명 영역 클릭·드래그, 아이템별 초상화 교체 기능을 제공합니다.

설치할 때 `ItemPortraitHD` 폴더 전체를 유지하고, 게임에서 이 모드와 `lewd_meme`를 활성화하세요. DLL 업데이트 후에는 게임을 다시 실행해야 합니다. 그 밖의 이미지 팩은 모두 선택적인 출처입니다.

관리자는 기본적으로 **F7**로 엽니다. 단축키는 게임 옵션의 '묘상 고해상도 초상화'에서 변경할 수 있으며, 해상도와 이미지 선택 방식 등은 모드 설정에서 조정합니다.

- [초상화 사용 안내](Docs/立绘使用说明.md): 관리자 조작, 이미지 선택 방식, 사용자 지정 PNG, 가져오기 기능
- [설정 및 호환성](Docs/配置与兼容.md): 가중치, 체형 CSV, 이름·성별, 이미지 출처 지원 범위
- [개발 안내](Docs/开发说明.md): 소스 빌드, 회귀 검증, 유지보수 규칙

소스 코드는 `Source` 폴더에 있습니다. 소스를 빌드한 결과와 현재 설치된 DLL은 다를 수 있으며, 소스를 수정한 경우 다시 컴파일해야 반영됩니다.
