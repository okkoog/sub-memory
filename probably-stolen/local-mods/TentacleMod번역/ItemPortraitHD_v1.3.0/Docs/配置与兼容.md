# 설정 및 호환성

## 캐릭터와 이미지 가중치

일반 모드는 게임이 직렬화해 저장한 캐릭터 등록 목록에서 다섯 세력으로 분류할 수 있는 원본 캐릭터를 사용합니다. 실행 중 새로 추가된 키나 별칭이 무작위 캐릭터 목록을 늘리지는 않지만, 추가 이미지를 수동으로 선택하는 것은 가능합니다.

상층·하층 구역, 치안부, 암시장, 혁명군은 캐릭터 키를 기준으로 분류합니다. `_scav`는 하층 구역으로만 취급하며 `eleanor`, `serpico`와 그 변형은 제외합니다. 요리사, 엔지니어, 농부, 의료인, 과학자, 광부처럼 두 구역에 공통인 직업은 상층과 하층에 각각 **0.5**씩 반영합니다.

이미지 가중치는 **0~10**, 기본값은 **1**입니다. 0은 선택하지 않음을 뜻합니다. 연결된 교체 이미지가 있다면 해당 캐릭터의 실효 가중치는 교체 이미지들의 가중치 합계가 됩니다. 교체 이미지가 없을 때만 게임 캐릭터 자체의 개별 가중치를 사용합니다. 캐릭터가 선택된 다음에는 해당 캐릭터에 연결된 이미지들 사이에서 가중치에 따라 이미지를 고릅니다. 여러 팩이 같은 캐릭터의 이미지를 교체한다고 캐릭터 수 자체가 늘지는 않습니다.

'초상화 수에 따라 포획 가중치 조정'을 켜면 세력별 실효 캐릭터 가중치 총합을 기준으로 세력을 뽑습니다. 끄면 원본 모드의 세력 선택 방식을 따르지만, 세력 내부의 캐릭터 및 이미지 가중치는 여전히 적용됩니다.

'최종 적용 초상화' 모드의 대체 캐릭터 목록은 캐릭터마다 가중치 **1**, 공통 직업은 구역당 **0.5**로 고정되며, 개별 캐릭터 가중치는 무시합니다. 다만 먼저 적용되는 체형별 지정 출처 및 PNG는 자체 가중치를 사용합니다. '고해상도 재구성만' 모드에서는 원본 모드가 이미지 선택을 모두 담당합니다.

관리자에서는 분류 가능한 사용자 지정 이미지와 연결 관계가 확인된 원본 다섯 세력 캐릭터만 가중치를 조정할 수 있습니다. 최종 이미지 출처, 알 수 없는 캐릭터, 추가 아이콘은 수동 사용은 가능하지만, 식별됐다는 사실만으로 무작위 가중치를 바꿀 수 있게 되는 것은 아닙니다.

## 체형 및 이전 설정

체형 이름과 순서는 소스 코드 `AdultBodySources.Bodies`와 설정 안내를 기준으로 합니다. CSV는 **배열 내 위치**에 따라 대응하며, 오래전에 설치한 DLL의 목록을 소스 코드의 기준으로 사용해서는 안 됩니다.

- `body_weights_csv`: 체형 내부의 상대 가중치입니다. 음수가 아닌 소수를 사용할 수 있지만 모든 값이 0이어서는 안 됩니다. 뒤에 빠진 값은 **20**으로 채웁니다.
- `scavenger_double_virgin_csv`: 체형마다 별도로 지정하는 이중 처녀 확률입니다. 범위는 **0~100%**이며, 합계가 100이 될 필요는 없습니다. 뒤에 빠진 값은 **60**으로 채웁니다.

서식 오류, 잘못된 숫자 또는 너무 많은 항목은 기존 규칙에 따라 기본값으로 되돌립니다. 성인 체형 가중치는 해당 체형 묶음 내부의 비율만 바꾸며, 전체 비중과 나머지 체형 확률은 원본 모드의 분포를 유지합니다. 이중 처녀 확률은 폐품 수집으로 생성된, 설정 목록에 속하는 새 캐릭터에만 적용됩니다.

예전의 개별 확률 설정은 CSV가 아직 없을 때만 이전 방식에서 이전합니다. 기존 읽기 및 이전 방식은 계속 유지합니다. 향후 체형을 추가할 때 **목록 맨 뒤에 추가**하면 누락된 값을 기본값으로 채울 수 있습니다. 중간에 끼워 넣거나 순서를 바꾸면 기존 CSV의 대응 관계가 어긋나므로 별도 처리가 필요합니다. 체형별 이미지 출처 설정도 기존 위치 인덱스로 저장합니다.

체형에 따른 가슴 크기 적용 기능은 별도의 **5단계 규칙**을 사용하며, 설정 가능한 성인 체형 목록과는 데이터 범위가 다릅니다. 이 옵션을 끄면 원본 모드의 독립적인 가슴 크기 분포를 복원하며, 두 목록을 하나로 합치지 않습니다.

## 이름과 성별

'새로 생성되는 아이템의 초상화 범위'는 여성만 또는 성별 제한 없음으로 설정할 수 있습니다. 폴더에 있는 PNG의 성별을 파일명으로 추정하지 않습니다. 원본 모드 아이템이 작용하는 성별과 일반 고객 여성화는 각각 독립된 옵션이며, 기존 캐릭터의 게임 내 성별을 변경하지 않습니다.

게임 기본 고객과 모드 고객은 이름 변경 보호가 따로 적용되며, 이미지 팩이 아니라 게임에 기록된 고객의 출처를 기준으로 판단합니다. 원본 모드의 이름 변경만 차단할 뿐, 이미 바뀐 이름을 되돌리지는 않습니다.

지역별 이름 제한은 이후 생성되는 이름에만 적용됩니다. 기존 이름이나 재사용 이름 목록에 들어 있는 이름을 다시 쓰지 않습니다.

## 이미지 출처별 호환 범위

| 출처 | 연동 방식 |
| --- | --- |
| 게임 및 모드에서 공개한 Sprite 사전 | 공개 이미지를 읽습니다. 수동으로 사용할 수 있으며, 매핑 기준에 맞는 원본 캐릭터는 일반 무작위 선택에 참여합니다. |
| 심우주 전당포 여성 초상화 미화 | 원본 팩의 연결 관계를 읽습니다. |
| RetroAnime / RetroAnimeGirls | `portrait-map.csv`를 읽습니다. |
| 정교한 일본풍 초상화 `refined_anime_portraits` | `portraits.tsv`를 읽으며, 이름이 같은 이미지의 읽기 가능한 슬롯을 구별합니다. |
| AllGirls | `ApprovedCharacters.json`에서 승인된 기본 게임 캐릭터 항목을 읽습니다. |
| all_girls | 원본 팩의 Collect, 매핑 및 변형 선택 기능을 재사용하고 원본 PNG를 읽습니다. |
| probably_rimworld | 원본 팩의 매핑 파싱과 검증을 재사용하고 원본 PNG를 읽습니다. |
| 백사 및 R18 확장 | 내장 PNG를 읽고 본편의 캐릭터 매핑과 전신/반신 설정을 따릅니다. 매핑되지 않은 이미지는 수동으로만 사용합니다. |
| 기타 출처 | 최종 `GetSprite` 결과를 읽을 수 있습니다. 일반 출처 추적이 해당 출처를 알아낼 수 있는지는 접근 권한 선언과 이미지 교체 방식에 따라 달라집니다. |

실행할 때 필수 모드인 `lewd_meme`는 활성화해야 합니다. manifest에 기재된 다른 선행 모드 ID는 이미지 출처 접근 범위를 선언하기 위한 것으로, 해당 초상화 팩은 모두 선택 설치입니다. **전부 설치할 필요는 없습니다.** 이미지 작성자를 식별하지 못해도 '최종 적용 초상화' 모드와 '고해상도 재구성만' 모드에서는 실제 이미지를 사용할 수 있습니다.

출처 팩의 전용 인터페이스는 업데이트에 따라 변경될 수 있습니다. 정적 회귀 검사는 인터페이스와 알고리즘을 확인하지만 실제 게임에서 새 캐릭터 생성·저장 파일 불러오기·화면 표시까지 대신 확인해 주지는 않습니다.
