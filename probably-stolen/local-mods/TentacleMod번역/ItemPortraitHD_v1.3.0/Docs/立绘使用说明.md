# 초상화 사용 안내

## 관리자

기본 단축키 **F7**로 관리자를 열거나 닫습니다. 단축키를 바꾸려면 게임 옵션의 '묘상 고해상도 초상화' 항목에서 단축키 버튼을 누르세요. 키 입력 감지와 Esc를 이용한 취소는 게임 자체 기능을 사용하며, 모드 설정의 `hotkey` 문자열에는 기존 값이 계속 저장됩니다.

왼쪽 목록에서는 현재 계산대와 창고 등 아이템 보관함 및 폐품 수집 목록을 하위 컨테이너까지 재귀적으로 검색합니다. 닫힌 하위 보관함도 조회할 수 있습니다. 판매 완료 아이템 구역과 고객 전시 목록은 제외됩니다. 이름이나 아이템 번호로 검색할 수 있으며 저장 파일을 불러오면 선택 상태는 초기화됩니다.

왼쪽에서 아이템을 선택한 뒤 오른쪽에서 원하는 출처의 이미지를 클릭하면 적용됩니다. 출처 및 검색 조건은 후보 이미지만 걸러 냅니다. 수동 선택은 해당 아이템에만 기록되고 다른 아이템에는 영향을 주지 않으며, 일괄 무작위 선택도 실행하지 않습니다.

'선택한 아이템의 원래 초상화 복원'을 누르면 이전에 저장된 원본 이미지 출처를 먼저 검증하고, 확인에 성공했을 때만 수동 덮어쓰기를 해제합니다. 해당 출처가 없으면 현재 선택을 유지하며 이유를 알려 줍니다. 원본 팩이나 이미지가 실제로 삭제됐다면 해당 리소스를 복구해야 합니다.

모든 묘상은 **완전한 4×4칸 점유 공간과 클릭 영역**을 사용합니다. 오래된 아이템이 공간 부족으로 들어가지 않으면 계산대나 창고로 옮기려고 시도합니다. 그래도 공간이 부족하다면 먼저 자리를 비워 주세요. 넘치는 아이템을 삭제하는 방식으로 처리하지 않습니다.

## 자동 초상화 선택 방식 세 가지

| 설정 | 동작 |
| --- | --- |
| 일반 모드: 호환 옵션 두 개 모두 끔 | 이 모드의 다섯 세력 캐릭터 목록, 교체 이미지 출처, 개별 가중치를 사용합니다. 체형별 출처와 사용자 지정 PNG도 지원합니다. |
| 고해상도 재구성만: 이미지 선택은 전적으로 원본 모드에서 | 가장 우선하는 모드입니다. 이 모드의 자동 이미지 선택을 모두 중단하고, 원본 모드가 고른 이미지를 실제 이미지 기준으로 재구성합니다. 출처를 모르는 이미지도 처리할 수 있습니다. 수동 교체와 4×4칸 점유는 유지됩니다. |
| 최종 적용 초상화만을 기준으로 선택 | 체형별 지정 출처와 사용자 지정 PNG를 먼저 처리한 뒤, 고정된 캐릭터 가중치로 인물을 선택하고 게임 `GetSprite`가 반환하는 최종 이미지를 읽습니다. 출처를 미리 검색하거나 식별할 필요가 없습니다. |

설정 변경은 앞으로 생성되는 이미지 선택에만 적용되며, 기존 캐릭터를 다시 무작위로 바꾸지 않습니다. 고객은 계속 원본 모드에서 이미지를 선택합니다. '고객 목록에서 선택된 초상화 고해상도 표시'를 켜면 실제 선택된 이미지에 대해서만 고해상도 재구성을 수행하며, 해당 이미지를 포획 가중치에 추가하지 않습니다.

## 사용자 지정 PNG

폴더 구조는 `Portraits/출처명/세력명/이미지.png`입니다. 세력으로는 상층 구역, 하층 구역, 치안부, 암시장, 혁명군, 세력 제한 없음을 사용할 수 있습니다. 세력 폴더 안에 하위 폴더를 더 만들어도 됩니다.

출처명은 관리자에 '사용자 지정 / 출처명'으로 표시됩니다. 출처마다 가중치를 따로 설정하거나 특정 체형에 지정할 수 있습니다. 세력 제한이 없는 이미지는 다섯 세력에 각각 1/5의 가중치를 제공합니다. 세력별로 분류되지 않은 PNG는 수동 선택에만 사용할 수 있습니다.

'폴더 초상화 교체 확률'의 기본값은 **0%**입니다. 체형에 사용자 지정 출처를 직접 연결하면 이 확률을 건너뜁니다. 특정 이미지 교체 팩을 지정한 경우 일반 PNG 선택 확률이 먼저 적용되지 않습니다. 최종 적용 모드에서 지정 출처를 찾지 못하면 PNG 또는 최종 이미지로 대체할 수 있습니다.

파일 형식은 PNG여야 하며, 한 변의 크기는 **1~4096픽셀**, 파일 용량은 **32MB 이하**여야 합니다. 출처를 인식했다고 반드시 다섯 세력의 무작위 선택 목록에 들어가는 것은 아닙니다. 자세한 기준은 [설정과 호환성](配置与兼容.md)을 참고하세요.

## 이미지 가져오기

'초상화 가져오기' 페이지에서 원본 출처, 이미지, 대상 사용자 지정 출처와 세력을 선택한 뒤 확인합니다. 현재 **128/256 해상도 설정**에 맞춰 전처리한 뒤 저장합니다. 이미지 내용의 해시값을 기준으로 중복을 제거하며, 원본 팩의 이미지를 변경하지 않습니다. 게임 기본 이미지와 이미 있는 사용자 지정 PNG는 가져오기 대상에 포함되지 않습니다.

가져온 결과는 현재 캔버스를 유지합니다. 이후 화질 설정을 바꾸면 같은 결과의 크기만 바뀝니다. 원본에서 더 선명한 세부 묘사를 다시 얻으려면 목표 해상도에 맞춰 새로 가져와야 합니다.

## 새로고침과 문제 해결

PNG를 추가하거나 이동했거나 출처 팩이 변경됐다면 '이미지 다시 불러오기'를 누르세요. 백사 모드의 전신/반신 설정을 바꾼 뒤에도 다시 불러와야 합니다.

'일반 출처 스캔'은 프레임마다 최종 이미지를 검사하며, 관리자를 닫으면 일시 정지합니다. 일반 추적 옵션을 꺼도 최종 결과는 검색할 수 있습니다. 이미지 작성자를 식별하지 못하면 '알 수 없는 출처'로 표시되지만 수동으로 사용할 수 있습니다.

처음 디코딩하거나 이미지를 자르고 크기를 바꿀 때는 처리 비용이 발생하며, 이후에는 캐시를 재사용합니다. 해상도를 바꾸거나 다시 불러오면 이전 변환 결과는 무효화됩니다. 원본 모드 등록부나 현재 화면에서 쓰는 이미지는 사용이 끝날 때까지 삭제를 미룹니다. 미리보기의 **192개**는 소프트 제한이므로, 사용 중인 이미지 때문에 캐시가 이 수를 넘을 수 있습니다.

이미지 로딩에 실패하면 먼저 출처 팩 활성화 여부와 PNG 경로를 확인하세요. 이후 이미지를 다시 불러오거나 저장 파일을 재로드해 시도합니다. 로그에 이 모드의 변환 단계별 소요 시간 안내가 남습니다.
