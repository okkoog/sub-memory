# 후속 02 실행 준비

기존 TSV에서 직접 출력으로 확인한 일반 표시·설정·로그 15개 호출을 실제 DLL의 메서드/오프셋/원문/출력 함수로 검증하여 패치하도록 구성했다. 전 메서드 opcode/operand, 관리 리소스 비교 및 ZIP CRC 검증 통과 시에만 반영한다. D 575개는 실제 DLL의 해당 메서드, 호출자, 필드 소비자 및 직접 피호출자 IL을 확보한 뒤 판정한다. 이 파일 자체는 실행 성공 또는 번역 완료를 의미하지 않는다. 실행 결과는 후속02/patch_result.json 및 IL_*.json에 기록된다.
