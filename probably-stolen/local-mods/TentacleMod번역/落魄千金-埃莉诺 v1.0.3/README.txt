몰락한 영애 엘리너 (Fallen Heiress - Eleanor) v1.0.3

제작자: 不问世事
선행 모드: 아마도 성인용품 v1.1.0 정식판 (probably_adult_goods)

■ 설치
1. 모드 폴더 전체를 Probably Stolen\Mods\에 넣습니다.
2. 게임 실행 후 모드 목록에서 '몰락한 영애 엘리너 / Fallen Heiress - Eleanor'를 활성화합니다.
3. Mods 폴더에 이전 정식판 Mods\落魄千金-埃莉诺가 남아 있으면 삭제하거나 다른 곳으로 옮기세요. 같은 ID의 폴더 두 개가 있어도 하나만 로드됩니다.
4. 개발판 '落魄千金-埃莉诺（开发版）'가 활성화돼 있으면 먼저 끄세요. 두 버전을 동시에 사용할 수 없습니다.

■ 파일 구성
- fallen_heiress_eleanor.dll: 캐릭터 그림, 아이템 이미지, 중국어·영어 대사를 내장합니다. 별도의 Localization 또는 Textures 폴더가 필요 없습니다.
- manifest.xml: 게임이 모드를 식별하는 목록 파일로, 숨겨져 있을 수도 있습니다. 삭제하거나 이름을 바꾸면 게임 모드 목록에서 사라집니다.
- README.txt: 이 안내서입니다.
- 한국어 수정 DLL에서는 원본 zh/en을 유지하고 ko 언어용 리소스와 등록 코드를 별도로 추가했습니다.

■ 기존 저장 파일에서 처음 사용할 때
- '기존 저장 파일에서 처음 사용할 때 엘리너 이야기 초기화를 물어보기' 옵션은 기본적으로 켜져 있습니다. 설정 → 스토리에서 끌 수 있습니다.
- 엘리너 진행 기록이 있는 기존 저장 파일에서 이 모드를 처음 켜면 이야기를 초기화할지 묻습니다.
- '예': 현재 이야기 상태를 지우고 다음 날 원본 줄거리 마지막의 순애/군 유흥업소 선택지로 돌아갑니다.
- '아니요': 현재 진행을 유지하고 다시 묻지 않습니다.
- 새 저장 파일에서는 이 질문이 나오지 않습니다.

■ 언어
- 중국어 게임 환경의 원본 모드명: 落魄千金-埃莉诺
- 그 밖의 원본 언어 설정에서 모드명: Fallen Heiress - Eleanor
- 원본 대사는 중국어일 때 zh, 다른 언어일 때 en을 내장 리소스에서 읽습니다. 한국어 수정 DLL은 ko/ko-KR을 추가합니다.

■ 게임 내용(스포일러 포함)
- 사고: 원본 Eleanor4 사건에서 50크레딧을 주면 엘리너가 작은 장난감을 답례로 줍니다. 보석금 경로로도 진행할 수 있지만 아이템 보상은 없습니다.
- 자유와 감금: 원본 Eleanor9 사건을 중간에서 가로채 분기합니다.
  - 행적을 누설하면 유흥업소 경로
  - 물건을 돌려주거나 보석금을 내주면 순애 경로(와일드)
- 새집: 두 경로가 다시 하나로 합쳐집니다. 가게에서 함께 살면서 먹을거리 제공, 대화, 옷 갈아입기, 상점 운영 지원, 손님 상대, 친밀감, 일기, 밤 외출 등의 상호작용이 추가됩니다.

■ 알려진 사항
- 원본 안내서에는 'v1.0.1에서 아직 미작성'이라고 기재된 비활성 항목이 있습니다. 특수 캐릭터 서비스, 평가, 보고 등 개발 중인 내용은 실행할 수 없으며 주 줄거리에는 영향을 주지 않는다고 설명합니다.
- 목록에 모드가 나타나지 않으면 manifest.xml의 존재 여부와 Mods 바로 아래에 폴더가 있는지 확인하세요. 같은 이름의 폴더를 한 겹 더 만들지 마세요.
