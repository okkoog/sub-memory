■ 설치
1. 원본 모드 폴더 전체를 Probably Stolen\Mods\에 넣습니다.
2. 게임을 시작해 모드 목록에서 「Fallen Heiress - Eleanor」를 활성화합니다.
3. Mods 안에 이전 정식판 폴더(Mods\落魄千金-埃莉诺)가 있다면 먼저 삭제하거나 다른 곳으로 이동합니다. 같은 모드 ID를 가진 폴더는 하나만 불러옵니다.
4. 개발판 「落魄千金-埃莉诺（开发版）」이 활성화돼 있다면 끕니다. 정식판과 개발판은 함께 활성화할 수 없습니다.

■ 원본 패키지 구성
- fallen_heiress_eleanor.dll: 캐릭터 초상화, 아이템 이미지, 중국어·영어 문구가 DLL에 내장돼 있습니다. 별도의 Localization 또는 Textures 폴더가 필요하지 않습니다.
- manifest.xml: 게임이 모드를 식별하는 필수 파일입니다. 삭제하거나 이름을 변경하면 모드 목록에 표시되지 않을 수 있습니다.
- README.txt: 원본 안내문입니다.

■ 기존 저장 파일에서 처음 사용
- 기본적으로 설정 → 「스토리」 → 「기존 저장 파일에서 처음 사용할 때 스토리 초기화 확인」이 켜져 있습니다.
- 엘리너 관련 진행 기록이 있는 저장 파일에서 이 모드를 처음 활성화하면 스토리를 초기화할지 묻는 창이 나타납니다.
- 「예」: 현재 엘리너 스토리 진행을 지우고 다음 날 기본 게임 후반부의 순애/군 매춘 분기 선택을 다시 배치합니다.
- 「아니요」: 현재 진행 상태를 유지하고 다시 묻지 않습니다.
- 새 저장 파일에서는 이 질문이 나타나지 않습니다.

■ 언어
- 원본 DLL은 중국어(zh)와 영어(en)만 내장하고, 그 외 언어에는 영어를 사용합니다.
- 이 한국어 시험 DLL은 별도의 ko 리소스를 추가하고 Localization의 ko 등록 분기를 추가했습니다. 원본 zh/en 언어 리소스를 바꾸지 않고 한국어 선택 시 한국어 문구를 쓰도록 정적 수정한 형태입니다.
- 내장 1,839키 중 실제 문구 1,553키를 한국어로 번역했으며, 원본 영어에서도 내용이 없는 개발 중 자리표시자 286키는 그대로 유지했습니다. 이 286키에 한국어 대사를 임의로 만들어 넣지 않았습니다.
- 언어 분기와 내부 리소스의 정적 검증과 실제 Unity/게임 실행 검증은 별개이며, 현재 실제 게임·세이브·다른 모드와의 호환성 검증은 미실시입니다.

■ 주요 이야기 (스포일러)
- 사고: 기본 게임의 Eleanor4 단계에서 엘리너에게 크레딧 50을 주면 답례로 작은 장난감을 받습니다. 보석금을 내는 경로로도 스토리에 진입할 수 있지만 그 경우 아이템을 받지 않습니다.
- 자유와 감금: 기본 게임의 Eleanor9 단계에 개입합니다.
  · 행방을 누설하면 매춘 루트로 진행합니다.
  · 그녀를 돌려보내거나 보호하면 순애 루트(王尔德)로 진행합니다.
- 새로운 집: 두 루트가 다시 합쳐진 후 엘리너가 가게에서 생활합니다. 먹을 것 제공, 대화, 의상 교체, 업무 지원, 서비스, 친밀도, 일기, 야간 외출 등의 상호작용이 추가됩니다.

■ 알려진 사항
- 원본 README는 v1.0.1을 기준으로 일부 특수 캐릭터 서비스/평가/보고 기능이 미작성 상태이며 개발 중 비활성화돼 있어 본편 진행에 영향이 없다고 설명합니다. 이 표기가 v1.0.3에서도 그대로 유지돼 있으므로 현재 구현 상태는 확인이 필요합니다.
