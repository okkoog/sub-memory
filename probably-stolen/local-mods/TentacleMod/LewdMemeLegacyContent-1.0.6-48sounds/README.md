# 淫色深空：可能更有互动 1.0.6

作者：今夜不能寐

## 前置

必须同时安装并启用 `lewd_meme`。本模组只补充内容层，不替代主模组。

## 内容

- 角色标签、性格、敏感带和偏好。
- 阶段描述、阵营描述、双击对话和旧版夜报。
- 双击成年契约者时，随机播放一段娇喘表示互动成功。
- 气泡不再播放原版逐字打字音效。
- 双击浮动气泡保持原对话气泡的像素缩放，修复部分文字发虚。
- 在女性角色和触手本体提示中追加状态。
- 使用乳汁、精液、排卵诱发剂与触手本体文案。

## 设置

- 在游戏“模组”菜单选中本模组，点齿轮按钮进入设置，可开关“显示旧版夜报”。
- **默认关闭**：本模组不再显示自己的夜报窗口，也不会替换主模组夜报，避免与其他模组的夜报叠加后超出窗口。
- 设置按模组保存在游戏配置目录，对所有存档共用。

## 1.0.6

- 兼容其他子模组：不再改写主模组现有物品（乳汁、精液、排卵诱发剂、触手本体）和人物（少女）的名字。
- 不再覆盖主模组的势力、体型、乳量词条；本模组自己的内容改用 `LEGACY_LC_*` 与自有展示标签保存。
- 本模组新增的阶段描述、提示与互动内容保持不变。

## 1.0.5

- 清单作者显示修正为“今夜不能寐”，与玩家说明一致。
- 内容与设置与 1.0.4 相同。

## 1.0.4

- 新增“显示旧版夜报”开关，默认关闭。
- 关闭时保留夜间数值结算（发情、绝顶、产奶等），只是不再显示旧版夜报窗口。
- 玩法内容、音效与 1.0.3 相同。

## 1.0.3 适配

- 适配 0.46D Rev13 的模组约束：改为直接引用前置模组 `lewd_meme` 的程序集，并用游戏提供的 `ModReflect` 校验补丁目标。
- 清单不再声明 `reflection-external` 能力；启用时不会出现“下一次游戏更新将拒绝的能力”提示。

## 存档

不新增或替换物品 ID。子模组停用后，主模组物品仍保留；本模组写入的附加标签和 `lewd_meme_legacy_content` 模块数据不会在普通停用时自动清除。

## 说明

主模组更新后，如本模组报告“挂接旧版内容补丁失败”，请优先核对主模组版本，而不是替换主模组 DLL。
