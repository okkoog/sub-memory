# 精简与兼容性审查

2026-11-17；暗流交易 1.6.4；前置 lewd_meme 1.9.2。本文只描述当前结果，历史长报告和旧验证已归档。

## 已落实

| 范围 | 当前结果 |
| --- | --- |
| 夜间活动 | 删除自有随机次数、偏好/疲劳倍率、破处回避，不再调用 Train 重做原版活动 |
| 夜间产物 | 原版先生成；每份自有乳汁先扣一瓶原版乳汁，无瓶则扣神奇乳汁桶一次，无来源也产出；优先补同类桶，失败回退 |
| 透支 | 角色入口跳过整段原版结算；活动、双方产出及全部孕育暂停，每夜仅恢复 5 点；不重算历史计数 |
| 疲劳 | 本体、开启结算的箱内、闹钟及开启的陷阱共用计数增量公式；其它位置每天恢复 25；透支在设备内只恢复 5；删除破处额外疲劳及状态快照 |
| 等级 | 移除本模组 5 级上限，兼读原版高等级存储；1～10 级采用指定系数表，11 级起零增长 |
| 桶装 | 结算后扫描整个产出区，支持堆叠；原版与自有神奇乳汁合并计数，乳汁阈值 3、精液 8；四开关只控制新建，已有桶始终可补充 |
| 箱内角色 | 在全体主苗床循环后、经验与原版报告前统一调用原版 NightlyTick；箱内全部存储页参与，主苗床区为空也结算；角色去重 |
| 设备 | 删除闹钟自有准入/补训练、陷阱屏蔽计数及精液概率覆盖；保留疲劳与透支门禁，正常活动让原版处理 |
| API/状态 | 删除自有夜间/分区公开 API、产物快照及重复网格引用缓存；保留内部按游戏存储读取的分区适配 |
| 孕育与立绘 | 复用原版受孕、分娩、女儿判断和立绘；旧女儿标识读档补齐，治安部线用原版 IsDaughter |
| 治安部奖励 | 保留剧情登记键，依据已完成节点恢复奖励；修复新物品先检查后补等级及读档只跳过未补登的问题；精液桶同享 II 级管制 |
| 生命周期 | 此前已取消重复 PatchAll，动态补丁按 owner 撤销，电话名称修改限制在自有联系人 |
| 名册 | 复用纸书工厂，关闭成交仅记账，数据变化时再构页；删除重复物品创建与图标兜底 |
| 用量与文档 | 桶装复用 UseCountHelper；指南集中 docs，根目录只保留 README 说明，清除失效报告及重复旧测试 |

夜报分开统计“本夜追加乳汁”与“库存装桶”，装桶不再冲减本晚产量。未达到阈值或关闭新建时保留瓶装，不报成创建失败。

原版乳汁未入桶反馈：确认旧自动扫描仅匹配 `milk_wondrous`，漏掉 `wondrous_milk`；现复用手动充能的来源判断，二者合计装入神奇乳汁桶。旧版在新增原版三瓶装桶回归中失败。未触发自有产乳时仍整理原版产出，原版夜报生成量与自有产量保持各自统计；没有读取反馈者存档或核验其截图现场。

箱内未结算反馈的摆放位置未经确认，尚不能断定玩家现场根因。代码检查确认旧实现依赖单页 Tick postfix、只读箱内第一个存储页；本轮消除回调依赖并扩为全部页，补充完整 SettleAll 检查。原版夜报继续记录其生成量，不回写成扣除替换后的库存量；同一神奇乳汁桶先扣再补时次数净变化为 0。

治安部登记奖励未在精简中删除；对照 1.5.29 备份，依赖物品已有违禁标签的早退已存在。当原版工厂未挂标签或旧物品只有解锁状态时，会漏掉管制属性。现统一补齐等级后调用原生管制转换，旧档首开门重施；节点 3/4/5 分别兜底排卵针/精液/苗床奖励，保留原有独立登记键，不重发剧情或改任务条件。游戏普通交易使用原生加价，本模组收购商保留独立估值公式。

## 仍保留的干预及取舍

当前静态清单为 **26 个不同 Hook 目标（游戏 15、前置 11），7 个 transpiler**；较 1.5.29 减少 2 个目标、1 个 transpiler。主要收益是删除整段活动/产物替换，钩子数量仍受既有交易与设备门禁需求影响。

| 范围 | 保留原因 |
| --- | --- |
| 原版 NightlyTick / SettleAll | 事前透支门禁、事后追加、箱内角色接入及实际经验人数；原版没有等价的取消/完成事件 |
| 设备 4 个入口 | 透支时拦截角色活动及产出，并让闹钟功能与报告使用一致资格；正常计数和概率不改 |
| 本体 BuildWindow / EnsureLayout | 原地扩展便签区并放入两份说明，保留其它区域及旧物品 |
| 原版角色工厂与游戏物品目录 | 补自有偏好、估值、液体回调及剧情违禁属性 |
| 原版拾荒 | 仅移除原有 0.5 秒捕获限流，其余捕获条件与概率保留 |
| 收购商与交易 | 七个游戏交易入口及前置 GuestBox 过滤，用于单件验收、付款差额、追加收购和对话清理 |
| 游戏其它入口 | 犯罪/管制、小物件点击区、电话、保存前疲劳及次日电话同步 |

夜间补丁只在角色门禁和描述刷新等锚点验证后插入调用，不再要求整段指纹一致；其它模组在中间插入的指令可保留。锚点不匹配时撤销整组本体夜间补丁，退回原版并记录警告。设备补丁独立安装，日志分别报告状态。仍需用真实组合模组验证顺序和行为，不能据此宣称完全兼容。

已经接受的设计变化：正常夜间恢复原版强度与精液产率；追加乳汁优先抵扣原版乳汁并直接入桶；透支暂停孕育；偏好只保留文本；设备不再保留先前自有活动规则。旧剧情、交易、标识和物品数据保留。

## 后续仍可精简

- **图像资源生命周期**：名册/回执使用的 SpriteInjector 缓存、裁剪贴图和 PaperChromeIcons 生成图标仍在使用，尚未统一梳理自建 Texture2D/Sprite 的释放与缓存失效。没有删共享资源或承诺此项已解决。
- **纸书按钮与节点**：原生控件承担主要生命周期，尚未实机核对连续开关/翻页的节点释放。当前没有证据证明按钮已泄漏；不应把可能的改善写成已确认故障。
- **交易干预**：若接受完全改用对话交付，可进一步撤掉多处交易 UI Hook；本轮未改交易设计。
- **便签区及拾荒**：若接受手动取得说明、恢复原版捕获限流，可再撤对应前置 Hook；本轮仍保留现有玩法。
- **内部状态**：仍需少量本体枚举、分区读取和附加报告状态，不能因删除公开分区 API 就声称不再读取分区。

原版分娩失败后的待产处理、女儿立绘继承与保存恢复使用原版现状，本模组不再加独立修补。前置指南没有提供分娩后处理、窗口扩展或特殊客人过滤的完整替代入口。
