# 开发指南

适用：暗流交易 1.6.4，核验前置 lewd_meme 1.9.2。

## 构建与发布

在 `Mods` 目录执行：

```powershell
dotnet build './LewdMemeShadowTrade/Source/MidnightPawn.csproj' -c Release
```

项目引用游戏 `Probably Stolen_Data/Managed` 和 `Mods/lewd_meme1.9.2/MidnightPawn.dll`，可通过 MSBuild 属性 `GameManaged`、`OriginalModAssembly` 覆盖路径。前置引用使用 `OriginalMod` 别名，不复制进发布包。

`Directory.Build.props` 将 bin/obj 放在系统临时目录的 `lewd_meme_remake-build` 下，实际产物路径见构建输出。发布时同步 manifest 版本和 AssemblyInfo，将候选 `ShadowTrade.dll` 复制到模组根目录；不要把测试 DLL、前置 DLL 或编译中间文件放入包内。

声明式 Harmony 补丁交给加载器安装。动态兼容补丁在物品目录初始化、加载器登记本模组后安装；跨模组反射限于声明前置的 `ModReflect` 范围，停用时按 owner 撤销。

## 数据和旧档

| 类型 | 继续使用 |
| --- | --- |
| 模组与大部分自有数据命名域 | `lewd_meme_remake` |
| DLL 文件名、AssemblyName | `ShadowTrade` |
| C# 命名空间 | `MidnightPawn`、`MidnightPawn.Game`、`MidnightPawn.Api` |
| 自有乳汁 | `milk_wondrous`、`milk_rich`、`milk_diluted` |
| 桶装 | `barrel_semen` 及三种 `barrel_milk_*` |
| 旧说明物品及图像标签 | `tentacle_manual_remake`、`MILK_REMAKE_OWN_SPRITE` |
| 原版本体等级、经验与女儿标识 | 读取原版；旧自有值按需迁移，女儿补齐 `MAIDEN_DAUGHTER` |

`remake` 仍用于旧标识、资源标签和构建临时目录，保留它们有助于旧档识别。当前使用四个 `auto_barrel_*` 配置键，以及角色标签 `SHADOWTRADE_EXHAUSTED_REST_DAY`，用于同夜透支恢复去重。旧产物倍率及破处回避配置不再读取，无需删玩家配置文件。

当前存储没有要求按旧程序集名反序列化自有角色对象的路径。文件名与 AssemblyName 同改后，已有物品及数据仍按 ID/键读取；外部扩展若静态引用 `MidnightPawnRemake`，必须改引用并重编译。此判断有代码和受控检查支持，尚无真实旧档重载验证。

治安部奖励保留 `liaison_reg_ovulation`、`liaison_reg_semen`、`liaison_reg_maiden` 三键；也分别接受 `liaison_stage >= 3 / 4 / 5`，其值代表下一个剧情节点。登记统一补齐原生违禁等级，再用 `PermitHelper.SetRestrictedClass` 与 `ContrabandHelper.RemoveContrabandStatus` 转为管制品；游戏承担加价。读取旧档时在既有首开门修复中重施奖励，新建物品、原版势力工厂及直接创建的精液桶也处理；无新增 Hook。剧情交货仍只接受瓶装精液。

## 扩展接口

**已删除** `NightlySettlementApi`、`NightlySettlementContext`、`BodyZoneInfo`、`TentacleBody.GetZoneInfo`。自有活动倍率、受孕倍率、产物倍率、破处回避及旧无效设置辅助入口也已删除。没有兼容空壳，依赖这些入口的外部插件需要迁移。

训练、统计、女儿判断、本体等级/经验与普通安全投递使用前置 `MidnightPawn.Api.TentacleApi`。应以实际 DLL 和前置目录的《子模组接入指南.md》为准。本机 1.9.2 DLL 的等级接口仍封顶 5，本模组取公开接口与原版 `body_lv` 存储的较大值，不设等级上限；原模组文件不修改。新版公开接口返回更高等级时直接支持。

疲劳快照只读取原版行为计数与入夜孕态，不订阅破处事件、不保存处女状态、不追加固定事件疲劳。所有设备使用同一等级系数表；系数为 0 时直接返回 0，绕过最少 1 点的正增长兜底。场外恢复排除本体、开启箱内结算的直接苗床箱、闹钟和开启的陷阱，按日去重。

`OnMaidenTrained` 在原版活动之后、孕育和产出之前触发，不能承担事前透支拦截或事后装桶。本模组因此保留少量插入式 Harmony 补丁；正常活动与孕育指令逐条保留。

附加输入在 `SettleAll` 主循环结束后、经验与原版夜报之前统一调用原版 `NightlyTick`，不依赖单页 Tick 的 postfix。角色按轮次去重，侵蚀区直接苗床箱通过游戏 `GetBodyStorage` 读取全部存储页，疲劳区域判断使用同一收集方法。箱内只追加一层，不递归其它容器。

自有乳汁逐份先扣原版瓶装、再扣现有神奇乳汁桶次数，优先直接补同类桶。用量复用 `UseCountHelper`；最后一瓶/不同品种的空源桶通过原生 `Expel` 暂时移出，成功后销毁，失败用 `UncheckedAccept` 将同一对象按原格位恢复。堆叠与桶次数也恢复原值，不创建替代源物品；同一源桶兼作目标桶时先扣再补，避免最后一次被提前销毁。

夜末装桶与手动充能共用 `ItemFactory.IsBarrelSourceItem`：`milk_wondrous` 和原版 `wondrous_milk` 合并计数，达到 3 份才新建神奇乳汁桶；其它品种各自匹配。原版产出保留，未被追加乳汁抵扣的瓶装仍参与装桶，已有桶不受新建开关和阈值限制。

独立 **TooltipApi** 保留。引用 `ShadowTrade.dll` 后订阅：

```csharp
MidnightPawn.Api.TooltipApi.BuildTooltip += context =>
{
    // context.Item、context.Builder、context.Section
};
```

该事件逐段触发，每个订阅者异常单独捕获。可用段包括 Body、CorruptTentacle、TentacleBox、Barrel、Maiden、Other。自行订阅的扩展应在卸载时退订。

## 验证入口

当前维护的检查集中在 `Mods/.compat-audit/shadowtrade/`，不随模组运行。构建后用候选 DLL 路径运行：

```powershell
pwsh -NoProfile -File './.compat-audit/shadowtrade/test-nightly.ps1' -Candidate '<候选 DLL 的绝对路径>'
pwsh -NoProfile -File './.compat-audit/shadowtrade/test-ledger-barrel.ps1' -Candidate '<候选 DLL 的绝对路径>'
pwsh -NoProfile -File './.compat-audit/shadowtrade/test-contracts.ps1' -Candidate '<候选 DLL 的绝对路径>'
pwsh -NoProfile -File './.compat-audit/shadowtrade/scan-package.ps1' -Package '<模组目录绝对路径>' -DllName 'ShadowTrade.dll'
```

检查直接执行候选程序集、原版角色循环及完整 SettleAll 变换后的 IL 与原生用量方法，替换场景、资源、随机数、经验入账和投放边界。完整入口执行真实 prefix/postfix/finalizer 方法，但不在 PowerShell 中安装原版 Harmony 运行时 detour。测试不写玩家存档；受控执行不等同 Unity 实机。当前结果和文件散列见该目录，待实机项目见审查报告。
