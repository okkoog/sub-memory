# 玩法指南

适用：暗流交易 1.6.4 / lewd_meme 1.9.2。

## 夜间结算

正常角色先运行原模组的活动、计数、互动刷新、事件、排卵、受孕、孕期、分娩及原有乳汁和精液产出，再追加自有乳汁和疲劳。追加乳汁按下述规则扣除原版乳汁，精液不受影响。

入夜疲劳达到 90 时，该角色整个夜间区段暂停：没有活动、双方产出、排卵或受孕判定，已有孕期不增加，也不分娩；疲劳恢复 5 点。即使恢复后低于 90，当晚仍暂停，同日重复进入不会再次恢复。未透支角色不修改原版活动或受孕计算；当晚活动使疲劳升至 90，不取消已进行的活动和本晚产出。

只有参与原版本体结算的角色推进孕期。场外不做全局推进；女儿生成、立绘、投放及失败处理使用原版实现。

“侵蚀区苗床箱参与夜间结算”默认关闭。开启后，只处理直接放在本体侵蚀区的 `tentacle_box` 内角色，读取箱内全部存储页，调用同一个原版循环，使用所属本体产出区，计入原版报告与经验；主苗床区为空也参与，角色按轮次去重。其它容器、其它分区和更深层箱子不参与。透支角色不获得本轮本体经验。

闹钟和陷阱恢复原版活动与精液规则，不追加自有乳汁；只附加疲劳与透支门禁。闹钟不再要求先解除两种处女状态，陷阱不再屏蔽原版计数，设备也不再使用自定义精液概率。透支角色不启用对应闹钟功能或成功报告。捕获、设备每日去重及其它外围效果沿用原版。

## 三种追加乳汁

角色泌乳等级至少为 1 或处于怀孕状态时，追加下表对应品种：

| 乳量 | 物品 ID | 基础概率 | 固定单价 |
| --- | --- | --- | --- |
| 贫乳 | `milk_rich` | 30% | 150 |
| 普乳及其它 | `milk_wondrous` | 50% | 80 |
| 巨乳 | `milk_diluted` | 70% | 50 |

泌乳等级从 2 起，每级增加 30 个百分点。概率整数部分保证相应瓶数，小数部分判定额外一瓶；空间不足则停止。泌乳等级不提高单价。产物倍率设置已移除。

每份追加乳汁先从所属产出区扣除一瓶原版 `wondrous_milk`，按堆叠数量扣；没有瓶装则扣 `barrel_milk_wondrous` 一次。两者都没有也照常产出，不扣本模组的瓶装 `milk_wondrous`。先扣后产以释放空间，放置失败则退回所扣原物品或次数。

产出优先直接补入已有同类桶，满桶后尝试下一个桶，全部满了才放瓶装；没有桶则先瓶装，整轮结束后才按阈值新建桶。当扣除与补入都是同一个神奇乳汁桶时，次数净变化为 0，追加产量仍记 1。这里的神奇乳汁桶沿用现有桶 ID，因为原版没有独立的另一种桶。

## 疲劳与估值

疲劳范围 0～100，按原版实际增加的次数追加：

`增长 = round((性交 + 肛交 + round(口交 × 0.5)) × 0.5 × 等级系数 × 孕期系数 × 设置速度)`

所有区域共用触手本体等级：1～10 级的疲劳系数依次为 **1、0.8、0.65、0.5、0.4、0.3、0.25、0.2、0.15、0.1**；11 级起为 **0**，不会累积疲劳。入夜已有孕期时系数为 1.5。加权次数与系数、设置速度均大于 0 时，每次结算至少增加 1 点；取整使用 Unity 的 RoundToInt，中点取偶数。

| 位置 | 正常结算 | 入夜透支 | 场外恢复 |
| --- | --- | --- | --- |
| 本体苗床区 | 按原版实际次数追加疲劳 | 跳过角色结算，−5 | 无 |
| 侵蚀区直接苗床箱，且开启箱内结算 | 同本体 | 同本体 | 无 |
| 闹钟苗床区 | 原版三种行为各 1 次，再追加疲劳 | 跳过角色结算，−5 | 无 |
| 已开启陷阱的苗床区 | 同闹钟 | 同闹钟 | 无 |
| 其它位置，包括关闭的陷阱、未开启结算的苗床箱 | 不追加疲劳 | 不执行设备透支恢复 | 每天 −25 |

默认速度下，闹钟与开启的陷阱在本体 1 级时未孕 +1、已孕 +2；2～10 级均为 +1；11 级起 +0。本体和开启结算的箱内角色随原版随机活动次数变化。高等级不会清空已有疲劳，达到 90 的角色仍按透支规则休息。

| 疲劳 | 本模组估值倍率 |
| --- | --- |
| 0～19 | 1.10 |
| 20～59 | 1.00 |
| 60～79 | 0.94 |
| 80～89 | 0.88 |
| 90～100 | 0.80，并暂停该角色本夜结算 |

本模组基础估值为 `300 + 调教值 × 2 + 普通处女加价 200 + 后庭处女加价 50`，再乘疲劳倍率、取整且最低为 1。疲劳不调整原版活动次数或受孕概率，偏好也不再调整次数。

喂自有乳汁最低只能降至 40，原已低于或等于 40 时不消耗。关闭疲劳系统后停用累积、恢复、估值修正及透支门禁。

## 桶装

在原版结算和自有乳汁追加完成后，扫描每个本体的整个产出区，包含前几天留存的瓶装，按实际堆叠数量计算：

| 对应瓶装 | 新建阈值 | 桶 ID |
| --- | --- | --- |
| `tentacle_semen` | 8 | `barrel_semen` |
| `milk_wondrous` 与原版 `wondrous_milk` 合计 | 3 | `barrel_milk_wondrous` |
| `milk_rich` | 3 | `barrel_milk_rich` |
| `milk_diluted` | 3 | `barrel_milk_diluted` |

先补充产出区已有的同类桶，不要求瓶装达到阈值。剩余瓶装达到阈值、且该类“自动新建桶装”开启时，才新建桶；四个开关默认开启，互不影响。关闭后已有桶仍补充，手动拖拽充能和取出保留。原版与自有神奇乳汁共同装入神奇乳汁桶，例如原版 2 瓶加自有 1 瓶即可建桶；当晚未触发追加乳汁或没有角色结算时，也整理产出区旧库存。

每桶上限 1000 次，占 4×4。新桶依次尝试产出区、己方柜台、仓库，成功放置才扣对应瓶装；满桶、关闭新建或无法放置时保留剩余瓶装。桶中次数与瓶装一比一换算。

使用桶后输入正整数批量取出，成功放置一瓶才扣一次，空间不足即停止，余量留桶。普通液体可拖到同类桶上补充。桶装不作为剧情要求的瓶装材料，交任务前先取出。

## 收购商、名册与夜报

橱窗展示乳汁种类决定每位收购商的独立到店概率：1 种约 33%、2 种约 66%、3 种 100%；没有则不来。每日上限在设置中调整。

每次只提交一名角色，优先提交界面选中的可售角色，无选择则按柜台顺序。首位按阵营、职业、体型、乳量、状态及行为次数验收；全部满足后额外收购 3～5 位，追加阶段按本模组基础估值 ×1，不再验收偏好。对话结束才允许下一次交货，名额用完或首位不合格后告辞离店。向治安部收购商提交同阵营角色会触发拒收和声望惩罚。

《苗床名册》记录成交数、收入和最近 100 笔交易，每页 5 条。关闭时成交只保存记录，下次打开且数据变化才重建书页；阅读中成交立即刷新。名册使用原生纸书，保留 2×3 图标与当前无文盲阅读限制的行为；读档首次开门缺失时补发。

原版夜报记录原版生成量与实际参与角色，其乳汁数字未扣后续被替换的数量，并非最终库存。暗流交易追加内容写入晨报日志和 2×2 报告便签。“本夜追加”含直接入桶的新乳汁，“库存装桶”只记后续瓶装转换，可包含旧库存，不重复统计直接入桶。便签按己方柜台、仓库、垃圾桶顺序投放，无空间时放弃实物。

## 治安部支线

卖出首名角色后的次日获得线人名片，拨打 **26535** 接入专线。按电话需求准备材料，确认后次日上门；预约沿用原版电话冷却。

主线依次涉及 5 份精液、双处女下层区角色、30 份精液，以及原版女儿标识且调教值大于 200 的角色；后续阶段有治安部声望门槛。旧 `MAIDEN_BORN` 会补齐 `MAIDEN_DAUGHTER`，旧标签保留。

剧情管制奖励持续生效，覆盖已有及以后生成的对应物品：

| 完成节点 | 奖励 | 保存的下一节点 `liaison_stage` |
| --- | --- | --- |
| 双处女下层区角色交货 | 排卵诱发剂为 I 级管制品 | ≥3 |
| 30 份精液交货 | 瓶装与桶装触手精液为 II 级管制品 | ≥4 |
| 女儿交货终章 | 全部苗床为 III 级管制品 | ≥5 |

管制品不记对应违禁案值，终章后苗床也不再记本模组贩卖人口案值；游戏普通交易使用原生管制加价。本模组收购商仍按独立基础估值与验收倍率结算。旧登记键保留，即使某个登记键遗漏，也会依据已完成剧情恢复奖励；读档后第一次开门补齐旧物品状态，无需重新交货。

完成后可使用归档与结案服务。归档按案值要求浓缩乳汁及特定阵营角色；结案需要革命军、黑市各一名，调教值均至少 200。实际需求与惩罚以当次电话和验收对话为准。管制登记、违禁等级、交易回执与剧情存档继续使用原有机制。
