# 淫色深空：暗流交易 1.6.4

原作者：白银；扩展作者：扫地机。本包为非官方扩展，需要同时启用 **lewd_meme 1.9.2 或更高版本**，当前核验版本为 1.9.2。

本模组追加三种乳汁、疲劳与估值、桶装、苗床收购商、交易名册和治安部支线。基础物品、捕获、活动、受孕、分娩与角色立绘由原模组提供。

## 安装与更新

将本目录放在游戏 `Mods` 下，同时启用前置与本模组。更新后重启游戏；本目录只保留一份 `ShadowTrade.dll`，不要并存旧 `MidnightPawnRemake.dll`。

模组 ID 仍为 `lewd_meme_remake`，命名空间、物品 ID 和原有存档键保留。已有角色、乳汁、桶装、名册和剧情进度继续使用；旧女儿标签会补齐原版标识。程序集改名及本次删除接口会影响外部扩展，详见开发指南。

## 当前结算规则

- 原版先完成活动、受孕和产出，再追加本模组三种乳汁；每产出一份先扣产出区一瓶原版神奇乳汁，没有瓶装则扣神奇乳汁桶一次，无可扣除时仍产出。已有同类桶优先直接加次数。偏好只保留文本。
- 疲劳只修正本模组估值；入夜达到 90 时，该角色本夜活动、双方产出、受孕、孕期推进与分娩全部暂停，恢复 5 点。未透支时完整运行原版计算。
- 本体、开启结算的苗床箱、闹钟及开启的陷阱共用疲劳规则，其它位置每天恢复 25。1～10 级系数依次为 1、0.8、0.65、0.5、0.4、0.3、0.25、0.2、0.15、0.1；11 级起不累积疲劳。
- 结算后扫描整个本体产出区：精液至少 8 瓶、每种自有乳汁至少 **3 瓶**可自动建桶；原版与自有神奇乳汁合计按 3 瓶装入神奇乳汁桶，含旧库存。四类开关独立控制新建；已有对应桶仍自动补充。
- 可选侵蚀区苗床箱结算直接调用原版循环，读取全部存储页，计入原版报告和经验；默认关闭，主苗床区为空也参与。
- 删除破处回避、产物倍率、自有夜间 API 和分区 API。原版夜报保留，追加乳汁与库存装桶另写晨报日志及暗流交易便签。
- 治安部管制奖励按剧情进度及旧登记键持续生效：排卵针 I 级、瓶/桶装精液 II 级、苗床 III 级；首次开门补齐旧物品，后续新物品自动登记。
- 指南集中到 `docs/`，过时报告和旧测试不再随当前说明重复维护。
