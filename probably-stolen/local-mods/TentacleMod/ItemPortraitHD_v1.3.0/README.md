# 苗床高清立绘管理器 ItemPortraitHD 1.3.0

为 lewd_meme 的角色物品提供 128/256 高清纹理、完整 4×4 占格、透明区域点击拖动和逐物品换图。

安装时保留整个 ItemPortraitHD 文件夹，在游戏中启用本模组及 lewd_meme，更新 DLL 后重启游戏。其他立绘包均为可选来源。

默认按 **F7** 打开管理器。快捷键可在游戏选项的“苗床高清立绘”分区改绑；分辨率、选图模式等在本模组设置中调整。

- [配置与兼容](Docs/配置与兼容.md)：权重、体型 CSV、名字性别及来源支持。
- [开发说明](Docs/开发说明.md)：源码构建、回归验证和维护约束。
