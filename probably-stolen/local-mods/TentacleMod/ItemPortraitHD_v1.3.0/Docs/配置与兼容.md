# 配置与兼容

## 角色及图片权重

普通模式使用游戏序列化注册表中能归入五阵营的原生角色。运行时新增键和别名不扩充随机角色池，额外图片仍可手动选择。

上下城区、治安部、黑市、革命军按角色键分类；`_scav` 仅算下层区；eleanor、serpico 及其变体排除。厨师、工程师、农民、医务、科学家、矿工等共享职业在上下城区各计 0.5。

图片权重范围 0–10，默认 1；0 表示不抽取。有已映射替换图时，角色有效权重是这些图片权重之和；没有替换图时才使用游戏角色的独立权重。抽中角色后在其替换图片中按权重选择，多个包替换同一角色不会增加角色数量。

“根据立绘数量调整捕获权重”开启时按各阵营有效角色总权重抽阵营；关闭时使用原模组的阵营抽取，阵营内部的角色和图片权重仍生效。

最终生效模式的兜底角色池固定每角色权重 1，共享职业各 0.5，忽略个人角色权重；先行处理的体型指定来源和 PNG 仍使用各自权重。仅高清重建模式完全交由原模组选图。

管理器只给可分类的自定义图片和已映射原生五阵营角色提供权重编辑。最终来源、未知角色、额外图标可手动使用，识别到它们不等于允许调整随机权重。

## 体型与旧配置

体型名称及顺序以源码 `AdultBodySources.Bodies` 和设置提示为准。CSV 按位置对应，不把旧安装 DLL 中的列表当作源码标准。

- `body_weights_csv`：体型内部相对权重，支持非负小数，不能全为 0；缺少的末尾值补 20。
- `scavenger_double_virgin_csv`：各体型独立的双处女概率，范围 0–100%，不要求合计 100；缺少的末尾值补 60。

格式错误、非法数字或项数过多会按现有规则回退默认值。成年体型权重只改变该子集的内部比例，整体占比及其他体型概率保持原模组分布。双处女概率仅作用于拾荒生成且属于配置列表的新角色。

旧逐项概率仅在尚无 CSV 时迁移，继续保留现有读取和迁移方式。以后若增加体型，追加到列表末尾可让缺失项补默认值；插入或重排会改变旧 CSV 对应关系，需要另行处理。体型来源配置也继续按现有位置索引保存。

体型影响乳量使用独立的五档规则，和可配置成年体型列表不是同一个数据范围。关闭该开关时恢复原模组的独立乳量分布，不合并这两组列表。

## 名字与性别

“新生成物品的立绘范围”可选仅女性或不限性别；文件夹 PNG 不按文件名推断性别。原模组道具作用性别、普通顾客女性化是独立开关，不修改已有角色的游戏性别。

游戏原版顾客与模组顾客有分别的改名保护，按游戏记录的顾客来源判断，不按立绘包判断。只拦截原模组的改名，不恢复已经改过的名字。

名字地区限制只作用于后续名字生成，已有名字及复用池中的旧名字不重写。

## 来源兼容范围

| 来源 | 接入方式 |
| --- | --- |
| 游戏与模组公开 Sprite 字典 | 读取公开图片；可供手动使用，符合映射规则的原生角色参与普通随机。 |
| 深空当铺女性立绘美化 | 读取原包绑定关系。 |
| RetroAnime / RetroAnimeGirls | 读取 portrait-map.csv。 |
| 精致日式立绘 refined_anime_portraits | 读取 portraits.tsv，并区分同名图片的可读槽。 |
| AllGirls | 读取 ApprovedCharacters.json 中已批准的游戏基础角色条目。 |
| all_girls | 复用原包 Collect 及映射、变体选择，读取原 PNG。 |
| probably_rimworld | 复用原包映射解析与校验，读取原 PNG。 |
| 白蛇及其 R18 扩展 | 读取内嵌 PNG，沿用主包角色映射及全身/半身设置；未映射图片仅手动。 |
| 其他来源 | 可读取最终 GetSprite 结果；通用追踪能否识别来源取决于访问声明与替换方式。 |

运行必须启用 lewd_meme。manifest 中其他前置 ID 用于声明来源访问范围，对应立绘包均可选；无需全部安装。未识别写入者不妨碍最终模式和仅高清重建模式使用实际图片。

专用接口随来源包更新可能变化。静态回归验证接口和算法，不能替代游戏内生成、读档及画面验证。
