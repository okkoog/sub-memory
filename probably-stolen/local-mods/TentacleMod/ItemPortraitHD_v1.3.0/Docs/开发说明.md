# 开发说明

## 构建与验证

使用 .NET 8 SDK。项目直接引用本地游戏 Managed 程序集；游戏目录变化时用 `-p:GameManaged=完整路径` 指定。

在模组根目录运行 PowerShell，输出放临时目录，避免覆盖正在安装的 DLL：

```powershell
$sourceRoot = Join-Path (Get-Location) 'Source'
$buildRoot = Join-Path $env:TEMP 'ItemPortraitHD-validation'
dotnet build "$sourceRoot/ItemPortraitHD.csproj" -c Release --configfile "$sourceRoot/NuGet.Config" "-p:BaseIntermediateOutputPath=$buildRoot/mod-obj/" "-p:OutputPath=$buildRoot/mod-bin/"
dotnet build "$sourceRoot/Tests/Tests.csproj" -c Release --configfile "$sourceRoot/NuGet.Config" "-p:PortraitAssembly=$buildRoot/mod-bin/ItemPortraitHD.dll" "-p:BaseIntermediateOutputPath=$buildRoot/test-obj/" "-p:OutputPath=$buildRoot/test-bin/" -p:UseAppHost=false
$env:MONOMOD_DMD_TYPE = 'cecil'
$originalDll = '原模组 MidnightPawn.dll 的完整路径'
$scanFolder = Join-Path $buildRoot 'scan'
New-Item -ItemType Directory -Force -Path $scanFolder | Out-Null
Copy-Item -LiteralPath "$buildRoot/mod-bin/ItemPortraitHD.dll", './manifest.xml' -Destination $scanFolder
dotnet "$buildRoot/test-bin/Tests.dll" $originalDll $scanFolder
```

每条构建或测试命令成功后再进行下一条。回归入口统一接收原模组 DLL 和候选目录两个参数；第二参数扫描该目录的 DLL，应使用刚构建的候选产物。

保留钩子签名与转写检查、名字保护、基础图像/权重规则、容器遍历和缓存注册项更新。删除了依赖具体来源包版本的素材快照、重复算法对照与专项命令入口。纯 .NET 测试不分配 Unity 原生纹理；指令检查只证明调用关系，不能证明画面或资源销毁行为。

## 维护约束

立绘包专用适配放在 `Source/Integrations`：AllGirls、Rimworld、白蛇资源与各包映射解析。目录外保留共享选图、转换缓存及基础 lewd_meme 兼容入口；新增立绘包适配也放入此目录。

- 以源码为准，保留体型列表、CSV 位置索引、来源设置和旧值迁移；不要根据旧 DLL 擅自补全列表。
- 三种选图策略的选择权和权重语义不同。共享扫描、采样表和转换缓存，保留各自路由及持久化来源 ID。
- 公开游戏属性和 Sprite 字典直接访问；原生角色边界仍取序列化 SpriteEntry 列表，不能用含运行时别名的总字典替代。
- 游戏 ModLoader 已应用本程序集补丁，入口不能重复 PatchAll。外部模组类型通过 ModAccess / ModReflect 按访问声明读取。
- 快捷键使用 AddGameOptionKeyBind，窗口遵守 KeyBindHelper.SuppressHotkeys，不再维护独立改键事件循环。
- 加权表按角色、来源或权重版本失效；最终图片扫描变化不应重建无关的本地 PNG 池。
- Portraits 统一拥有输出 Sprite/Texture。失效后先保留外部使用者，重建只更新仍引用旧结果的注册键，再回收无引用对象。
- 输出纹理必须保持 CPU 可读：游戏 SetSpriteAndShapeFromMod 会读取像素。保留现有透明裁边、等比画布和预乘透明度采样，不能用普通 Blit 假定等价。
- PNG 解码交由 Unity，解码前仍校验格式与 32MB/4096 边界；导入路径、哈希去重和原子落盘不可随重复代码删除。

## 游戏内验收

至少检查三种模式的新生成、顾客显示、F7 手动替换及恢复、来源包重载、128↔256、停用/再启用、存档往返和旧物品空间不足的回滚。改键需验证 Esc 取消及改键当帧不会开关管理器。

修改安装版前退出游戏；用候选 DLL 替换后重启。源码构建成功不表示当前安装版已经更新。
