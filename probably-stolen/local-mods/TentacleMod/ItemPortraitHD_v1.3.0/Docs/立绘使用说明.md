# 立绘使用说明

## 管理器

默认 F7 打开或关闭管理器。改键使用游戏选项“苗床高清立绘”中的快捷键按钮，由游戏处理按键捕获与 Esc 取消；模组配置中的 hotkey 字符串继续保存已有值。

左栏递归读取当前柜台、仓库等物品栏及拾荒栏，关闭的子容器也可列出；不包含已售物品区和顾客展示栏。搜索可用名字或物品编号，读档后重置选择。

选中左栏物品，再点击右侧来源图片应用。来源和搜索只筛选候选图片。手动选择写入该物品，不改变其他物品，也不触发批量随机。

“恢复所选物品原立绘”先验证原保存来源，成功后才清除手动覆盖；来源不存在时保留当前选择并提示原因。原包或图片确实被删除时，需要恢复资源。

所有苗床使用完整 4×4 占格和点击区域。旧物品空间不足时会尝试迁往柜台、仓库；仍放不下时先腾出空间，不以删掉物品解决溢出。

## 三种自动选图方式

| 设置 | 行为 |
| --- | --- |
| 普通模式：两个兼容开关均关闭 | 使用本模组的五阵营角色池、替换来源及个人权重，支持体型来源和自定义 PNG。 |
| 仅高清重建：立绘完全由原模组选取 | 优先级最高，停用本模组全部自动选图，由原模组选图后重建实际图片；未知来源也可处理。手动换图和 4×4 占格保留。 |
| 选图仅使用最终生效立绘 | 先处理体型指定来源、自定义 PNG，再按固定角色权重选角，读取游戏 GetSprite 的最终结果；无需先扫描或识别来源。 |

模式只影响后续选图，不会重新随机已有角色。顾客仍由原模组选图，开启“顾客栏已选立绘高清显示”只重建其实际选中图片，不加入捕获权重。

## 自定义 PNG

目录形式为 `Portraits/来源名/阵营名/图片.png`，阵营使用：上层区、下层区、治安部、黑市、革命军或不限阵营。阵营目录内可再建子目录。

来源名会显示为“自定义 / 来源名”，每个来源可分别配置权重或指定给体型。不限阵营图片向五阵营各贡献 1/5 权重；目录未分类的 PNG 只供手动选择。

“文件夹立绘替换概率”默认为 0%。体型直接指定自定义来源时跳过此概率；指定替换包时不会被普通 PNG 概率抢先。最终模式中指定来源失败后仍可回退 PNG 或最终图片。

文件须为 PNG，单边 1–4096 像素且不超过 32MB。识别出来源不代表一定属于五阵营随机池，规则见[配置与兼容](配置与兼容.md)。

## 导入图片

在“导入立绘”页选择来源、图片、目标自定义来源和阵营，确认后按当前 128/256 档位预处理并保存。导入按内容哈希去重，不改源包图片；游戏基础图和已有自定义 PNG 不在导入范围。

导入结果保留当前画布，之后改清晰度只缩放该结果；若需要从原始图片重新获取更高清细节，请按目标清晰度重新导入。

## 刷新与排查

新增、移动 PNG 或调整来源包后点“重载图片”。更换白蛇全身/半身设置后也需重载。

“扫描通用来源”逐帧更新最终图片，关闭管理器暂停。关闭通用追踪开关仍能扫描最终结果；无法识别写入者的图片显示为未知来源，可手动使用。

首次解码、裁切和缩放有开销，之后复用缓存。清晰度切换和重载会使旧转换失效；仍被原模组注册表或画面使用的图片延迟回收。预览的 192 条为软阈值，正在使用的图片可能使缓存超过该数量。

加载失败时先确认来源包已启用和 PNG 路径存在，再重载图片或重读存档以重试。日志保留本模组转换阶段的耗时提示，转换成功与否仍需以游戏画面确认。
