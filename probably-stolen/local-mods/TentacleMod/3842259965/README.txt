可能是成人用品 v1.1.0
作者：不问世事

安装：
1. 把整个文件夹放进 Probably Stolen\Mods 里；
2. 启动游戏，在模组菜单里启用「可能是成人用品」；
3. 建议先关掉旧的稳定版 probably_adult_goods，两者 ID 相同只能启用一个。

说明：
- 贴图、物品数据和中英文文本都已打包进 probably_adult_goods.dll，
  所以文件夹里除了 dll 只有这一篇说明和游戏必需的 manifest.xml。
- 幻龙收藏柜在杰克逊博士处购买，可升级到 24×12；
- 幻龙陈列盒同样是博士售卖，9 个格子各收一种幻龙；
- 模组设置里可以调柜子上限、拾取概率倍率和奇珍开关。
