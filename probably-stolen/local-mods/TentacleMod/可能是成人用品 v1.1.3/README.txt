可能是成人用品

安装：把本文件夹放进游戏的 Mods 目录，在主菜单的模组界面启用，然后重启游戏。

这个模组往店铺里加入「成人用品」这一类货物，包括计生包装和各类玩具，并让商人、拾荒和报纸行情能碰到它们。

贴图：
工坊包里是文字占位图，占的格子和正式图一致。
完整贴图另行分发，不要从创意工坊里找。
拿到图包后解压，把里面的 PNG 覆盖到本模组的 Textures/Items/ 目录，文件名保持不变。
也可以自己换图，只要文件名和原来的一致，游戏就会用新图。
不要把压缩包留在模组文件夹里。这个版本不读取 ExternalArt。

======== English ========

Probably Adult Goods

Install: put this folder in the game's Mods directory, enable it on the main-menu mod screen, then restart.

The mod adds an Adult Goods category to the shop: contraceptive packs, assorted toys, and the merchant stock, scavenging finds, and newspaper prices that go with them.

Art:
The Workshop package uses text placeholders. They occupy the same grid cells as the finished art.
The real art pack is distributed separately. It is not included here.
Unzip that pack and overwrite the PNGs in this mod's Textures/Items/ folder. Keep the filenames unchanged.
You can also supply your own icons, as long as each filename matches the file it replaces.
Do not leave the archive inside the mod folder. This version does not read an ExternalArt folder.
