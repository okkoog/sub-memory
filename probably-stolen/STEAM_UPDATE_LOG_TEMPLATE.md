# Steam Workshop 업데이트 로그 작성 양식

이 문서는 Probably Stolen 통합 한국어 번역팩(`3834117650`)의 **스팀 창작마당 업데이트 로그** 작성 규칙이다.
번역 작업 후 로그를 요청받으면 기존 대화에서 임의로 양식을 추측하지 말고 이 문서를 먼저 확인한다.

## 기본 규칙

1. 첫 줄은 **`한국어 번역 데이터 업데이트 v{실제 배포 버전}`** 형식으로 작성한다.
   - 버전은 사용자가 알려 준 실제 배포 버전을 사용한다.
   - 버전을 확인하지 못했다면 임의로 올리거나 만들어 내지 않는다. `v{버전}`으로 표시한다.
   - 업데이트 시각은 사용자가 제공한 경우에만 정확하게 기록한다.
2. 본문은 **`■`로 시작하는 큰 구분** 아래에 실제 변경된 모드를 적는다.
3. **모드 이름은 한국어 이름과 원제목을 함께** 표기한다.
   - 예: `물자 상자 및 장물 거래상 확장 (Fence and Case Expansion)`
   - 모드 이름을 추측하거나 비슷한 다른 모드 이름으로 바꾸지 않는다. 원본/기존 지원 목록을 확인한다.
4. 모드 이름은 **독립된 한 줄**에 적고, 변경 사항은 바로 아래에 **`- `**로 시작하는 줄로 적는다.
   - `ㄴ`, `└` 같은 기호로 들여쓰기를 바꾸지 않는다.
   - 모드 사이, 큰 구분 사이에는 빈 줄을 넣는다.
5. 실제 작업 내용만 적는다. **신규 번역**, **기존 번역 수정**, **오류 수정**, **검수**를 구별하고 확인된 수량만 기록한다.
   - 같은 수정 건수를 중복 집계하지 않는다.
   - 번역 대상이 아닌 모드나 단순 확인만 한 모드를 업데이트 대상으로 쓰지 않는다.
   - 번역되지 않는 부분 또는 게임 내 적용을 확인하지 못한 부분을 완료한 것처럼 쓰지 않는다.
6. **Steam 모드 링크는 기본적으로 넣지 않는다.** 사용자가 명시적으로 요구한 경우에만 링크를 추가한다.
7. 사용자에게 의미 없는 내부 관리 정보는 제외한다.
   - ZIP 파일 정리, GitHub 커밋/동기화, CSV 파일명, 업로드 여부, 작업 브랜치 등은 Steam 업데이트 로그에 적지 않는다.
8. `■ 신규 모드 한국어 지원`, `■ 기존 모드 번역 갱신`, `■ 번역 오류 수정`, `■ 번역 검수 및 보완`, `■ 작업 결과` 등은 **실제 해당하는 항목만** 사용한다.
   - 억지로 모든 구분을 채우지 않는다.
   - 같은 성격의 수정 사항은 모드별로 묶어 간결하게 정리한다.
9. Steam에 복사해서 쓸 수 있는 **본문만** 제공한다. 부연 설명, 링크 목록, 확인되지 않은 작업 완료 선언을 뒤에 붙이지 않는다.
10. 사용자가 '현재 버전'을 따로 지정했다면 그 값을 우선한다. 사전에 안내받지 않은 배포 버전(예: v0.9.14)을 임의로 만들지 않는다.

## 고정 템플릿

아래 템플릿에서 해당하지 않는 큰 구분은 통째로 삭제한다. `{...}`는 실제 정보로 대체한다.

```text
한국어 번역 데이터 업데이트 v{배포 버전}

■ 신규 모드 한국어 지원

{모드 한국어명} ({원제목})
- 신규 번역 {N}개 추가.
- {새로 번역한 주요 콘텐츠 및 기능}.
- {필요한 경우 추가 상세 내용}.

■ 기존 모드 번역 갱신

{모드 한국어명} ({원제목})
- 신규 번역 {N}개 추가.
- {기존 번역에서 반영한 구체적 변경 사항}.

{다른 모드 한국어명} ({원제목})
- 기존 번역 {N}개 수정.
- {구체적 수정 사항}.

■ 번역 오류 수정

{모드 한국어명} ({원제목})
- {실제로 수정한 번역 오류와 결과}.

■ 번역 검수 및 보완

{모드 한국어명} ({원제목})
- {실제로 검수·보완한 내용 및 범위}.

■ 작업 결과

- 신규 번역 총 {N}개 추가.
- 기존 번역 총 {N}개 수정.
```

## 실제 작업 내용을 반영한 예시 (2026-11-18)

아래는 **형식 예시**다. 배포 버전이 별도 확인되지 않았으므로 버전은 자리표시자로 남겼다.
이번 예시의 신규 번역은 감정 확장 180개 + 스택 수납 40개 + 폐품 수집 도구 업그레이드 2개 = 222개다.

```text
한국어 번역 데이터 업데이트 v{배포 버전}

■ 신규 모드 한국어 지원

감정 확장 (Extended Appraisals)
- 신규 번역 180개 추가.
- 시럽 감정 안내서, 위조품 판별 기준 및 가격표 번역.
- 랫 밴들레이 관련 대사, 이벤트 및 정산 문구 번역.

■ 기존 모드 번역 갱신

스택 수납 (Stack Storage)
- 신규 번역 40개 추가 및 기존 번역 보완.
- 컨테이너 연결 및 연결 관리 관련 문구 번역.
- 사용 설명서 최신 내용 반영 및 사용하지 않는 번역키 정리.

폐품 수집 도구 업그레이드 (Scavenging Tool Upgrades)
- 신규 번역 2개 추가.
- 탐지기의 잡동사니 감소 및 추가 전리품 관련 문구 번역.

■ 작업 결과

- 신규 번역 총 222개 추가.
```

## 작성 전 확인할 사항

- 기준: **실제 배포할 번역팩의 변경 내용**. `mods/` 원본의 변경과 한국어팩에 적용된 변경을 혼동하지 않는다.
- 사용자에게 불필요한 작업 과정 대신, 플레이어에게 보이는 변경 사항을 설명한다.
- 버전, 번역 수량, 모드명, 적용 범위를 발행 전에 확인한다.
- 특별히 사용자가 다른 양식을 지정하면 이 문서보다 그 요청을 우선한다.
