# Probably Stolen — 번역 파일 출처 및 대응 범위

확인일: 2026-11-08 (KST). 사용자 지시 우선. 이 문서는 번역키 대조 시 먼저 확인할 작업 메모이며, 실제 최신 버전/키 수는 GitHub 현재 HEAD의 파일을 다시 읽어 판단할 것.

## 특히 혼동 금지 — 단독 ko.csv의 정체

- **`probably-stolen/번역 모드/Localization/ko.csv`는 게임 기본 번역이나 무소속 CSV가 아니라 '스택 수납 / 堆叠收纳 / Stack Storage' 모드의 한국어 번역 파일이다.**
- 해당 원본 모드: `probably-stolen/mods/3829085054/` (Steam Workshop ID `3829085054`, manifest 내부 ID `Dream_Item_Storage`).
- 키는 `is_` 접두사를 사용한다. 현재 `ko.csv`에는 원본 `Localization/en.csv` 및 `zh.csv`의 키를 번역한 항목들이 있다.
- 매번 '스택 수납 한국어 번역이 없다'고 판단하거나 `pskb__3829085054.csv`가 없다는 이유만으로 신규 번역 대상으로 분류하지 말 것. **키 대조 시 위 `ko.csv`를 스택 수납의 실제 한국어 번역본으로 매핑**한다.

## 최신 번역 모드 위치

- 사용 중인 한국어팩 원본 로컬 경로: `G:\steam\steamapps\common\Probably Stolen\Mods\content` 아래 한국어팩.
- GitHub 고정 위치: `probably-stolen/번역 모드/` (과거 `0.8.3/` 폴더에서 변경).
- 버전은 폴더명이 아니라 `번역 모드/manifest.xml`의 `<ModVersion>` 및 `VERSION.txt`로 확인. 확인 당시 버전 0.8.4.
- 업로드된 원본 워크샵 모드 폴더: `probably-stolen/mods/<워크샵ID>/`.

## 대조 지침

1. 현재 `main`에 실제 존재하는 모드 `Localization` 키와 한국어팩 `pskb__<워크샵ID>.csv` 키를 비교한다.
2. 단, 스택 수납은 `번역 모드/Localization/ko.csv`가 번역 파일이고, 제작자가 `ko.csv`를 제공하는 모드는 자체 번역을 별도로 확인한다.
3. CSV가 없는 모드는 DLL 내부 문자열까지 확인하지 않았다면 '신규 번역 키 없음'으로 확정하지 않는다.
4. 원본 키 신규 추가, 기존 값만 변경, 번역 파일 누락, 배포본과 작업본 불일치를 별도 분류한다.
