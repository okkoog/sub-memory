## 의미·표현 검수 중 반영한 수정

- MyGO: 이벤트 영구 중단 선택지의 '매정한 말' 뉘앙스 복구, 라나의 크레딧 부재/선물 설명 보완.
- NPC Girls: 조르지오가 세르피코 관련 대사에서 반말과 존댓말을 혼용하던 문제 교정; 중국어 `程` 성씨는 '정'으로 통일.
- Fishing Cuisine: `Space Rocket Fish`를 '우주 로켓물고기'로 통일하고 해파리 관련 표현 수정. 조리법, 요리 재료, 고객 피드백 등은 영중 원문 대조를 수행함.
- Cyber Fried Rice: '노련한 여주방장' 이름을 기존 Fried Rice Girls 번역과 일치시키고 중국어 원문에 따른 가족 관계 및 무쇠 팬 묘사 정정. 요리 이름 '황먼지' 설명 보완.
- 물품 설명 UI: 소유 여부에 따른 감정서 색상 설정 명칭 통일.
- 숙련도, 총기 확장, Cyber Fried Rice: 쉼표가 들어간 설명 문자열을 CSV 인용 형식으로 수정.

## 의도적으로 유지하는 값

1. NPC Girls `portrait:*` 17개: 초상화 리소스 식별자이므로 영문 그대로 보존.
2. Fishing Cuisine `FishingCuisineExpansion.厨师菜谱.txt`: 번역 대상 문장이라기보다 원본 파일명에 해당하므로 변경하지 않음.
3. 총기 확장 CSV의 `config_vex_poster`, `config_vex_poster_tip`: 현재 영어 원본에 없는 한국어팩 과거 키 2개. 호환성을 고려해 유지함.
4. 모든 외부 모드 DLL/파일과 한국어팩 DLL: 이번 검수에서 직접 수정하지 않음.

## 남은 실제 검증

- 게임 실행 후 신규 모드별 실제 화면 출력, 글꼴/폰트 지원, NPC 대사 분기, 조리책·주문 UI를 확인해야 함.
- 대사 문맥·표현을 대상으로 하는 수작업 2차 검수를 정적 검사와 구분하여 지속함.
- ZIP은 재생성 시 반드시 최신 GitHub `번역 모드/Localization` 11개 CSV를 기준으로 만들어야 함. 오래된 중간본 ZIP을 최종본으로 사용하지 말 것.
