## 비교 후 실제 교정 14개
- 약제 설탕 보조재 표기와 오래된 주재료 설명 6키: 중국어 `糖`는 설탕, `主料`는 주재료. 상대 번역에서도 '분말 기반'으로 옮긴 명백한 오역은 채택하지 않음.
- 설명서 한 페이지 제목 1키: 같은 중국어를 다르게 해석한 `원액 10mL당 안정제 투입량`을 `조합별 투입량`으로 정정.
- 정수·병입 가공 분류 4키: 원문 `净水`의 정수/정화 의미 복원. 상대 번역의 '물 및 병입'도 원문 의미가 불충분하므로 독립 번역.
- 물약 고객의 약효 과다 판정 2키: 원문 `过强`를 '수량 과다'가 아닌 '효과가 너무 강함'으로 표현. 동일 의미의 두 납품 UI를 통일.
- 고객 대사 표기 1키: '연락주세요'를 '연락해 주세요'로 다듬음.
- 변경 전/후 및 중국어·영어 출처: `probably-stolen/analysis/GO_FISHING_REFERENCE_ONLY_COMPARISON_FIXES_20261115.csv`.

## 참고 번역과 견줘도 수정하지 않은 항목
- Ratfish/鼠鱼는 추가 확장과 기존 한국어 표기를 고려해 '쥐치'를 유지. 상대 번역 내부에도 '은상어' 등 상충 표기가 있어 그 자체를 근거로 삼지 않음.
- `gameplay.a8d32d3a831d7e9a`의 Stardrop과 `item.gf_star_fruit.name`의 Star Fruit는 같은 중국어 `星之果实`라도 영어 명칭과 사용처가 달라 코드 확인 없이 통일하지 않음.
- `item.gf_fish_offal.name`은 Fish Offal, `powder.machine.scrapName`은 Fish Scrap. 표시 문맥에 따른 '생선 내장/생선 부산물' 구분 유지.
- `reagent.effect.strength` (Strength) 및 `reagent.five.effect.strength` (Fortify)는 중국어 `强化`가 같지만 영어와 시스템 세대가 달라 임의 통일하지 않음.
- 윌리 판매 대사: 상대 번역의 높임말 일괄 적용 대신 캐릭터의 상황·기존 대사 어체 유지.
- 구형 보조재 안내의 150µl / 신규 조합 안내의 0.5mL 수치는 각각 해당 원문 그대로 유지. 게임의 실제 실행 경로는 미검증.

- 사용자가 실제 게임 메뉴를 이해하는 데 더 익숙한 표현을 우선하며, 해당 원문 영어도 `Water and Bottling`임.

- 스팀·DLL은 수정하지 않음.

## UI 문구 간결화 재수정 (2026-11-15)

- 사용자의 실제 UI 가독성 기준에 따라 `reagent.order.drag.effectHigh`와 `reagent.order.visitor.effectHigh` 두 키를 모두 `{0} 효과가 너무 강함`에서 **`{0} 과다`**로 간결하게 수정함.
