# 堆叠收纳（ItemStorage）

这个 MOD 给游戏加了一种储物：收纳箱，如果有想添加的内容&遇到了BUG可以直接@浮生若梦，看到了就会回复，长时间没回复可能是睡着了。

## 更新日志

### v1.3.4

- 修复了一个配合堆叠类 MOD 时的取出问题：桌上已经有同类物品堆时，从箱子取出的东西会尝试并进那堆，能不能并上由堆叠规则说了算。以前并上的时候，箱子这边以为没放出去，提示空间不足还不扣数量，物品就多出来了。现在并上了也算正常取出，箱子照常扣数，不会再多出物品。
- 感谢玩家反馈，帮忙定位到了这个问题。

### v1.3.3

- 空瓶子更好收了：拖到收纳箱上或一键收纳时，箱里就算还没有同款瓶子格，也会直接开新格收进来——空瓶里没水，不存在混水的问题。优先还是并进已有的空瓶格、水瓶格，都没有才开新格。
- 「至少留一件」不再拦亲手点格子：开着这个开关时，左键/右键（含 Alt 变体）点格子都能把最后一件也取走。一键上货这类自动搬运还是会给同类留最后一件，方便续存。
- 若干内部稳定性增强（界面与玩法行为无变化）。

### v1.3.2

- MOD 的所有界面文字接入了游戏官方的本地化系统：游戏设置里是什么语言，收纳箱的按钮、提示、悬浮说明、设置面板就跟着显示什么语言。目前游戏本身支持 8 种语言（英语、简体中文、俄语、德语、日语、法语、西班牙语、波兰语），暂时还没有对应翻译的语言会显示中文——不会出现一串英文键名之类的占位符，请放心。
- 想帮忙把它翻成你的语言？欢迎。两种方式都行：把翻译文件（CSV，一行一条 `键,文本`）发给浮生若梦，合并进 MOD；或者做成独立的语言包 MOD（Localization 文件夹 + 一个空的 IMod DLL），玩家装「堆叠收纳 + 语言包」就能生效，收纳箱会自动优先读取语言包里的翻译，没翻到的键自动落回中文。键名以 `is_` 开头，发布后固定不改，翻译时 `{0}`、`{1}` 这类占位符原样保留、位置可以按你的语序调整。

### v1.3.1

- 其他 MOD 做的特殊版物品，存进收纳箱再取出来不会"掉回原形"了。最典型的就是公司增强的海明威限量包装：以前存一包进去，取出来变回普通正品烟（名字、价格 200→100、专属贴图和鉴定界面的限量叠图全没了）；现在限量标签会跟着一起存、一起取，取出后名字、价格、贴图、风味文本原样回来——而且这些全是官方动作和对方 MOD 自己算的，收纳箱一个字都不改。这条规则是通用的：以后任何 MOD 只要按官方那套条件动作挂定价、贴标签，它的特殊版东西进箱出箱都自动保真，不用等适配。
- 顺带把分格判据收拢成了一套：化学品按纯度档分格、种子按基因分格这些规则，以前在"手动拖放""一键收纳""箱子之间搬货"三条路上各写了一份，偶尔会出现这边能并进去、那边又并不进去的拧巴情况；现在三条路读的是同一份判据，说并就并、说分就分。

### v1.3.0

- 同一款东西不再因为价格不一样被拆成两格。以前同一款物品只要价格差一点（顾客买走时系统改的价、买入价不同、各种加成）就会分开占格，看着像两种货。现在它会老老实实待在一格里——取出的时候每一件还是按它自己存进来时的价格和状态还原，卖价一分不少。老存档里已经因为价格分出去的格子，打开箱子就自动恢复吸收能力，不用取空重存。
- 带真假的东西（香烟、注射剂这些）现在只按真假分格：都是真的一格，都是假的一格。以前"正品名"和"赝品名"会被当成两种货分开摆，可名字只是个标签，红标签机随时能改，按名字分格反而越改越乱。真烟和真注射剂这种"都是真、但不是同一样东西"的，仍然各占各的格，绝不会混到一起。
- 一键收纳的规矩没变：箱子里有同款才收，箱里没有的东西摆在店里再多也不会被吸进来。
- 水这次是真的混在一起了，不是只显示混在一起。同一规格的瓶子（同样的瓶、同样的容量）进同一格，每瓶倒进来的水按毫升累加成一池；取的时候按瓶子的容量从池里均分，先取后取都是同一池水里舀出来的，每一瓶的水质和档位都一样。以前只是图标显示混着，取出来还是各自原来那瓶水。
- 顺带把水的几条老毛病一起收了：玩家改过名的水瓶不再单独占一格，取出恢复默认名；20L 储水罐和升级到 50L 的罐子不再挤同一格（容量不同就是两种规格），取出来的罐子容量也不会被模板重置；空瓶、大瓶、小瓶各归各的格，不会串。
- 空瓶子也能一键收纳了，但只并进同规格的瓶子格：先找空瓶格（池子里没有水的），没有空瓶格才并进同规格的水瓶格；两种格都没有就不收，不会为了一个空瓶另开一格把水搅在一起。想放在指定位置，直接拖到那个格子上就行。
- 拖放落点按你松手的那格来：松手在空格上就在那格开新格（箱里已经有同款也一样，方便你把货分区）；松手在放不进去的别的物品格上，才会并进箱内已有同款格，箱里没有同款才顺位另开一格。
- 枪和配件的悬浮窗跟箱外一致了：枪显示品质修正后的当前属性（不是出厂基础值），配件按" +10 精准度"这种格式显示，不会再把配件当枪渲染。种子和果实按基因、性状分格，不同品种不会混堆。
- 箱体上"收纳箱"三个字不会莫名消失了。以前切场景、箱子进背包、读档之后可能变空白，要重进游戏才回来；现在会自己补上。
- 修复"把每格数量上限调小之后，取东西会吞数量"的问题——比如一格里存了 50 件，上限调到 20，以前取 1 件会直接变成 20 件，现在正常剩 49 件。上限只拦新放进去的，不会削减已经存好的。
- 箱子和箱子之间整格搬东西，失败时不会再出现"两个箱子各有一份"的情况。

### v1.2.4

- 把"垃圾、线缆、空啤酒瓶自己占一格、老格怎么都并不进去"这个毛病真正修完了（v1.2.2 只修了一半，抱歉）。真凶是游戏自己会偷偷改物品的图标名：顾客把东西买走的那一瞬间会把图标名改成"原名+数量"，东西在柜台上叠起来或者拆开的时候也一样会改。要是收纳箱正好在这之后把东西收进去，记下的就是那个临时名字，跟正常的同款怎么都对不上号——于是新开一格，而且老格清空之后新格又接着变脏，来回换。现在存入、取出、格子记录、格子图标这四条路都会自动认回原厂图标；**老存档里已经分出去的格子，打开箱子就自己恢复了吸收能力**，不用取空重存，也不用重开档。
- 顺手把一键收纳的提示文字改清楚了：以前那句"1 件销毁走裸销毁兜底"看着像丢东西，其实清掉的是已经搬进箱子的空壳，东西一件没少。
- 修复"格子里堆到上限之后，一键收纳就不肯再收了"的问题——以前只有手动拖过去才会自动开下一格，一键收纳遇到满格会当成"这类东西没地方放"直接跳过，全箱收纳也一样。现在格子堆满会自己接着开新格；顺带修好了箱子 16 格全满时提示文案说反的问题（以前会弹"没有可收纳的物品"，现在明确告诉你"箱子已装满 16 格，先取出一些再收纳"，全箱收纳同样会提示"所有收纳箱都装满了"）。单格上限在设置里调小（比如先调到 20 试）也能正常接下一格。

### v1.2.3

- 修复一键上货把满瓶水当成日用品摆上柜台的问题——瓶子的类别其实跟着"装没装水"走（空瓶算日用品、装了水算水），之前上货判定用的是出厂空瓶样本，日用品顾客的清单里明明写着"不要"水，柜台上却被摆了一瓶。现在判定会按格子里货的真实状态来，日用品顾客不会再收到水。
- 买水的顾客现在能正常一键上货了，而且**只上他要的档次**：每位水客都有自己的水质清单（有的只要纯水/优质水，有的只要普通水，拒收危险水的顾客不收锈水、沟渠水），档外的水一律不上架；要的档里有好几格时，纯度最高的那格先上。顺带一提，倒出来的散装酒在官方水质体系里算铁锈水档，所以"只要纯水/优质水"的顾客天然不会收到散装酒——这是官方语义，不是漏上。

### v1.2.2

- 一键上货/全箱上货现在支持"又卖又收"的混合型顾客了——化学家、药剂师、矿工、各路拾荒者、买水的客人这些自己摆货也收货的顾客，之前会被误拦"该顾客不是来购物的"，现在能正常一键上货他们想收的东西。
- 修复同规格瓶装水无法放进同一格的问题——之前水量或水质差一点点就会各开一格，现在水格回归"成分池"：任意水质、任意水量都能混进同一格，存入什么成分取出就还原什么成分，倒出来的散装酒也照这个规则混存。
- 修复垃圾、线缆这类物品"自己占一格、怎么都并不进去"的问题——原因是在柜台上被顾客买走的一瞬间图标数据会被临时改写，如果恰好在恢复前就把它们收进箱子，箱子里记下的就是那个临时样子，和普通同款永远对不上号。现在收纳时会自动认回原厂图标，已经分出去的格子也会立刻恢复吸收能力，不用再取空重存。

### v1.2.1

- 性能优化：其他 MOD 查询"某物品是否寄存在收纳箱"（`IsUidStored`）从全箱扫描改为版本化缓存——数据没变时每次查询零解析成本，箱子变动后首次查询重建一次。玩家无感知，受益方是调用接口的其他 MOD（比如深空装机保存前对账）。
- 新增 `GetAllStoredUids`：其他 MOD 一次拿全部寄存编号的捷径，批量对账更省。
- 新增滥用观测：接口被异常高频调用时日志每分钟告警一次（正常玩法不可能触发）。

### v1.2.0

- 新增「物品身份保真」：每件物品在游戏里都有一个隐藏的出厂编号，有些 MOD 靠这个编号认东西。以前物品存进收纳箱再取出来，编号会换成新的——东西本身一点没变，但对方 MOD 就不认识了。现在有"个性"的物品（老鼠、鱼、带状态的配件、其他 MOD 的特殊物品这类）取出时编号原样带回，取出来的还是原来那一件。普通杂物不记编号，行为和以前完全一样。
- 适配深空装机：他的收藏品（战术核显这类）、整机、物资箱、组合件存进收纳箱时会弹一条提示——这类物品在箱子里时深空装机会暂时找不到它、暂停存档，**取出该物品即可立即恢复**，箱内其他物品不受影响。每档只提醒一次，不会每次都唠叨。普通电脑配件不受影响，照常收纳、取出后深空装机照常收储。
- 新增「其他 MOD 作者看这里」小节（见下）：如果你的 MOD 按物品编号记账，可以查收纳箱的公开接口，把"物品不见了"降级成"寄存中"，两边玩家都舒服。

### v1.1.7

- 新增「一键上货」按钮：在收纳箱窗口把箱里的东西按件摆上柜台，有顾客在的时候才会工作——它会只挑这位顾客想买的东西上，摆到顾客预算花光或者柜台放满为止。上货是一件一件弹进去的，不卡画面。
- 新增「全箱上货」按钮：和全箱收纳一样是一次性动作，从你所有收纳箱里找这位顾客想买的东西上柜台。
- 顾客的预算卡得更准了：每件东西上柜前都会按它的真实价值（包括变种、改标之后的价）预估，放上去之后还会再核一遍账——万一有东西实际比预估贵，会自动放回箱子里再停手，柜台上摆着的总价永远不会超过顾客的钱包，你不会吃亏。
- 空桶、空电池这类空容器不会再被自动上架了（顾客也没法买空桶）。
- 多样性顾客（"每样只买一个"的那种）记得更牢了：不光看卖出去的，柜台上已经摆着的同款也算数，不会摆两件只卖一件。
- 新增格子锁定：左键点格子下面的名字条，就能把这格锁住（图标左上角会出现红点标记，名字条翻成黑底白字，悬停格子也有说明）。锁住的格子不会被一键上货和全箱上货拿走，收纳和取出照旧不受影响。格子清空或者换了别的东西，锁会自动解除。
- 新增「一键整理」按钮（标题栏上，齿轮左边）：箱子用久了东一格西一格的，点一下就自动往前压实——东西还是那些东西、顺序还是那个顺序，只是空格被填上了。锁定格不会动，物品的所有属性原封不动跟着搬，放心点。没得整理时会告诉你"目前顺序已经无法整理了"。
- 设置面板（标题栏小齿轮）全新改版：分成了「快捷键」和「开关」两组。新增"一键上货"快捷键（每箱一个）和"全箱上货"快捷键（全局一个，和全箱收纳键一样）；新增"不参与全箱上架"开关——打开后全箱上货会跳过这个箱子，但它自己的一键上货按钮和快捷键照常能用。
- 四个开关换成了和官方机器窗口一样的方块样式，开还是关一眼就能看出来。
- 彻底修复水培蘑菇存取后变回"化学品/违禁品"的问题（上一版的修复没修干净，抱歉）——蘑菇的"食物"类别现在也逐件记账了，整堆存入、逐个取出都还是食物。
- 彻底修复大退游戏后其他 MOD 物品图标变问号/灰块的问题（也是上一版没修干净的）——现在箱子会自己把对方 MOD 的图标"要"过来，不用再取出一件才恢复；个别实在要不回来的会显示灰块占位，不会再显示问号。

- 悬停收纳箱本体不再显示那一大段库存清单（把箱子顶得老高那个）——格子的悬停里什么都有了。

## 玩法说明

**获取**：安装 MOD 后第一次进店铺，自动获得第一个收纳箱（带【破旧】标签，卖价约 150）。之后杰克逊博士上门时，会售卖收纳箱。

- 该收纳箱占用内存少，如有因为收纳箱出现卡顿，请联系浮生若梦修复卡顿。
- 物品属性：2×3 占格，价值 600，储藏（STORAGE）类型。
- 存放方式：把物品拖到收纳箱上松手，按自动顺序进入格子；把物品拖到详情面板的某个格子上松手，直接进对应格；点击一键收纳，一键把店里主界面空间（橱窗、垃圾桶、其余所有储物容器内、海报后除外）里与盒内已有种类相同的物品收进盒子。
- 已经存入的物品取出时再次获得，像背包、水瓶打印机、这类内部装着东西的物品，会被拒收，请清空其中的物品后再放入。
- 同类物品优先堆进已有的格子，那格满了会开新格。每格默认最多 99 个，设置面板里能改（20-999）；改小只拦新放进去的，不会削减已经存好的。
- 左键点格子取出 1 件，右键点格子一次取 5 件，格子里不够 5 件会全部取出，空间不够时停止取出。
- 老鼠和鱼这类养着的活物，取出顺序是后存入的先取出，格子贴图显示最新存入的那只。
- 物品会按真实品质分格堆放：纯度不同的分开；带真假的东西按真假分（同真值放一格，标签名字怎么写不影响），取出来的时候标签会恢复成真实状态。
- 无法放入的物品：【储藏】、【机器】、酿造中的酒瓶、【赃物】、【模组】、【物资箱】、【节点】、【工具箱】，还有显示成问号的物品（见下面「其他 MOD 的物品」）。

**一键上货**：收纳箱窗口底下一排现在有四个按钮，从左到右是「全箱收纳」「全箱上货」「一键上货」「一键收纳」。

- 一键上货是把**这个箱子**里的东西摆上柜台卖，全箱上货是把**你所有收纳箱**里的东西摆上柜台。两个都只会在有顾客站在店里时工作。
- 上货只挑顾客想买的东西：他喜欢的类型才会被摆上去，不感兴趣的、以及官方规定不能卖给这位顾客的（比如警察不收违禁品）都会自动跳过。"又卖又收"的混合型顾客（化学家、矿工、拾荒者这些）同样支持——他自己带来的货摆在进货区，想收的东西从收纳箱上柜台，两边互不打扰。买水的顾客按水质档次挑货：清单里要哪几档就只上哪几档，同档里纯度最高的格优先。
- 摆上去的每件东西都按官方实时计价卡着顾客的预算，预算花光或柜台摆满就停。多样性的顾客（每样只买一件那种）每样只摆一件，不会把柜台摆满卖不掉的死货。
- 空桶、空电池这类"有容量却空着"的物件不自动上货——卖出价太低，留着等你装满再卖。
- 左键点格子下面的名字条可以锁格：锁住的格子不上货，图标左上角有官方"固定"同款小锁标记，悬停也有说明。格子清空或换物自动解锁。想整箱不参与全箱上货，去齿轮面板开"不参与全箱上货"——注意这个开关只影响全箱上货，箱子自己的一键上货照常能用。
- 四个快捷键都在齿轮面板里绑：一键收纳 / 一键上货是每个箱子各自的键，全箱收纳 / 全箱上货是全局共用一个键。绑定前会自动检查冲突，撞了官方按键或其他箱的键会拒绝并提示。

## 其他 MOD 作者看这里

收纳箱的存入=销毁物品本体、取出=重建物品实例（数据全部记在箱子标签上，省内存）。从 v1.2.0 起，**有独立状态的物品取出时会写回原 uniqueId**，按 uniqueId 记账的 MOD 取出后能直接对上账。

如果你的保存前校验需要处理"账本里的物品暂时不在场"，可以查收纳箱的公开桥（modId `Dream_Item_Storage`，类型全名 `ItemStorage.ItemStorageApi`，纯 public static，DLL 反编译或 README 即可发现全部接口），把这种情况降级成"寄存中、允许保存"：

```csharp
// 反射探测（类型不存在时静默跳过，不产生硬依赖）：
var asm = System.AppDomain.CurrentDomain.GetAssemblies()
    .FirstOrDefault(a => a.GetName().Name == "ItemStorage");
var api = asm?.GetType("ItemStorage.ItemStorageApi");   // 注意：命名空间就是 ItemStorage

// static bool IsUidStored(int uid)
//   → 该 uniqueId 是否正寄存在玩家任一收纳箱中（版本化缓存，O(1)）
// static IReadOnlyList<int> GetStoredUids(GameItem box)
//   → 指定收纳箱（全部格子）内寄存的 uniqueId 并集
// static IReadOnlyList<int> GetSlotUids(GameItem box, int slot)
//   → 指定收纳箱指定格子的 uniqueId 列表
// static IReadOnlyList<int> GetAllStoredUids()
//   → 全部收纳箱寄存编号并集快照（批量对账推荐：一次拿全表自己建 HashSet）
var isStored = (bool?)api?.GetMethod("IsUidStored",
    System.Reflection.BindingFlags.Public | System.Reflection.BindingFlags.Static)
    ?.Invoke(null, new object[] { item.uniqueId });
```

语义约定：`IsUidStored` 返回 true = 物品本体已销毁、数据完整寄存在收纳箱里，取出时会原样写回这个 uniqueId——你可以放心把"实物失踪"挂起而不是阻止保存。存箱期间账本暂时对不上是设计内窗口期，不是数据损坏。有问题随时群里@浮生若梦。

**使用约定（写给所有调用方）**：

1. `IsUidStored`/`GetAllStoredUids` 走版本化缓存，随意调用不伤性能；但请**不要在每帧 Update 里轮询**——按事件（保存前校验、物品变动）调用即可，这是对玩家机器的基本礼貌；
2. 取出接口（`TryWithdraw`）请提供**玩家可见的入口**（按钮/确认），勿在后台静默扫箱搬货——箱子东西不告而取，玩家第一个找的是收纳箱作者；
3. 接口异常会打 `[堆叠收纳API]` 前缀日志，对接调试时 grep 这个前缀。
