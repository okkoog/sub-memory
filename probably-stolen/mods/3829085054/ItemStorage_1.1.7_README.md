# 堆叠收纳（ItemStorage）

这个 MOD 给游戏加了一种储物：收纳箱，如果有想添加的内容&遇到了BUG可以直接@浮生若梦，看到了就会回复，长时间没回复可能是睡着了。

## 更新日志

### v1.1.7

- 新增「一键上货」按钮：在收纳箱窗口把箱里的东西按件摆上柜台，有顾客在的时候才会工作——它会只挑这位顾客想买的东西上，摆到顾客预算花光或者柜台放满为止。上货是一件一件弹进去的，不卡画面。
- 新增「全箱上货」按钮：和全箱收纳一样是一次性动作，从你所有收纳箱里找这位顾客想买的东西上柜台。
- 顾客的预算卡得更准了：每件东西上柜前都会按它的真实价值（包括变种、改标之后的价）预估，放上去之后还会再核一遍账——万一有东西实际比预估贵，会自动放回箱子里再停手，柜台上摆着的总价永远不会超过顾客的钱包，你不会吃亏。
- 空桶、空电池这类空容器不会再被自动上架了（顾客也没法买空桶）。
- 多样性顾客（"每样只买一个"的那种）记得更牢了：不光看卖出去的，柜台上已经摆着的同款也算数，不会摆两件只卖一件。
- 新增格子锁定：左键点格子下面的名字条，就能把这格锁住（图标左上角会出现红点标记，名字条翻成黑底白字，悬停格子也有说明）。锁住的格子不会被一键上货和全箱上货拿走，收纳和取出照旧不受影响。格子清空或者换了别的东西，锁会自动解除。
- 新增「一键整理」按钮（标题栏上，齿轮左边）：箱子用久了东一格西一格的，点一下就自动往前压实——东西还是那些东西、顺序还是那个顺序，只是空格被填上了。锁定格不会动，物品的所有属性原封不动跟着搬，放心点。没得整理时会告诉你"目前顺序已经无法整理了"。
- 设置面板（标题栏小齿轮）全新改版：分成了「快捷键」和「开关」两组。新增"一键上货"快捷键（每箱一个）和"全箱上货"快捷键（全局一个，和全箱收纳键一样）；新增"不参与全箱上架"开关——打开后全箱上货会跳过这个箱子，但它自己的一键上货按钮和快捷键照常能用。
- 四个开关换成了和官方机器窗口一样的方块样式，开还是关一眼就能看出来。
- 彻底修复水培蘑菇存取后变回"化学品/违禁品"的问题（上一版的修复没修干净，抱歉）——蘑菇的"食物"类别现在也逐件记账了，整堆存入、逐个取出都还是食物。
- 彻底修复大退游戏后其他 MOD 物品图标变问号/灰块的问题（也是上一版没修干净的）——现在箱子会自己把对方 MOD 的图标"要"过来，不用再取出一件才恢复；个别实在要不回来的会显示灰块占位，不会再显示问号。

## 玩法说明

**获取**：安装 MOD 后第一次进店铺，自动获得第一个收纳箱（带【破旧】标签，卖价约 150）。之后杰克逊博士上门时，会售卖收纳箱。

- 该收纳箱占用内存少，如有因为收纳箱出现卡顿，请联系浮生若梦修复卡顿。
- 物品属性：2×3 占格，价值 600，储藏（STORAGE）类型。
- 存放方式：把物品拖到收纳箱上松手，按自动顺序进入格子；把物品拖到详情面板的某个格子上松手，直接进对应格；点击一键收纳，一键把店里主界面空间（橱窗、垃圾桶、其余所有储物容器内、海报后除外）里与盒内已有种类相同的物品收进盒子。
- 已经存入的物品取出时再次获得，像背包、水瓶打印机、这类内部装着东西的物品，会被拒收，请清空其中的物品后再放入。
- 同类物品优先堆进已有的格子，那格满了会开新格。每格最多 99 个。
- 左键点格子取出 1 件，右键点格子一次取 5 件，格子里不够 5 件会全部取出，空间不够时停止取出。
- 老鼠和鱼这类养着的活物，取出顺序是后存入的先取出，格子贴图显示最新存入的那只。
- 物品会按真实品质分格堆放（纯度、正品赝品这些标签都算），取出来的时候标签会恢复成真实状态。
- 无法放入的物品：【储藏】、【机器】、酿造中的酒瓶、【赃物】、【模组】、【物资箱】、【节点】、【工具箱】，还有显示成问号的物品（见下面「其他 MOD 的物品」）。

**一键上货**：收纳箱窗口底下一排现在有四个按钮，从左到右是「全箱收纳」「全箱上货」「一键上货」「一键收纳」。

- 一键上货是把**这个箱子**里的东西摆上柜台卖，全箱上货是把**你所有收纳箱**里的东西摆上柜台。两个都只会在有顾客站在店里时工作。
- 上货只挑顾客想买的东西：他喜欢的类型才会被摆上去，不感兴趣的、以及官方规定不能卖给这位顾客的（比如警察不收违禁品）都会自动跳过。
- 摆上去的每件东西都按官方实时计价卡着顾客的预算，预算花光或柜台摆满就停。多样性的顾客（每样只买一件那种）每样只摆一件，不会把柜台摆满卖不掉的死货。
- 空桶、空电池这类"有容量却空着"的物件不自动上货——卖出价太低，留着等你装满再卖。
- 左键点格子下面的名字条可以锁格：锁住的格子不上货，图标左上角有官方"固定"同款小锁标记，悬停也有说明。格子清空或换物自动解锁。想整箱不参与全箱上货，去齿轮面板开"不参与全箱上货"——注意这个开关只影响全箱上货，箱子自己的一键上货照常能用。
- 四个快捷键都在齿轮面板里绑：一键收纳 / 一键上货是每个箱子各自的键，全箱收纳 / 全箱上货是全局共用一个键。绑定前会自动检查冲突，撞了官方按键或其他箱的键会拒绝并提示。
