# 卷帘门今日事件 Shutter Events 1.3.3

开店前在卷帘门上显示今日事件、价格影响和剩余持续时间。事件持续时间与标题同一行；4 条及以上事件自动分页，每页最多 3 条并提供上一页/下一页按钮；告示牌随卷帘门升起。

闭店后，同一块告示牌改为显示 **调查进度**（数值与进度条）和 **当前涉案总金额**（信用点）。金额来自治安调查档案中当前记录的案件合计；结案或消除后的历史金额不计入。进度口径沿用游戏：涉案金额不足 100 信用点或调查进度为负值时显示「暂无调查」。闭店时读取一次数值，随后保留这次快照；闭店存档读档或应用 Mod 设置时按需刷新，睡醒后恢复今日事件。

1.3.1 移除了闭店面板的逐帧计时组件和每半秒数据检查。面板显示期间不再持续检测调查数据。

告示牌仍为 250 × 184，沿用已保存的设置和原有默认值，无新增模组权限。

在主菜单的「模组」中选择「卷帘门今日事件 Shutter Events」，点击齿轮进入 **Mod 设置**，修改后点击「应用」。模组需要先启用并重新启动游戏，设置入口才可用。

- **字体大小**：50%～200%，默认 100%。调整标题、日期、事件和闭店调查文字的字号范围，告示牌与文字区域保持原尺寸。字号调大放不下时会自动回落到原 100% 范围，事件持续时间与标题同一行以保留更多纵向空间。
- **事件分页**：事件达到 4 条时启用分页，每页显示最多 3 条；点击告示牌底部的 `<` / `>` 翻页，页码显示在中间。3 条以内保持原来的单页布局。
- **背景颜色**：输入十六进制颜色，例如 `#203040`；可附加透明度，例如 `#203040CC`。留空保留原来的背景和标题栏。
- **字体颜色**：例如 `#FFFFFF` 为白色、`#FFC74A` 为黄色。设置后统一标题、日期、事件和闭店调查文字的颜色；留空保留原有多色文字。
- **隐藏无关事件**：默认关闭。开启后，只显示至少有一项非零价格修正的事件；同一事件中同时有涨价和跌价也会保留。无关事件不占前三条显示名额，也不计入「还有几条」。没有价格事件时会显示专用提示。

初次使用保持 1.1.0 的默认大小、配色和事件显示规则。颜色格式无效时回退到原配色；「恢复默认」后点击「应用」可以恢复全部默认设置。设置由游戏保存，跨存档生效。

从 1.2.0 更新时，旧的「告示牌大小」值不再生效，新的「字体大小」从 100% 开始。已经保存的背景颜色、字体颜色和事件过滤设置继续保留。

安装：将安装包中的 `shutter_events` 文件夹放入游戏 `Mods` 目录。若已安装旧版，将包内文件覆盖到原模组文件夹；文件夹名称不影响模组 ID。通过游戏模组菜单启用；更新 DLL 后重新启动游戏。

构建：`dotnet build ShutterEvents.csproj -c Release`。可以用 `-p:GameDir="游戏目录"` 指定游戏位置。

逻辑验证：`dotnet run --project tests/ShutterEvents.Checks.csproj -c Release -- "游戏目录/Probably Stolen_Data/Managed" "待验证的模组文件夹"`。测试使用编译后的模组和游戏程序集，验证默认值、已保存设置、颜色输入、事件过滤、闭店调查数据及完整模组文件夹权限扫描，不写入玩家配置或存档。
