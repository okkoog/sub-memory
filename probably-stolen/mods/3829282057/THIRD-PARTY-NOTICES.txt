Unicode data and reference-implementation notice
================================================

The following files in this directory are derived from Unicode Consortium material:

- UnicodeData.Generated.cs : tables generated by tools/gen_unicode_tables.py from the Unicode Character Database 15.1.0
  (UnicodeData.txt, ArabicShaping.txt, BidiBrackets.txt, BidiMirroring.txt, extracted/DerivedBidiClass.txt).
  SHA-256 values of the exact inputs are recorded in the file header.
- UnicodeBidi.cs : C# port of the Unicode reference implementation of the Bidirectional Algorithm (UAX #9),
  BidiReference.java and BidiPBAReference.java (https://www.unicode.org/Public/PROGRAMS/BidiReferenceJava/,
  by Doug Felt, Roozbeh Pournader, Asmus Freytag and Deepak Jois).
- ArabicShaper.cs : uses the joining types of ArabicShaping.txt and the presentation-form mappings of UnicodeData.txt
  (through the generated tables).
