# 香烟拓展：正式版

版本：0.5.4。使用官方模组加载器，以正式版酿酒拓展 `brewing_expansion` 为必需前置。兼容首个正式版公开发布以来的存档，不兼容Demo／MelonLoader旧档。

## 0.5.4 尼古丁摄入修复与香烟提示精简

拥有尼古丁成瘾特质时，右键自有香烟可选择「摄入」，消耗一包并按原版规则缓解戒断。双击打开烟况与贴牌检查。

香烟提示使用白色正文显示稀有度和口味文案，移除正文中的检查、贴牌及摄入说明。凡间、远来、情思和遗光分别拥有独立的灰色斜体短句。旧物品加载时刷新描述和短句。

## 0.5.3.9 新版加载器适配

语言刷新由模组自己持有的场景组件运行，停用时立即取消，重新启用后重新建立。移除新版扫描器报告的待弃用后台运行能力警告，不增加权限。配方、委托规则和存档格式沿用0.5.3.8。

## 0.5.3.8 委托酒品质与中文机器说明

每日普通委托刷新为6个：3个香烟委托、3个酒类委托。其中1个香烟委托保底为「4包基础烟，或2包任意凡间风味烟（不含基础烟）」。两条路线任选其一，首次实际提交后锁定路线，不混交；仍要求真品与烟况完好，期限及奖励沿用普通委托。完成和领取只结算一次。特殊印章委托仍额外出现。外环区声望达到−60时仍只提供1个委托，优先保留此保底；−80时仍不能接取。

已接委托的进度和奖励保留。升级时仅调整当天尚未接取的旧委托，并扣除当天已使用的名额；次日完整按3烟3酒刷新。同一天接走的委托不会反复补出，待完成委托上限仍为5个。

委托种子奖励先抽稀有度，再在该档内等概率抽品种。普通委托的凡间（含烟草）／远来／情思／遗光概率为75%／20%／4%／1%，稀有委托为55%／30%／12%／3%，珍稀委托为35%／35%／23%／7%。特殊印章委托按自身委托等级使用对应概率。数量仍为普通4颗、稀有6颗、珍稀10颗、特殊4颗，已接取委托中确定的奖励种子保留。

四种一次性公司贴牌基础售价调整为10／25／60／120信用点，实际购买价格继续应用原版难度和当天折扣。公司加价、贴牌出现概率、委托信用点及声望奖励保持原规则。

物品提示按原版字体的实际字宽换行，尽量把完整单词和数字单位留在同一行。制烟机和烘干机的说明页去掉重复标题，用空行分隔准备步骤与后续操作。中文步骤编号可在原版手写字体中显示。

17 种香烟介绍的第一行显示凡间、远来、情思或遗光稀有度，基础香烟归入凡间。

香烟灯牌可收进原版档案箱，放在橱窗中才会吸引专属访客。夜间香烟商店每天有 20% 概率举行当天九折活动，地图卡片会显示优惠。

物品提示底部的模组来源署名按当前语言显示，旧物品保存的中文署名也会使用正确的本地化名称。沿用已有资源就绪流程，不改写磁盘清单名称。

委托收酒按委托人要求品质：拾荒客、星际客至少3分（量产酒液），上层区顾客至少5分（臻品窖藏），其他委托人与xuxu特殊委托保持至少5分。委托详情及选货要求行显示对应门槛，库存选货仅列出合格的酒，提交时再次核对实际品质。已接取委托的剩余交付使用对应委托人门槛，已提交进度保留。

## 0.5.3.7 标签交易修复

修复改过真伪和烟况标签的香烟在批量出售时可能卡住的问题，也覆盖放在未上锁容器内一起出售的香烟。能识破的顾客会在确认出售时揭露标签并给出修正报价，玩家可再次确认成交。

## 0.5.3.6 委托选货、放大镜鉴定与机器收纳

点击「从库存提交」会在委托机内打开选货清单。每件合格物品单独列出名称、估值和位置，容器里的物品也会显示外层容器所在的格子。默认勾选估值最低的货品，可以换选或只交一部分，确认后才会扣除勾选的物品。

放大镜使用游戏的原版对质面板。烟盒标示为正品时会出现五项包装问题，标示为赝品时只显示「正品」供反向指认。停用香烟拓展时会清理留在放大镜里的果味烟贴图。

修复未付款的盒装卷烟纸可放入制烟机的问题。香烟拓展的制烟机和烘干机只接收已拥有的物品。已拥有的纸盒也只接收已拥有的散纸，刷新纸盒时保留纸张原有的所有权。盒装卷烟纸付款后可整盒放入烟纸区。

## 0.5.3.5：中英文整理

补齐物品、机器、顾客、委托及印章界面的中英文语言表，校验17种香烟的英文描述，并补齐三本故事书共40页英文正文。中文原稿和故事页面保留；英文正文使用可翻页文字，避免缩小字体。英文名称、期限与数量单位采用完整句式，修复空格被裁掉后文字挤在一起的问题。读取正式版旧档时刷新自有物品和顾客的显示文字，保留其身份、品质、价格与库存位置。

继续接入玩家提供的俄语、法语、日语、德语和波兰语译文，补齐完整句式模板，并核对与酿酒拓展的酒名。三本故事的这五种语言同样使用实时正文，去掉固定宽度的硬换行，由界面正常排版。鉴定手册目前只有中文和英文图片，新增语言沿用英文图版；物品图案及公司商标保留原设计。

请在游戏设置中选择语言后完全退出并重启。本轮冷启动中英文已验证；运行中切换语言仍观察到原版词条加载错误，暂不作为稳定支持流程。工程校验与测试记录见research/tobacco-localization-implementation-20261104。七语言版本已在创意工坊发布。

## 0.5.3.5：原版规则整理

书本激活、印章机和盒装卷烟纸开窗、机器分区收纳与委托机场景生命周期改用物品自身回调及原版规则；合并重复的顾客到访处理。三批共移除15个补丁类，保留57个适配；真品防误判及如实标为赝品的验真查询交由原版规则处理；鉴定指认直接使用已同步的实际包装标签，辰子气泡颜色在自身创建和恢复时配置。物品ID、机器库存顺序、配方、价格和委托奖励规则不变，继续兼容正式版存档。

## 0.5.3.4：启动中文词条保护

修复部分加载顺序下安装香烟补丁提前触发原版词条静态初始化、导致无效资源句柄与香烟启动失败的问题。全部香烟补丁先跳过加载器最早的自动安装阶段，等待资产、玩家语言和原版词条就绪后再安装；不修改玩家语言或原版全局本地化逻辑。发生过该错误的进程需要完全退出并重新启动，不能靠同一次运行中重新启用模组恢复。

## 0.5.3.4：顾客喜好显示与加价

修复顾客售货、批发等新版交易页面不显示喜好的问题。喜好在空柜台时即可查看，放上物品后继续显示。口味喜好加价10%；正品、赝品、瑕疵品的品质喜好也各加价10%，口味与品质同时匹配则合计加价20%。例如偏好黄瓜正品烟，提交符合条件的香烟时获得20%喜好加价。保留真假/烟况标签鉴定与识破规则。

## 0.5.3.4：委托机点击拦截

修复点击委托窗口会选中、拖动或操作后方柜台/仓库物品的问题。使用原生物品输入可识别的透明拦截层，只覆盖当前委托窗口，保留窗口大小、移动、正文滚动和按钮操作；关闭后解除拦截。不修改物品ID、玩法数值或存档结构。

需要配套酿酒3.6.7.5或更新版本。通过前置公开的标准服务接口注册烟草孵化配方，不再访问酿酒内部类型或直接引用其DLL；沿用酿酒的孵化配额、扣电与交易检查。等待本模组资产与原版本地化资源就绪后初始化，保留前置加载顺序修复。权限清单为空，不修改玩法数值、物品ID或存档结构；已完成配套接口与孵化、首发旧档读取和当前档保存重启验证；版本号统一后的构建另外完成编译与独立清单扫描。

## 新手怎么玩

1. 晚上到辰子的香烟商店购买烟草种子、孵化器、刀具、卷烟纸与机器。共享的孵化器、电池和收纳由前置酿酒拓展提供；机器需要有电的电池。商店报价受原版难度等规则影响。
2. 烟草种子放进孵化器，过夜获得烟草。烟草先烘干，再把刀具拖到干烟草上切丝：普通刀具得到1份，xuxu小刀得到2份。没有烘干机时，烟草放置两天也能成为受潮的干烟草，但湿材料制出的烟有不可修复的瑕疵，价值降低30%。
3. 双击制烟机，按区放入烟丝、卷烟纸和电池，点击开始加工。每包消耗1份烟丝、2张纸、4电量；整盒卷烟纸可直接放入烟纸区，空盒保留。不放提取液可制基础烟。
4. 想制果味烟：先在酿酒拓展中制作原浆，把针管拖到原浆上抽取，再将装有提取液的针管放入制烟机提取液区。每次抽四分之一原浆，每包用1份，每支针管最多提取2次。梦尘区是可选项，放入的全部含快感／毒性的药品（包括整组数量）会合并到同一包烟；不放也能制烟。
5. 手工自制的公司价格减20%。一次性贴牌拖到自己的一包香烟上会消耗1张，替换显示的公司与公司加减价；永久印章则需放进印章机并激活，再拖印章机盖章，可重复使用。四家公司分别为帕斯泰尔0%、远日点20%、开普勒40%、xuxu外环公司80%。公司修正相互替换，不叠加，也不是在当前报价上再乘这些百分比。
6. 双击香烟检查烟况；鉴别真伪另用放大镜与鉴定手册。「检查贴牌」会撕掉一次性贴牌，恢复原公司和价格，不退回贴牌。会检查公司标签的顾客在确认出售时识破贴牌，会扣10点外环区声望。交易面板可先查看顾客喜好，再挑选货物。
7. 展示香烟灯牌可邀请烟贩与每天售卖贴牌的辰子。桌上的外环区委托机独立运作：接取委托 → 进入待完成委托并选择笑脸 → 从库存提交 → 完成后领取奖励。默认要求实际真品、烟况完好，特殊要求以详情为准；贴牌不会抬高委托的真实估值。信用点与声望立即结算，种子和印章送到柜台，放不下的保留待领取。未完成委托逾期失败，已交物品不退；已完成未领取的到期自动结算。
8. 一周内完成7个委托，可解锁下一枚公司印章的特殊委托。委托人是xuxu，接取后3天内交满5件指定品质烟酒，可全部交烟或全部交酒。奖励印章、5声望与4颗种子，不发信用点；失败需等下周重新达到条件。印章不在辰子处出售。
