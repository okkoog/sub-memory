# Probably Stolen 한국어 화학 가이드

## 설치와 사용

1. 게임의 `Mods`에 `ChemGuide` 폴더를 놓습니다. 이전 수동 설치본을 업데이트한다면 기존 `ChemGuideKO` 폴더를 먼저 빼 두세요. Steam 기본 경로는 `steamapps\common\Probably Stolen\Mods`입니다.
2. 게임을 재시작한 뒤 모드 목록에서 **화학 가이드**를 활성화합니다.
3. 용기, 재료, 완성품, 증발기, 화학 마감기를 우클릭하고 **화학 가이드**를 누릅니다. 화학과 관계없는 아이템에는 이 항목이 나오지 않습니다. 가게에서는 설정한 단축키(기본 F7)로 열고 닫을 수 있습니다.
4. 용기를 열면 기본값은 **자동 · 현재 성분으로 판별**입니다. 분석기 없이도 **제작 안내**에서 판별한 제품, 판별에 쓰인 성분량, 다음 행동과 목표 온도를 확인할 수 있습니다. 드림 캡 추출액처럼 여러 제품에 쓸 수 있는 경우에는 목록에서 목표를 선택하세요.

창을 열어 둔 채 다른 용기를 우클릭하면 창 위치와 보던 탭은 그대로 두고 대상만 바뀝니다. 선택한 용기는 0.25초마다 직접 읽습니다. **성분** 탭에서 성분명, 현재량, 배합 비율을 표로 확인할 수 있습니다. **레시피** 탭에서는 선택한 제품의 용도, 전체 제작 순서, 전분 준비법을 볼 수 있습니다.

생 드림 캡이나 감자 같은 재료 원물을 열면 성분과 함께 "블렌더로 갈아 용기에 담으라"는 안내와 필요한 알코올 양만 표시합니다.

## 1.3.0

- 메인 메뉴에서 **모드 → 화학 가이드 → 설정 → 가이드 단축키**를 선택해 원하는 키를 고르고 적용할 수 있습니다. 모든 세이브에 적용되며 기본값으로 돌아가려면 F7을 선택하고 적용하세요.

## 0.8.0 새 화면

글자 창 대신 직접 그린 계기판 화면을 씁니다.

- **상세 창** · 단계 표시줄, 지금 할 일 카드, 온도 눈금(반응 구간 초록, 끓거나 분해되는 구간 빨강), 성분 막대와 목록, 완성품 1개 판정 타일(순도·독성·효능·개수)을 한 화면에 보여 줍니다. 제품 이름을 누르면 목표를 바꿀 수 있습니다.
- **작업 바** · 창을 닫으면 한 줄 바로 남습니다. 바의 X를 누르면 완전히 닫힙니다. 끌어서 옮긴 위치는 창과 바 각각 저장됩니다.
- **증발기** · 건조 단계에서 가게의 증발기를 최대 3대까지 찾아 대마다 상태(비어 있음, 사용 중, 전력 부족), 하루 처리량, 이 배치를 넣으면 걸리는 일수를 보여 줍니다.
- **아이콘 버튼** · 책(제작 순서), 과녁(다음에 스캔하는 용기로 전환), 핀(항상 위), 톱니(설정), 줄이기, 닫기.
- **설정** · 톱니를 누르면 창 안에서 펼쳐집니다. 항상 위, 작업 바, 증발기 표시, 크기, 불투명도, 최소 등급, 커피 물 추출, 마감기 모듈 수, 스포이드 안내는 바로 바꿀 수 있습니다. 알코올 병 농도와 희석액 유효량처럼 숫자를 적는 값은 누르면 게임의 모드 설정 창이 열립니다.

### 0.8.1

- **언어** · 화면의 이름표와 설정 항목을 게임이 지원하는 11개 언어로 보여 줍니다. 기본은 게임 언어를 따르는 자동이고, 설정의 언어에서 직접 고를 수 있습니다. 0.9.0부터 지금 할 일 안내문, 판정 설명, 제작 순서도 같은 11개 언어로 나옵니다. 가이드가 만드는 한국어 문장을 화면에 그리기 직전에 번역하므로, 번역 표에 없는 문장은 한국어 그대로 보입니다.
- **창 크기** · 기본과 작게 두 가지입니다. 작게는 단계, 지금 할 일, 온도, 판정 요약 한 줄만 보여 줍니다. 창 위의 크기 아이콘이나 설정에서 바꿉니다.
- 설정이나 목표 목록을 열면 그 내용만 보여 줍니다.

아래 설명 중 탭과 입력 칸에 관한 부분은 0.7까지의 글자 창 기준입니다.
## 연속 추출 (1.0.0)

알코올은 그대로 두고 죽만 나눠 넣어, 적은 알코올로 최대 수율을 유지하는 방법을 가이드가 대신 반복합니다. 추출은 알코올을 소모하지 않으므로 같은 알코올을 계속 쓸 수 있고, 말릴 용매가 늘지 않아 증발기 하루 처리량 안에 들기 쉽습니다.

1. 알코올이 든 반응 용기에서 가이드를 엽니다. 드림 캡·나이트메어 캡·커피(알코올 경로)에서 **연속 추출** 칸이 나옵니다.
2. 죽이 든 재료 용기를 칸의 네모에 끌어다 놓거나, **재료 선택**을 누른 뒤 그 용기를 클릭합니다. 용기는 원래 자리에 그대로 있고 가이드는 어느 용기인지만 기억합니다.
3. **시작**을 누르면, 반응 용기의 죽이 0 mL이고 온도가 맞을 때마다 1회분을 옮깁니다. 드림·나이트메어는 40°C 이상 50°C 미만, 커피는 50°C 이상 78°C 미만입니다.

- 1회 투입량은 죽이 알코올의 1/5(커피는 4/3)을 넘지 않도록 계산합니다.
- 반응 용기가 가득 차거나 말릴 양이 가게 증발기의 하루 처리량을 넘게 되면 멈춥니다. 하루 한도는 설정에서 끌 수 있습니다.
- 다른 용기에서 가이드를 열면 멈춥니다.
- 설정의 **연속 추출 (재료 자동 투입) 사용**을 끄면 이 칸이 사라지고 가이드는 예전처럼 안내만 합니다.

옮기는 양과 조건은 손으로 할 때와 같고 수율·온도는 게임이 그대로 계산하지만, 손을 대지 않고 액체가 옮겨지는 기능입니다.
## 시약 고순도 정제와 복구 (1.1.0)

산·염기·환원제·리포본드 결합제 병은 살 때부터 불순물이 2~8% 섞여 있습니다(화학 오염물, 물리적 오염물, 미생물, 중금속이 무작위 비율). 가이드가 이 시약을 순도 99% 이상으로 올리는 순서를 안내하고, 다른 것이 섞인 시약을 되살릴 수 있는지도 판정합니다.

1. 시약이 든 용기를 우클릭해 가이드를 엽니다. 한 가지 시약이 절반 이상이고 순도가 99% 미만이면 자동으로 정제 안내가 뜹니다. 직접 고르려면 목표 목록 맨 아래의 **산 / 염기 / 환원제 / 리포본드 결합제 고순도 정제**를 선택하세요.
2. "지금 할 일"이 다음 한 단계를, 그 아래가 현재 순도, 남은 순서, 예상 최종 순도를 보여 줍니다.
3. 산·염기를 알코올에 탄 용기는 예전처럼 희석액 안내가 뜹니다.

| 섞인 것 | 빼는 방법 | 남는 양 |
|---|---|---|
| 미생물 | 산·염기는 스스로 죽임(미생물의 1% 소모). 환원제는 70°C 이상 가열 또는 자외선 필터. 결합제는 자외선 필터만 | 0 |
| 물리적 오염물·미네랄·유기 폐기물·미세플라스틱 | 정수 필터를 끼운 물 피처 | 걸린 양의 약 0.16% |
| 불용성 이물질·식물질·죽 | 코튼 원단 | 0 |
| 화학 오염물 | 물 1 mL + 물 정화 정제 | 전체 부피의 0.7% |
| 중금속, 남은 화학 오염물 | 하수로 틸라피아 어항(무게 100 g당 하룻밤 0.5 mL) | 어항 물의 0.25% / 0.16% |
| 물·알코올·결합제 | 증발기 또는 가열판(100°C / 78.4°C / 55°C 초과) | 0 |
| 단백질·안정제 (산·염기) | 저절로 침전 → 코튼 원단 | 시약이 그만큼 소모됨 |
| 지방 | 리포본드 결합제(8:1) → 코튼 원단 | 0 |
| 반대 성질의 시약 | 1:1 중화 | 같은 양의 시약을 잃음 |
| 당분·전분·카페인·다른 시약·추출액 | 분리 불가 | 순수한 시약을 섞어 묽히는 양을 계산 |

- **정수기와 하이드로리드(수초)는 쓰지 않습니다.** 둘 다 시약 자체를 제거 대상으로 보고 물로 바꿉니다. 정수기는 입자가 큰 것부터 지우는데 시약(5)이 중금속(12, 마지막 순서)보다 먼저 지워집니다.
- **틸라피아 어항**에는 물이 조금이라도 있어야 합니다(물이 0이면 전혀 줄지 않음). 바닥값이 어항 물의 양에 비례하므로 물은 10 mL쯤만 넣습니다. 먹은 만큼 물로 바뀌므로 끝난 뒤 말립니다. 어항 액체 전체가 물고기 필요 수량(200 g 350 mL, 450 g 750 mL, 600 g 1,000 mL)의 절반 아래면 물고기가 죽으니 병을 여러 개 합치세요.
- **리포본드 결합제**는 55°C에서 가장 먼저 끓기 때문에 물이나 알코올을 빼낼 수 없고, 틸라피아가 먹은 오염물도 물로 남습니다. 병을 스캔해 깨끗한 병을 고르는 것이 유일한 방법입니다.
- **증발기 회수 용기**로 결합제를 모을 수는 없습니다. 용매 회수 모듈을 끼운 증발기는 알코올만 회수하고 결합제와 물은 버립니다(회수량은 증발량 × 장비 품질 보너스%).
- 제품 배치에 중금속이 0.05 mL 이상 남으면 제작 안내의 참고 줄에 틸라피아 복구 방법이 함께 나옵니다.
- 물고기 없이 99%를 넘기려면 중금속이 약 0.3%(250 mL 병에서 0.75 mL) 이하인 병을 고르세요. 정제가 화학 오염물을 0.7%까지 줄입니다.

게임 0.46D의 코드(병 불순물 생성, 필터, 염소, 양식, 정수기, 수초, 끓는점)에서 읽은 값이고, 안내 문구는 자동 검사 22건을 통과했습니다. 게임 화면에서 직접 해 보지는 않았습니다. 특히 어항에 시약을 부을 수 있는지는 코드에서 막는 곳을 찾지 못했을 뿐 실제로 확인하지 않았습니다. 이 안내문은 아직 한국어로만 나옵니다.

## 시약 오염물 제거표와 틸라피아 어항 예상 (1.2.0)

목표 목록 맨 아래의 **시약 오염물 제거표**를 고르면 가이드 창이 표로 바뀝니다. 탭이 세 개입니다.

- **섞인 것별 제거 방법**: 미생물·중금속·화학 오염물 등 12가지를 산·염기 / 환원제 / 리포본드 결합제 열로 나눠 제거·저절로·일부·불가로 표시합니다.
- **도구별**: 코튼 원단, 정수 필터, 자외선 필터, 물 정화 정제, 틸라피아, 증발기가 지우는 것과 남는 양.
- **틸라피아 어항**: 가게의 어항마다 오염물을 먹는 물고기 수와 성숙도, 합계 무게, 하룻밤 제거량을 보여 줍니다. 어항 안의 중금속·화학 오염물·물리적 오염물이 첫날 밤 얼마나 줄고, 얼마가 남고, 며칠 만에 사라지는지 표로 나옵니다. 오염물이 든 용기를 우클릭해 연결해 두면 그 용기를 부었을 때의 예상도 함께 나옵니다. 성숙도별 한 마리 제거량 표도 아래에 있습니다.

시약 고순도 정제 안내 중에도 연결한 용기에 틸라피아가 먹을 오염물이 있고 가게에 먹는 물고기가 있으면 어항 예상이 함께 뜹니다.

계산 방식(게임 0.46D 코드): 살아 있는 물고기(알·치어 무리 제외)의 무게 100 g당 하룻밤 0.5 mL를 세 오염물 각각에서 뺍니다. 바닥값은 어항 물의 0.25% / 0.16% / 0.07%이고, 먹은 양은 물이 되어 바닥값이 조금씩 오릅니다. 그래서 물이 많은 어항에 병을 부으면 전혀 줄지 않을 수 있고, 표에는 "이미 바닥"으로 나옵니다. 어항 액체가 물고기 전체 필요 수량의 절반 아래면 그날 밤 전부 죽습니다. 게임은 물고기를 먼저 자라게 한 뒤 물을 검사하므로, 가이드는 오늘 밤 자란 뒤의 필요 수량(이틀 치 성장까지)으로 경고합니다. 예: 유어 13마리와 내일 준성체가 되는 틸라피아 5마리는 낮에는 1,800 mL지만 밤에는 3,050 mL가 필요해, 액체 1,420 mL로는 전멸합니다(1.2.1에서 반영). 무게는 현재 값을 쓰므로 물고기가 자라면 실제는 더 빠릅니다. 계산은 자동 검사 33건을 통과했지만 게임 화면에서 직접 확인하지는 않았습니다. 이 화면은 아직 한국어로만 나옵니다.

## 완성품 한 개를 기준으로 보는 방법

**제작 안내**에서 강조된 단계와 다음 행동을 확인하세요. **완성품** 탭은 1개당 예상 등급, 순도, 독성 점수, 도취감, 효능 판정과 성분별 양을 표시합니다. 젖은 배치는 건조 후를 가정합니다. 실제 바이알이나 알약을 열면 그 물건에 기록된 순도와 게임의 독성·치사·도취 판정을 읽습니다.

### 제품별 효능 기준

게임의 고객 반응 판정을 그대로 따릅니다. 설정과 관계없이 항상 확인합니다.

| 제품 | 용도 | 항의를 받지 않는 조건 |
|---|---|---|
| 드림 더스트, 판타 정 | 마약 | 1개의 도취 점수 1,000 이상 (드림 더스트는 순도 50% 이상) |
| 카페인 정, 노모어 주입기 | 의약 | 순도 45% 이상 |
| 피임약 | 피임 | 1개에 피임 호르몬 0.05 mL 이상 (순도 50% 이상) |
| 자이아나이드 정, 나이트메어 더스트 | 독약 | 1개의 독성 점수 1,000 이상 (치사) |

독약은 독성을 피하는 대상이 아니라 치사에 도달해야 하는 제품입니다. 가이드는 독약에 전분 희석을 권하지 않습니다.

자이아나이드 정은 마감기 1정이 0.6 mL라서 자이아나이드만으로는 최대 996점이고 치사가 될 수 없습니다. 이때 가이드는 치사에 필요한 나이트메어 추출액의 양을 계산해 안내합니다. 시판 자이아나이드 정(자이아나이드 1 mL)은 이미 치사이므로 풀어서 다시 출력하면 오히려 약해집니다.

### 독성은 항상 750 미만이어야 합니다

게임은 독약이 아닌 제품이 독성 구간(750 이상)이면 치사 미만이어도 항상 항의와 보상 요구, 평판 하락으로 처리합니다. "치사만 아니면 괜찮은" 제품은 없습니다. 그래서 0.6.1부터 독성 한도는 설정이 아니라 고정 규칙입니다.

독성 구간에 들면 750 아래로 내려가는 최소 정수 mL의 전분을 계산합니다. 희석 결과가 최소 등급이나 효능 기준에 못 미치면 투입을 권하지 않고 이유를 설명합니다. 등급 구간이 바뀌는 경우에는 "등급 변화"로 알려 줍니다. 판타는 순도 75% 이상이면 독성 구간이라 무독성으로 팔 수 있는 최고 등급은 시중 표준입니다.

### 설정 → 최소 등급

제한 없음 / 고물 등급 (30%) ~ 실험실 순도 (99%) 중에서 고릅니다. 이 순도 아래로는 마감도, 전분 희석도 권하지 않습니다. 선택은 자동 저장됩니다. 기본값은 고물 등급입니다. 0.7.3부터는 0.5의 옛 설정을 이어받지 않습니다(게임의 모드 검사가 설정 내부를 읽는 것을 막습니다).

### 자동 판별

용기에 든 성분 중 양이 가장 많은 제품을 자동으로 고릅니다. 다른 후보가 있으면 "다른 후보"로 이름만 보여 주고, 위 목록에서 바꿀 수 있습니다. 1개 분량의 절반에도 못 미치고 건조 성분의 1%도 안 되는 미량 성분, 그리고 주성분의 5%에 못 미치는 성분은 후보에서 제외합니다. 드림 캡 추출액만 있으면 드림 더스트를 먼저 고르고, 환원제나 노모어가 있으면 노모어로 판별합니다.

### 제작 안내 화면

"지금 할 일"은 해야 할 행동을 밝은 색으로, 설명을 흐린 색으로 줄을 나눠 보여 줍니다. "완성품 1개 판정"은 등급·독성·효능·마감기·조정을 항목, 예상값, 판정의 세 칸짜리 표로 보여 주고, 판정은 충족이면 녹색, 미달이면 노란색, 치사면 붉은색입니다.

### 전분은 감자에서 얻습니다

게임에 순수 전분 아이템은 없습니다. 감자 100 g에 전분 17.33 mL가 들어 있고, 가이드는 필요한 전분량을 감자 무게로도 표시합니다. 감자를 갈아 단백질 처리 → 여과 → 건조한 가루(전분 약 96%)를 희석용으로 쓰세요. 순서는 레시피 탭에 있습니다.

### 화학 마감기 모듈 수

모듈 수는 자동으로 읽습니다. 용기가 마감기 슬롯에 들어 있으면 그 마감기를, 아니면 가게에 있는 마감기를 확인합니다. 마감기를 찾지 못하거나 마감기마다 모듈 수가 다를 때만 설정에 적어 둔 값을 씁니다. 그것도 없으면 독성은 손실 없음 기준, 등급과 효능은 모듈 0개 기준으로 보수적으로 판정합니다. 마감기를 우클릭해 가이드를 열면 슬롯의 용기를 따라갑니다.

## 제작 안내가 계산하는 것

- **안정제 제거** · 필요한 산의 양을 한 번에 계산합니다. 산은 천천히 줄어들기 때문에 1 mL가 안정제 약 5.5 mL를 없앱니다. 기본 N-메틸올 베이스 병(안정제 125 mL)은 산 28 mL입니다.
- **단백질 처리를 추출과 함께** · 죽에 단백질이 있으면 알코올을 넣을 때 필요한 산도 함께 넣으라고 안내합니다. 게임에서 단백질 침전은 온도·알코올·부피와 무관하고 추출은 산·염기의 영향을 받지 않아 손해가 없고, 두 반응이 동시에 진행되어 기다리는 시간이 줄어듭니다. 필요한 산의 양은 순서와 관계없이 같습니다.
- **커피 알코올 추출** · 50°C 이상 78°C 미만입니다. 알코올은 78.4°C부터 끓어 날아갑니다.
- **노모어** · 알코올이 배치의 10%를 넘으면 반응하지 않습니다. 환원제와 결합제를 넣은 뒤의 비율로 판단하므로, 시약만 넣어도 풀리는 경우에는 증발기를 거치지 않습니다.
- **노모어의 리포본드 결합제** · 게임은 이 반응에서 결합제를 소모하지 않습니다. 결합제는 1초마다 반응하는 양을 min(1, 결합제×4÷추출액)배로 조절할 뿐이고, 아무리 적어도 1초에 0.1 mL는 반응합니다. 넣은 만큼 그대로 남아 나중에 날려야 하므로 0.7.4부터 추출액의 25%가 아니라 5%(최소 1 mL)를 권하고 예상 반응 시간을 함께 보여 줍니다. 추출액 100 mL 기준으로 5 mL는 약 80초, 25 mL는 약 55초입니다. 환원제는 추출액과 1:1로 소모되고 반응량의 60%가 노모어, 40%가 불용성 이물질이 됩니다.
- **가열판 건조** · 노모어와 카페인은 열에 분해되지 않습니다. 건조 단계에서 열에 약한 성분(버섯 죽·추출액, 판타)이 남아 있지 않으면 리포본드 결합제(55°C 초과)와 알코올(78.4°C 초과)을 가열판으로 끓여 없애는 방법과 걸리는 시간을 함께 안내합니다. 끓는점을 넘으면 1초에 2%(최소 0.1 mL)씩 줄어듭니다. 물은 100°C를 넘겨야 합니다.
- **정제** · 독성 한도와 관계없이 지방, 단백질, 이물질, 오염물 처리를 마감보다 먼저 안내합니다. 정수 필터는 물리적 오염물, 미네랄, 유기 폐기물, 미세플라스틱을 거릅니다.

여과 후에는 받는 용기를 우클릭하거나 창 위쪽의 **다음에 스캔하는 용기로 전환**을 켜고 스캔하세요.

## 산·염기 희석액 (스포이드용)

스포이드는 1 mL씩만 옮기므로 산이나 염기를 0.1 mL, 0.5 mL처럼 적게 넣을 수 없습니다. 순수 알코올로 미리 묽혀 두면 스포이드 1 mL에 원하는 양만 들어갑니다.

1. 산(또는 염기)이 든 용기를 우클릭해 가이드를 엽니다. 제품 원료가 없고 산·염기만 든 용기는 자동으로 희석 안내가 뜹니다. 직접 고르려면 창 위 목록 맨 아래의 **산 희석액 만들기** / **염기 희석액 만들기**를 선택하세요.
2. 입력 칸에 **스포이드 1 mL당 유효량**을 적습니다. 예: 0.1, 0.5. 산과 염기 값은 따로 저장되고 게임을 다시 켜도 남습니다.
3. 그 아래 칸에 **더 넣을 원액의 농도(%)**를 적습니다. 순수한 산·염기면 100 그대로 둡니다. 이 값도 산과 염기 따로 저장됩니다.
4. 가이드가 용기 상태에 맞춰 무엇을 얼마나 넣을지 알려 줍니다. 목표보다 진하면 순수 알코올을, 묽거나 알코올만 담겨 있으면 원액을 넣으라고 안내합니다. 양은 1 mL 단위입니다.

| 상황 | 안내 |
|---|---|
| 유효 산 10 mL, 목표 0.1 | 순수 알코올 90 mL → 전체 100 mL, 100회분 |
| 용기가 작을 때 | 소량으로 만들기 · 빈 용기에 이 용액 스포이드 1회 + 알코올 스포이드 9회 |
| 목표보다 묽을 때 (알코올 500 mL에 산 0.97 mL, 목표 0.1) | 산 원액(농도 100%) 55 mL 더 넣기 |
| 알코올만 담긴 용기 (90 mL, 목표 0.1) | 산 원액(농도 100%) 10 mL 더 넣기 → 전체 100 mL |
| 빈 용기 | 원액 스포이드 1회 + 알코올 스포이드 9회 |
| 원액이 목표보다 묽을 때 | 맞출 수 없다고 알리고 더 진한 원액이나 낮은 목표를 권함 |
| 산과 염기가 섞였을 때 | 1:1로 중화된 뒤 남는 양으로 계산 |

희석액 1 mL에는 알코올이 함께 들어갑니다(0.1짜리는 0.9 mL). 증발기에서 제거되지만, 노모어는 알코올이 배치의 10%를 넘으면 반응하지 않으니 주의하세요. 산·염기와 알코올은 보관 중에 줄지 않습니다.

### 중화 필요량을 스포이드 횟수로

설정 탭의 **중화 필요량을 희석액 스포이드 횟수로 안내**(기본 켜짐)를 켜면, 제작 안내가 남은 산·염기를 1 mL 단위 원액과 희석액 스포이드 횟수로 나눠 알려 줍니다. 예: 남은 염기 3.3 mL → "유효 산 3 mL + 산 희석액 스포이드 3회". 원액 농도를 50%로 적어 두었다면 "산 원액(농도 50%) 6 mL + 산 희석액 스포이드 3회"로 바뀝니다. 희석액 한 번의 절반보다 적게 남은 양은 생략합니다. 끄면 예전처럼 1 mL 단위로만 안내하고 0.5 mL 미만은 생략합니다.

## 증발기 건조 시간

증발기 또는 메인 슬롯의 용기를 우클릭해 가이드를 여세요. **제작 안내**에 남은 용매, 하루 처리량, 완전 건조까지 남은 일수가 표시됩니다. 장비의 현재 성능과 전력을 읽어 매일 밤 한 번 가동하는 기준으로 예상합니다. 배터리가 부족하면 전력이 공급된 뒤 필요한 기간을 표시합니다.

## 검증 범위

게임 0.46D의 코드에서 고객 반응 판정(용도별 효능, 독성·치사 기준), 마감기 분배와 손실, 반응식, 끓는점, 필터 구멍 크기, 감자 성분, 증발기 처리량을 대조했습니다.

0.6.1은 게임의 Mono 런타임에서 독약 판정, 제품별 효능 기준, 자동 판별과 미량 제외, 무독성 희석과 최소 등급의 조합, 안정제 투입량, 알코올 상한, 창 재사용, 재료 원물, 완성품, 증발기와 마감기 연동을 검사했고, 제작 진단 문구 60건을 따로 검사했습니다. 새 표 형태의 제작 안내 화면은 게임에서 직접 확인하지 않았습니다.

0.7.4는 게임 0.46D의 반응식 22개를 다시 대조했습니다. 노모어 결합제 권장량과 가열판 건조 안내 외에 틀린 수치는 찾지 못했습니다. 새 안내 문구는 자동 검사만 통과했고 게임 화면에서는 확인하지 않았습니다.

0.7.0은 같은 방식으로 희석 계산, 입력값 저장과 검증, 산·염기 용기 자동 인식, 중화 횟수 안내와 그 설정을 검사했고 진단 문구는 65건입니다. 0.7.1은 원액 농도 입력, 묽은 용기와 알코올만 담긴 용기에 넣을 원액량 계산을 더해 같은 검사를 통과했습니다. 원액 농도 입력 칸은 게임 화면에서 확인하지 않았습니다.
