# 自学习强化机：兼容性说明

本说明只覆盖四类接入：

1. Mod 电源接入建议；
2. Mod 自学习上限接入建议；
3. Mod 自学习步数修改接入建议；
4. 不会被本 mod 识别的情况。

> **兼容无需反射，也无需声明或申请任何额外权限。**  
> 不需要 `reflection-external`、`files`、`native` 等能力，不需要引用本 mod 程序集，也不需要 Harmony 补丁。

## 1. Mod 电源接入建议

自学习机只通过原版入口判断和消耗电源：

```csharp
PowerHelper.CanDrawPowerSource(cell, drawn)
PowerHelper.DrawPowerSource(cell, drawn)
```

电源 mod 只需保证自己的电源物品：

1. 能放进机器电源槽；
2. 正确参与上述两个原版入口；
3. 不需要让自学习机识别自定义 ID、tag 或类型。

例如 Better Reactor 的电力接口：

- 物品自身 `power_source_item_energy = 0`；
- 电力来自反应堆内部 pool；
- 电源 mod 自己补丁 `CanDrawPowerSource` / `DrawPowerSource`；
- 自学习机无需硬编码 `better_reactor_power_interface`。

推荐：

- 判断可用性走 `CanDrawPowerSource`；
- 实际扣电走 `DrawPowerSource`；
- 不要把电量下降当作唯一成功条件，特别是不使用自身 energy 的电源。

如果电源 mod 只实现自己的私有扣电方法、不参与原版入口，自学习机不会识别。

## 2. Mod 自学习上限接入建议

每个带自学习词条的模组，上限由以下 tag 决定：

```text
LEARNING_ALGO_MAX_PERFORMANCE_INT
LEARNING_ALGO_MAX_EFFICIENCY_INT
LEARNING_ALGO_MAX_QUALITY_INT
```

接入建议：

1. 外部 mod 直接修改这些 tag 即可，自学习机每次推进都会重新读取；
2. 想让上限更大，把对应 max 改大；
3. 想让上限更小，把对应 max 改小；
4. 修改后建议保证：
   ```text
   BONUS_PERCENTAGE_* <= LEARNING_ALGO_MAX_*
   ```
5. 授予自学习词条时，优先使用原版：
   ```csharp
   ModuleEffectHelper.InitLearningAlgo(mod)
   ```
   再按需要调整 max。

行为说明：

- max 每次推进实时读取，没有缓存；
- max 改大或改小，下一夜生效；
- max 小于当前 BONUS 时，自学习机不会把值往回改；
- 正属性没有 max 时不成长；
- 负属性没有 max 时按 0 处理，继续向 0 成长；
- 修改基础 BONUS 后不会自动重算 max，需要外部 mod 自己同步 max。

## 3. Mod 自学习步数修改接入建议

自学习机的基础成长值优先读取机器 tag：

```text
SELF_LEARNING_GAIN_PER_USE_INT
```

接入示例：

```csharp
machine.ModifyTag("SELF_LEARNING_GAIN_PER_USE_INT", ts =>
{
    ts.Enable();
    ts.SetInt(9);
}, true);
```

总基础步数：

```text
SELF_LEARNING_GAIN_PER_USE_INT（无 tag 时按原版语义 1）
+ ModSettings.BaseAdvances
```

其中 `base_advances`：

```text
额外推进次数
范围 0–9
默认 1
```

因此：

```text
tag 9 + 设置 1 = 10 点基础步数
```

外部 mod 也可以通过官方配置 API 修改 `base_advances`，但推荐优先使用公开 tag：

```csharp
ModConfig config = ModHelper.GetConfig("Pen_mod_selflearning");
ConfigEntry<int> entry = config?.Get("base_advances") as ConfigEntry<int>;
if (entry != null) entry.Set(1);
```

说明：

- tag 修改无需反射、无需权限；
- 不修改原版 `LEARNING_ALGO_GAIN_PER_USE` 常量；
- 质量额外步数仍按机器 TEMP 质量计算，另加在基础步数上。

## 4. 不会被本 mod 识别的情况

以下修改不会影响自学习机：

1. 只修改原版私有常量：
   ```text
   LEARNING_ALGO_GAIN_PER_USE
   ```
   它是 `private const`，当前原版实现没有实际读取，且编译期已内联。

2. 只补丁原版：
   ```text
   OnUsedLearningAlgo
   ```
   自学习机不调用该方法。

3. 只修改原版机器的基础 cycle / `onCycleEndSlotItemFunc`；
   自学习机使用自己的 cycle。

4. 只修改机器总加成 tag，却没有更新模组仓的 `TEMP` / `BONUS`。

5. 电源 mod 只实现私有扣电方法，不参与：
   ```text
   PowerHelper.CanDrawPowerSource
   PowerHelper.DrawPowerSource
   ```

6. 期望通过反射、Hook 私有方法或申请额外权限来“强制兼容”。

本 mod 的兼容接口就是：

```text
原版电源入口
LEARNING_ALGO_MAX_*
SELF_LEARNING_GAIN_PER_USE_INT
官方 ModConfig
```

这些都不需要反射或额外权限。
