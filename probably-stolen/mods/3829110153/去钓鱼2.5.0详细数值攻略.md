# 去钓鱼2.5.0详细数值攻略

适用：去钓鱼 2.5.0，截至 2026 年 11 月 13 日的源码与配置，涵盖养殖、出海、加工、药剂与蚀晶螺石。它是[机制版攻略](去钓鱼2.5.0模组攻略.md)的数值补充，两份可搭配查阅。

金额均为信用点，重量为克，食物热量为kcal；电量为设备的电量点。表中的定义基础价、公式报价和商店成交价分别说明。市场行情、原生品质特征、实际重量及取整可能继续影响界面价格。

**本攻略核查了源码、配置与相关原版接口，没有新增游戏实测。养殖倍率是可取得的上限，参考报价不是扣除饲料、电池、设备与占格成本后的净利润。**

## 三、养殖加价与收益计算

### 3.1 哪些增长可以加价

养殖设备中实际吃料产生的新高体重进入加价账本。单纯放缸、编辑物品、换容器或恢复之前掉过的体重，不会重复赚取增长奖励。

从卵成长的鱼可以显示“养殖鱼”来源标签；出海取得的鱼显示“野生鱼”。来源标签与内部增重账本分开，野生鱼后续真正养出的新体重仍按当前账本规则处理。旧卵缺少新来源标记时，不能只凭涨价倒推已经显示了养殖标签。

设：

- `主窗口 = max(1, 成年节点g − 幼年节点g)`；尾窗口＝老年节点g−成年节点g。
- `主额外加价 = (主段上限倍率−1) × 已记主增重/主窗口`。
- `尾额外加价 = (主段上限倍率−1) × 0.5 × 已记尾增重/尾窗口`，没有尾窗口则为0。
- `当前倍率 = 1 + 主额外加价 + 尾额外加价`。

代码以万分比逐段向下取整。两个窗口内都没有赚到足够新增体重时，不能直接套满倍率。

### 3.3 活鱼、死鱼、主肉的报价区别

活鱼先按真实体重与整鱼单价算基础值，再乘已赚取的养殖倍率；死整鱼与风干整鱼不再使用这层活鱼养殖加价。片出的主肉继承相应养殖进度、来源与品级，不能拿已加价活鱼的总价再次当主肉基数重复相乘。

主肉单块的当前报价核心为：

`floor(该块真实克数 × 分鱼种肉价 × 品级系数 × 当前养殖倍率 ÷ 1000)`。

结晶另加其修饰。每块分别取整，最后才求总价。鱼杂不等同于主肉，也不自动套用主肉价格表。

### 鱼饵查表

鱼饵双击转入出航装备库。普通、持久、强效版本效果作用对象相同，区别是耐久与加成幅度。成功率加的是百分点，例如60%加25个百分点是85%，不是75%。

|鱼饵|作用条件|普通：耐久/加成|持久：耐久/加成|强效：耐久/加成|
|---|---|---|---|---|
|鼠屎球|血色鱼影|15 / +25个百分点|30 / +25个百分点|10 / +50个百分点|
|鱼肉糜|普通鱼点，排除血色与巨型鱼影|15 / +25个百分点|30 / +25个百分点|10 / +50个百分点|

闪光鱼饵不增加本竿上钩率；它加的是上钩成功之后的条件概率。假设某种情形上钩率60%，成功后宝箱率20%，整竿拿到宝箱的概率才是12%；这个20%仅为演算例子，不是本节确认的宝箱基础值。实际每竿耗饵为“1＋地点额外磨损＋本竿额外磨损”，所以耐久15也不能一概写成可用15竿。成长带来的耐久加成还会加在物品基础耐久之上。

### 本竿上钩率怎样算

当前抛竿顺序为：60%基础值，加地点及连钓修正，加适用鱼饵，加节点/海况修正；本竿候选中只要存在生物巨型鱼，再减15个百分点；最后开启巨力引擎则减20个百分点，并将结果限制在5%至100%。这只是上钩概率；需要搏鱼的鱼还得过张力操作，不能把上钩率当成最终入舱率。

|条件|上钩率修正|其他效果|
|---|---:|---|
|该点压力0—2|0|鱼群充足|
|该点压力3—5|-25个百分点|鱼群受惊|
|该点压力6以上|-50个百分点|鱼群稀疏|
|新闻鱼群|+10个百分点|仍叠加其他规则|
|密集鱼群|0|基础多1条；压力不足3加2扰动，否则加4|
|深海巢穴|0|稀有权重×3；加5扰动|

引擎时间按15－等级×2.5，再采用中点远离零取整，所以1级是13分钟、3级是8分钟。鱼舱格数是平面面积，长条物件能否放下仍受实际形状和摆放影响。航海图以横纵步数之和计算距离，呈菱形揭示；调查可选距离为揭示半径加1、最多5格，即初始3格，一级4格，二级5格。船只正常移动只允许上下左右相邻一格。

巨力引擎是另一个设备，标价1000，不是永久引擎升级的第五级。开启时每格再省1分钟，因此0—4级分别为14、12、9、7、4分钟；代价是上钩率减20个百分点、追猎出现率加20个百分点、自然海域每小时额外加10扰动。它适合赶路，钓鱼前关闭可避免该上钩惩罚。静音购买后还要确认开关，关闭时等级仍保留，但减扰动不生效。

### 600分钟内怎样安排搜索与风险

航程时间上限是600游戏分钟。若按18:00作为航程起点，600分钟对应次日04:00。个别界面绘制代码还留有18:00—02:00的旧注释，应以上限600分钟的实际计时规则为准。普通打捞资源周期为2天，周期按从起始日以来的天数整除2计算，不是每次返航重新刷新全部箱子。

搜索按真实进度的整秒收费：每推进1个完整搜索秒扣5游戏分钟。搜索品质档0、1需要1秒，即5分钟；档2、3需要2秒，即10分钟；更高档需要3秒，即15分钟。中途进度分段收费，不能把一次完整搜索一律记成5分钟。普通钓鱼界面标示30分钟，使用探照灯标示25分钟；移动、搜索与其他服务都要共同计入返港预算。

自然扰动的基础增长如下：航程0—239分钟为0；240—359分钟每30分钟加5；360—479分钟每30分钟加8；480分钟以后每30分钟加12。平静夜晚先乘0.7，再乘静音倍率，随后加入巨力引擎额外增长及之前不足1点的余数，向下取整；剩余小数继续保留。扰动限制在0—100。例：后段30分钟基础12，二级静音变9.6，不能每段都舍掉0.6；累积余数最终会成为整数扰动。巨力引擎的额外值是在静音倍率之后加入，不能直接宣称静音把它也削减20%。

|扰动|异动事故抽取基础概率|追猎出现基础概率|
|---|---:|---:|
|0—24|0%|10%|
|25—49|12%|20%|
|50—74|30%|35%|
|75—89|50%|50%|
|90—100|75%|70%|

两列属于不同判定，不是一次操作同时发生两件事的保证。自然航程以30分钟安排事故检查，但还有节点、事件等调用入口；不能简单写成每移动一格固定抽一次。追猎基础值开启巨力引擎后加20个百分点，并限制在0—100%。水下撞击分支损伤为：扰动不足50扣1，50—89扣3，90以上扣5；这也不是所有事故都必然扣该数值。

### 张力操作与追猎

每回合新张力＝当前张力＋鱼的本回合力量＋玩家操作力量，限制在0—100。三个操作的力量依次为-25、+15、+30。安全目标区为30—70，系统建议会在能落入此区的选项中选最接近50的一个。看到鱼向上猛拉时仍要看当前张力和实际力量，不能死记固定轮换。

|鱼重|基础成功目标数|基础反应时间|
|---|---:|---:|
|不足500克|2|4.5秒|
|500—1999克|3|4秒|
|2000—4999克|4|3.5秒|
|5000克以上|5|3秒|

稀有或巨型鱼的反应时间再减0.5秒，最低2.5秒。这是普通重量规则，追猎战还会设自身目标，不能把表格直接套成所有Boss只需5次。小黄鱼和沙丁鱼仍有巨型词条搏鱼豁免；林冠区域鱼类还使用每公斤基础价严格大于100的搏鱼门槛。

追猎遭遇时，没有可用鱼叉会触发捕食者攻击。正式开战先消耗1点鱼叉耐久，所以失败也不应当视为免费试打。鱼叉上限3次，幽灵船获得并放入正式鱼舱带回后进入装备库；船坞每花1500修复1点。安全港会解除当前遭遇。成功后的捕食者还有领取与入舱步骤，打赢不代表已经放入背包。

求救信标在已实现的致命撞击救援入口自动消耗1枚。若船体已经降至0，救援先补到1，再按成功返航处理，鱼舱按正常返航结算。这和靠自己返回港口不是相同触发方式，也不能推广为所有失败原因都能自动保货。生命、血色等钥匙及隐藏出口有各自入口和库存条件；本节未完成对应掉落链与消耗链的逐项复核，暂不编造钥匙掉率、保底轮数或隐藏奖励数量。

| 三级 | 70% | 700 µL | 300 µL |
| 二级 | 82% | 820 µL | 180 µL |
| 一级 | 92% | 920 µL | 80 µL |

### 药效的完整浓度曲线

每一种鱼粉独立算分，没有一种“主粉”获得额外倍率。主效、次效是浓度排序后的结果。统一折算到每10ml药液：x＝该有效组分µl÷总药液µl×10000。

|每10ml有效量 x|该种药效分数|
|---|---|
|0～1000µl|0.04x|
|1000～1500µl|40＋0.05×(x−1000)|
|1500～2500µl|65＋0.02×(x−1500)|
|超过2500µl|85封顶|

最终分数限制在0～100并四舍五入。分档是：不足20未成效；20～39第一档；40～64第二档；65及以上第三档。理论连续曲线20、40、65、85分分别对应5%、10%、15%、25%有效浓度，显示四舍五入可能使边界提前极少量跨档。浓度提示以最高一种有效浓度判断：不足10%偏弱，10%～25%适中，超过25%偏浓。其余组分也能独立形成第二、第三药效，但不会因为混了更多种就提高单项上限。

### 辅剂与稳定剂

以添加辅剂前的原液体积为基准。以下是每 10 mL 原液降低一级副作用所需的一组剂量。

| 目标 | A + B |
|---|---|
| 乏力 | 糖 0.5 mL + 蛋白质 1 mL |
| 口渴 | 糖 0.5 mL + 矿物质 0.5 mL |
| 躁动 | 梦帽提取液 0.5 mL + 矿物质 0.5 mL |
| 失眠 | 梦帽提取液 0.5 mL + 蛋白质 1 mL |
| 嗜睡 | 咖啡因 0.5 mL + 糖 0.5 mL |
| 恶心 | 蛋白质 1 mL + 矿物质 0.5 mL |

每项最多四组，I 级可降至无。共用辅剂按调和优先级分配，同一份材料只能计入一组。稳定剂每 10 mL 原液使用 5 mL，一次处理。例：20 mL 原液要把 III 级乏力降至无，需要三组，共糖 3 mL、蛋白质 6 mL。

副作用基线取投辅剂前的浓度，正面药效按成品浓度计算。辅剂占体积，可能使正面药效降档。污染影响纯度，可用原版过滤器处理。多余辅剂没有额外副作用惩罚。

### 定量灌装与历史配方

每支取 10 mL，每支消耗一份电量和一个空针管，受库存和输出空间限制。25 mL 可灌两支，余下 5 mL。新针管和同批余液使用灌装前配方评估药性；加入新料后重新按组分评估。历史配方复用时核对缺额并消耗实际材料。

### 单支基础价

`基础价 = 四舍五入(10 + 100 × 综合药效权重 × min(副作用系数, 稳定性系数) × 装量系数)`。装量系数为实际体积 ÷ 10 mL，最大 1，新针管为 1。

| 条件 | 计算 |
|---|---|
| 药效权重 | 未成形、初级、中级、高级分别为 0、1、2、3 |
| 多效排序 | 按药效分排序，权重依次 1、0.35、0.15、0.05、0.05；总和封顶最高档权重的 1.6 倍 |
| 副作用 | 各项分数 ≤0、1～19、20～39、40～69、≥70 分别为 0～IV 级；合计每级扣 5%，最多扣 30% |
| 稳定性 | ≥70 系数 1.00，60～69 系数 0.90，低于 60 系数 0.75 |

稳定且无副作用的单效满支，初级 110、中级 210、高级 310。例：中级、合计两级副作用、稳定值 55，满支基础价为 10 + 200 × 0.75 = 160。实际交易可再受原版品质等修正。

## 十二、计算口径与版本依据

### 查收益时按这个顺序

1. 先确定是整条活鱼、尸体、主肉、鱼杂、风干成品还是罐头；这些不是同一个价格基数。
2. 读取当前真实克数与剩余热量，不用旧图大小猜实际肉量。
3. 单独读取品级、来源、已经赚到的养殖进度与结晶；每项只计算一次。
4. 片肉逐块取整，副产物按原体重各自整除，罐头按投入件数计适性。
5. 最后扣饲料、电池、耗材、设备、时间与空间成本，才是净收益。不同物种不需要追求相同日收益。
