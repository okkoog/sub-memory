## 快速上手

1. 店内的船钥匙交互入口现在常驻显示。维修未完成时不能使用，提示“飞船正在维修”；完成导师的首次付款后获得出航资格。维修欠款共1000信用点，可以先支付100解锁，不要求先还清全部。
2. 完成出航解锁后，等待威利来访。首次介绍时会随名片给你渔业终端；后续渔具和情报随剧情开放。
3. 准备鱼竿、鱼饵和必要物资，在出海整备页核对携带状态。先做短途，熟悉地图、资源消耗和返航方式。
4. 回港后处理正式鱼舱与货箱，把要研究、养殖和加工的鱼分开留存。
5. 有稳定供水、过滤和饲料后再扩大养殖。先用少量鱼熟悉每日消耗，不要直接塞满养殖空间。
6. 根据用途选择整鱼出售、片肉、风干、罐头或研究；同一条鱼不能同时用在这些路线中。

建议第一次出海把“安全回来并取出货物”作为目标。鱼的价值受鱼种、重量、品级和加工方式影响，没有一种处理路线对所有鱼都保证利润最高。

## 威利与终端

选择「交付一条鱼王(优先选取桌面)」，系统会先从桌面、再从背包选取一条符合条件的鱼王。黄金鱼、蓝晶鱼、落芙鳞、尼奥伦均可交付。

### 来访与解锁

威利不是看到钥匙当天立即出现。完成船只解锁后，最早在解锁的次日安排首次介绍。首次介绍后至少间隔4天，才进入旧渔网相关来访。修网后的主线会优先安排鱼饵实验；高级鱼饵、鱼竿研究和后续鱼王情报要按任务顺序推进。

| 阶段 | 玩家应做什么 | 容易误解之处 |
|---|---|---|
| 导师与船只 | 完成首次付款，取得出航资格 | 钥匙常驻显示不等于免除首次付款 |
| 威利介绍 | 接收名片、渔业终端 | 终端不是等养殖系统解锁才发 |
| 旧网与鱼饵 | 阅读来访任务、交付要求的材料 | 只等天数不能跳过交付 |
| 鱼类研究 | 完成已开启研究与后续来访 | 不同来访有等待间隔及前置 |
| 鱼王与行星情报 | 按当前任务推进、补齐高级渔具 | 高级鱼不是仅靠换一根鱼竿就全部开放 |

以上是流程顺序，具体交付清单、费用和当前进度请查看任务与对话。多个条件同时满足时，主线优先；没有当天来访不一定是坏档。

### 终端购买

双击渔业终端打开界面，通过页签查看图鉴、研究和商店。商店按当前解锁状态显示分类，尚无可买商品的分类可能不出现。实体威利货架的购买方式仍保留。

普通商品可用加减按钮选择数量；养殖设备等限购物品按各自配额处理，每种每周限购1台，以界面显示的本周余量与重置时间为准。不要把一种设备的剩余额度理解为所有设备共用的次数。盐、辣椒、鱼油、超级盐、火爆辣椒五种调料属不限购白名单，可按需随时补货。

购买需要满足现金、解锁和存放空间条件。系统尝试把物品送入主物品栏或仓库，成功交付后才扣款并登记限购。无法购买时，先留出能容纳物品形状的连续空间。

终端和各类手册属于单份用品：已持有时不会反复出售，丢失或卖掉后可补购，每次一份。旧档已越过发放剧情时有补发流程，先检查仓库与待领取内容。

威利上门收购仍限现有鱼、鱼类材料、食品和鱼饵范围，并非本Mod所有工具设备都收。当前会读取物品的原版Mod来源标记，明确来自其他Mod的货物不因名称相同就视作本Mod货物；鱼杂、蟹来源原版肉及无标记的既有目录物品保留各自识别路径。

## 出海指南

### 整备与物资

出海前依次检查船只状态、电力、可用物资、渔具、鱼饵和鱼舱空间。以整备页显示的实际携带状态为准，不能因为店内仓库里有某物，就认为本次航行一定能用。

鱼竿用于相应钓鱼操作，渔网与其他工具按场景提示使用。高阶目标可能同时受剧情、情报与装备约束。准备修理、补给和应急物资时，应给往返路程留余量；不要把全部电量和物资花在抵达目标上。

### 时间、海况与地图

远航地图为19×15格，航程从18:00计时，最迟应在次日04:00前完成返航，单次上限600游戏分钟。每晚只能正式出航一次；不要把关闭界面理解为已经安全返港。普通鱼舱从6×6起步，可通过船只升级增加容量。普通打捞资源按2天阶段刷新；固定地形、探索发现状态与资源刷新是不同记录，不应把刷新理解为所有地形和战利品同时重置。

远航中的导航、搜索和其他行动会推进航行时间。时间不是可以忽略的背景数值：自然扰动在航程前240分钟不增长，240分钟后每30分钟基础增加5点，360分钟后增加8点，480分钟后增加12点，再受海况与其他修正影响。平静夜间对应的自然增长乘0.7。林冠还有自己的扰动增长规则。

这些数字描述基础增长，并不是保证安全的倒计时。海况、航行方式、事件和船只状态都会改变实际处境。看到风险提示应重新评估，而不是等到某个固定分钟数才返航。

| 地图信息 | 使用方法 |
|---|---|
| 已发现节点 | 查看当前可到达位置与连接路线 |
| 鱼点 | 核对可用渔具、鱼饵及目标条件后行动 |
| 追猎目标 | 结合当前位置与移动线索追踪，给追赶预留资源 |
| 漂浮物、沉船等 | 选择搜索或打捞，并承担对应时间与风险 |
| 港口 | 查看补给、服务、返航等当前可执行选项 |
| 隐藏点 | 先满足钥匙和入口条件，再决定是否进入 |

发现一个地点不代表可以跨越障碍直接进入。地图上的钥匙房标记也不代表入口已经清理。

### 钓鱼与张力

进入鱼点后按当前选项选择作钓方式。抛竿后的搏鱼要同时观察鱼的状态和张力，按界面提供的收线、放松等操作调整。追求速度却持续把张力推向危险区，会失去可控余量；过分保守也会消耗时间。

不同鱼、鱼点和渔具会改变选择与搏鱼表现，不能套用“一直按同一个按钮”的通解。先用普通鱼熟悉状态变化，再挑战鱼王。鱼未成功领取前，不应当作已经装入鱼舱的收获。

### 追猎、打捞与返航

追猎需要跟上目标的行动与位置变化；路线规划时，把搜索、接战和返回港口一起计算。打捞同样可能需要多次行动，搜索进度不等于已经取得所有物资。

正式鱼舱是本次远航的货物空间。拖动鱼舱物品时，可按 Q／E 或鼠标右键旋转。拾得物品要考虑占格与形状，遇到空间不足时先整理，再决定保留哪些货物。部分特殊钥匙不是普通店内商品：例如血色钥匙和生命钥匙可在鱼舱中用于相应隐藏点，带回后进入装备库并自动携带；每批隐藏物资首次入场消耗一把，批次内重进不再重复消耗。它们不能出售或转入店内背包。

返航前确认港口提供的实际操作条件，完成返航后再处理货箱、鱼舱与待领取内容。不要在海上看到奖励提示后，就以为已经进入店内库存。若符合求救信标的触发条件，救援会自动消耗信标并护送返航，鱼舱按正常返航结算；信标是应急手段，仍应主动管理返程。

## 拾荒钓鱼特性

“简易拾荒钓鱼”是单独的2点开局特性。选择后携带合适渔具，便可在对应拾荒流程尝试钓鱼。

| 项目 | 简易拾荒钓鱼 | 正式远航 |
|---|---|---|
| 入口 | 开局特性与拾荒流程 | 船只解锁、整备与航行 |
| 上鱼 | 每轮固定50% | 受鱼点、选择与搏鱼等流程影响 |
| 失败 | 执行原版拾荒 | 按当前远航行动结果处理 |
| 鱼池 | 单双日不同，部分鱼受情报限制 | 随行星、地点和解锁条件变化 |

林冠、铸星相关鱼种仍需要相应情报，鱼王还需要剧情与高级渔具。选了特性不会取消远航，也不意味着拾荒能无条件取得所有鱼。

## 养殖与保存

### 先准备环境

养殖前先查看终端鱼类档案，确认食性、成长阶段、需水量和夜间排污。系统沿用原版的成长、喂养、水质与繁殖基础流程，各鱼种的具体参数不同。

| 要素 | 实际含义 | 操作建议 |
|---|---|---|
| 空间 | 鱼及其后代能否实际放下 | 为成长变形与产卵留空位 |
| 水量 | 满足鱼当前阶段需求 | 水箱先装水，再放入对应槽 |
| 过滤 | 处理污染的能力 | 增大水箱不能代替提高过滤 |
| 食物 | 维持生长与繁殖 | 按食性提供可吃的饲料 |
| 电力 | 设备正常工作所需 | 定期检查供电与电池 |

大型生态养殖设备的展示规格为24×4格、4个滤芯槽，支持扩容和节能升级；储水箱另购。60升储水箱创建时为空，必须装水。旧储水箱读档只更新容量上限，不清空现有水，也不会自动装满。实际设备状态以当前面板为准。

不要只按幼鱼体型计算容量。鱼进入新阶段后体重、用水和排污可能变化，成年日龄也不等于已经长到最大重量。例如黑鱼当前成年节点为13发育日，小黄鱼与沙丁鱼为4发育日；实际经过多少个夜晚，还受喂食和成长速度影响。

### 来源、品级与繁殖

从卵成长并保留来源的鱼可显示为养殖鱼，出海取得的是野生鱼；旧档来源不明的鱼不会被强行补认。来源与鱼种会参与加工、研究和计价判断，因此不要把名称相同的旧鱼肉一律当作已知来源样本。

整鱼品级在首次捕获时确定，片鱼主肉继承品级；繁育鱼默认为四级。出海生物鱼按鱼种成年阶段生成，词条只在首次捕获时施加。每条已领取鱼提供10钓鱼经验，满级需要9500经验。

繁殖通常需要成年雌雄同缸，并满足食物与环境需求；隔夜有机会产卵。不是只要两条成年鱼就每天必产，也不能用高品级代替水质和食物条件。

加价按养殖设备中真正吃料长出的新增体重逐步累计，不是把鱼放入缸里便立即获得上表倍率。恢复以前掉过的体重不重复计奖；活鱼和由它片出的鱼肉沿同一养殖进度计算，避免重复乘价。达到成年段上限后，成年至老年段新增体重还可以按较低速率取得尾段加价，尾段额外加价最多为主段额外加价的一半。

例如黑鱼主成长段最多从1倍逐步到4倍；尾段也全部取得时理论上限为5.5倍。剑鱼的配置上限为1倍，定位更偏大量肉与饲料供给，不靠养殖溢价追赶高利润鱼。这里的倍率只描述养殖加价层；绝对收益仍受重量、品级、售价基数、逐块取整、食料与设备成本影响，不等于每日净利润。

“养殖鱼／野生鱼”是来源标识；从卵成长的标记与实际喂养增重加价分开处理。不能仅凭标签名，推断这条鱼已经取得全部加价。

### 冰柜与蚯蚓

冰柜可以存食物与活鱼。活鱼放入后暂停生理状态，取出后恢复，因此适合临时保留种鱼或样本；暂停期间不能把它当作正在正常成长、繁殖的养殖空间。

蚯蚓培育盒接收蚯蚓、鱼肉和鱼杂。鱼肉与鱼杂在夜间按真实热量转存为盒内余粮，有活蚯蚓才消耗食料。还躺在格子里的材料，不等于已经可以花费的内置余粮。

幼蚯蚓需要足食夜晚成长，成年蚯蚓可按已有操作刀切或配对繁殖；检查年龄、饱食和空间提示，死亡蚯蚓不能当活种使用。

两个饲料按钮分别生产工业饲料、工业肉饲料。每次消耗1条存活成年蚯蚓与5000kcal已存余粮，产出1份5000kcal饲料，交付到有合适空间的仓库或主物品栏。输出无处放或制作失败时应保留、恢复投入。工业肉饲料是独立肉食物品，按原版饲料机制使用，不能拆分。

## 片鱼与副产物

片鱼按该鱼种的热量档位拆出鱼肉，不是所有鱼统一切成同样大小。配置以每100kcal的鱼肉重量为基础折算，实际鱼肉档位由鱼种分别定义；例如部分鱼使用400、300、200、100kcal四档，其他鱼可能有更大的档位。不能把100kcal理解为所有肉块都固定只有100kcal。

系统从大档到小档分配热量，剩余热量达到25kcal才保留为鱼杂；不足25kcal的尾数不再产出鱼杂。片鱼主肉保留来源和品级。产出的每块鱼肉有各自热量与占格；本版不再提供旧的合肉流程。

副产物独立按整鱼体重计数，数量为“鱼体重÷每份所需克数”向下取整，和切出了多少块肉无关。当前23种普通生物鱼配置了分鱼种片肉档位，其中以下12种有额外产物规则；大白鲨与帝王赤甲蟹另走各自分解流程。

## 风干

把支持配方的原鱼放进风干架，按架子显示的剩余天数等待。不同鱼有独立配方，不支持的鱼不会因为放进去就自动开始。跨天推进后，完成的鱼可能显示待转换，打开架子完成转换即可。

新流程保留原鱼的身体重量与能量；“售卖得率基准”只用于计算报价，不代表实际身体和热量按比例缩水。成品会带风干标记，不能再次风干，也不能再次片肉。要取鱼肉和片鱼副产物，应在风干前决定。

售价基数按售卖得率重量与配方每公斤价格计算，再应用结晶和品级修饰。结晶对应1.5倍；四级、三级、二级、一级、特级分别对应1、1.1、1.25、1.5、2倍。这些是价格修饰，不表示再次生成更多鱼肉或副产物。

## 鱼罐头

### 装罐与做法

双击小空罐头或大空罐头，装入原鱼或鱼肉。小罐内部4×3格，大罐6×4格，能装多少首先受形状与格子限制。

可以不加调料，也可选择盐、辣或油其中一条路线。同罐最多2份同路线调料，不能把盐、辣椒和鱼油混成多个做法。盐和超级盐属于盐路线，辣椒与火爆辣椒属于辣路线，鱼油属于油路线。

### 品质与价格

| 计分项 | 规则 |
|---|---|
| 基础分 | 全部鱼原料中取最高基础分：整鱼1分、鱼肉2分，只算一次 |
| 适性 | 符合该做法的鱼原料按件数加分，不按总重量 |
| 调料 | 按投入份数加分，上限受两份调料限制 |
| 混鱼 | 混合不同鱼种减1分 |
| 最终品质 | 夹紧为1～5级 |

盐路线适合净水鱼、玻璃鱼、彩虹鱼、蓝晶鱼、落芙鳞、尼奥伦、铁氧体水母等；辣路线包括黑鱼、鼠鱼、大白鲨、独角剑鱼、帝王赤甲蟹、火山鱼、穆斯贝尔之子、赤尾鱼、无支祁、拉恩的噩梦等；其余鱼种多为油路线，原版鱼也有独立对应关系。来源不明的旧鱼肉不凭空猜测鱼种适性。

成品价值以空罐及全部投入材料的基础价值为基数，乘以品质系数：1至5级分别为1.1、1.2、1.3、1.4、1.5倍，最后四舍五入。小空罐基础价值5、大空罐10。为了升一级加入昂贵原料是否划算，要比较实际投入，不能只看品质数字。

### 加工与罐头架

新生成罐头成品带有加工食品标签，成品批次估价严格大于1000时另有奢侈品标签。现有旧罐头沿用其标签。


开始腌制后原料窗口锁定，基础加工时间2天；罐头架可加速，按界面进度查看完成状态。准备能容纳成品的输出位置，放不下时源罐保留并可按流程重试。

罐头属于肉食食物，可放进现有罐头架。存放不再陈化涨价，因此无限放置不会无限增值。旧版封装罐头仅为旧档保留占位，不再按旧商品、旧加工玩法使用。

### 罐头计算例子

同一种适合当前路线的普通鱼肉放两块，加一份对应调料：鱼肉基础2分＋两块适性2分＋调料1分＝5分。换成不适合该路线的鱼肉，就没有这两次适性加分；混入另一鱼种还要再减1。若空罐与全部材料的价值合计100，5级罐头的加工价值为150，存放时间不会继续增加这个数值。

## 容器打印

在威利加工服务支付300信用点解锁容器打印，同时领取1台容器打印机。解锁后对应设备开放采购；已经取得打印机即可使用，不另设使用门槛。

电池拖进指定电池槽，每次消耗4电，产出1件。可打印小空罐头、大空罐头、蚯蚓培育盒和空针管。打印前检查剩余电量和输出空间，缺电或放不下时不应消耗本次资源。首次赠送未能交付时，先处理待领取或恢复提示。

## 加工台

双击加工台打开操作面板，把配方要求的材料放进原料格后即可制作。完整 58 条配方表见[详细数值攻略](去钓鱼2.5.2详细数值攻略.md)第九章。

匹配规则：原料种类必须与配方完全一致（多放、少放或混入配方之外的材料都不会匹配），每种材料数量达到配方的最小需求即可，不必精确等于配方数量。材料富余时可以一次制作多份：数量框两侧的加减按钮在 1～10 份之间自由切换，不受当前库存限制；点开始制作时才按选定份数核对材料，配方不匹配或材料不足会弹出提示，不会静默失败。加工台只认配方指定的材料形态，例如鱼肉糜配方认整条小黄鱼或沙丁鱼，而大部分高级配方认导电鱼筋、发热腺体、净水囊等鱼类器官与加工材料，放入整条鱼不会匹配。

数量选项上方有一个便签样式的手册槽，可以放入加工手册；点击槽内手册即可打开图文版配方书（16 页 58 条，按分类翻页）。手册也可以不放入，直接双击手册本体阅读。

## 鱼粉和药剂

### 用原版搅拌机制取原液

在搅拌机接上液体容器，放入带合格鱼种来源的鱼杂并搅拌。原液直接进入容器，原版容量和溢出规则生效。模块档位越高，萃取损耗越低。带净水鱼来源的鱼杂可用来制作单效解毒药剂。药剂设备礼包首次发放原版搅拌机；旧粉碎机保留原有库存和待出货批次。

旧存档里的五种干粉仍可使用。读档会把旧粉的品质和重量换成原版化学组分，溶解时由原版处理整份用量和溢出。原液也可以倒入其他容器继续使用。

### 调配、调和与定量灌装

1. 把原液容器放进药剂台原液槽，选择取用量。主面板实时预览调配后的药效数值、稳定性和副作用等级，再点「调配／补料」应用。
2. 效果不足时补入更浓的对应原液。浓度过高时可只补水，补完后检查有没有降档。调双效时先调出主效，再少量加入第二种原液。
3. 选择调和目标，核对建议的辅剂用量和药性变化，再确认补料。按加辅剂前每 10 mL 原液计量，一组完整 A+B 降低一级副作用。稳定剂单次处理，具体组合见游戏手册或数值攻略。
4. 放入空针管和电池。每支固定取 10 mL，消耗一支空针管和一份电量；不足一支的余液留在台内。
5. 灌装栏可查看支数、余量和单支基础价。保存历史配方可以复做，复做仍消耗实际材料。

药剂手册有七页，辅剂速查前新增鱼杂来源页，列出五类粉末与对应鱼种。第一次制作可照着净水鱼解毒示范做，再用浓度色带和售价页核对成品。

## 蚀晶螺石

### 到店与购买

商人按排期当天的游戏天数决定间隔，第 1～14 天为 4～6 天，第 15～29 天为 3～5 天，第 30 天起为 2～4 天。已排定的来访日期继续生效，后续排期采用新间隔。

螺石采集商带来极光或林冠的 6～8 块螺石，货物需要店内桌面有足够空间。每块占 2×2 格。原生螺石基础报价 300 信用点，开皮后才知道品种和品级。明价货已开皮，商人按品种和品级报价。

每块明价货有 30% 的概率预切一处。购买前能看实际贴图，预切位置在详情里显示「?」，商人仍按未切货报价。纯石面没有彩色切口，所以外观看不出时也可能已经预切。买下后显示结果，预切计入三刀上限。首次购入后，威利次日来店送四页图文手册《前辈的经验》。第四页用常品底图与三档透明度对照绿泥石和绿萤芯，帮助辨认切口。

### 开皮、切割与精磨

1. 用放大镜检查自己持有的螺石。原生螺石点「开皮」，揭晓重盐螺、沉毒螺或虹蚀螺，以及劣品、常品、佳品或典藏品级。
2. 把鉴定页上方的打磨机拖到切口，让白色磨头累计接触该处 2 秒。切割免费，每处最多一次，总共最多三刀。加工中会显出颜色和品质线索，切完才写入结果。石面会降价，劣等矿物的影响视矿种而定，宝石会加价。
3. 准备定型时点「精磨」。指针用 4 秒往返，去、回各 2 秒。三个宽窄不同的绿区随机排列，每区确认一次，去程漏点可以回程补点。点偏立即留一道暗裂，往返结束仍漏点也各留一道。
4. 精磨开始后不能再切割，定型前也不能出售或易货。关窗后可恢复原布局和已结算区域。0、1、2、3 道暗裂分别按当前估价的 120%、95%、75%、60% 结算。

不精磨也可以直接出售。螺石归为材料，切出宝石内芯后获得宝石标签，开皮后估价超过 1000 信用点时归为奢侈品。报价、掉率与估价公式见[详细数值攻略](去钓鱼2.5.2详细数值攻略.md)第十一章。

## 研究图鉴与联动

持有渔业终端与合格样本即可按行星条件研究，不需要额外先解锁养殖系统。提交研究会消耗1条自有鱼，风干鱼不接受。稀有种、种鱼和唯一任务样本应先决定用途，再点提交。

图鉴可查看捕获条数、最大重量、词条、首次取得时间及片鱼记录等信息；养殖档案显示阶段、体重、需水与排污，适合在扩养前查阅。实际档案比把某种鱼的经验套给全部鱼更可靠。

## 常见问题

| 问题 | 优先检查 |
|---|---|
| 看到钥匙仍不能出海 | 导师首次付款是否完成，整备条件是否满足 |
| 威利没有立即来 | 船只解锁日期、主线交付、等待天数与更优先来访 |
| 商店少了一个分类 | 当前分类是否有已解锁商品 |
| 有钱却买不了设备 | 周配额、商品数量、连续库存空间 |
| 水很多仍然污染 | 滤芯能力与夜间排污；水量不是过滤能力 |
| 鱼已经成年但不够大 | 成年阶段与实际成长重量不同 |
| 成年雌雄不产卵 | 食物、水质、电力、空间及隔夜机会 |
| 冰柜里的鱼不长大 | 柜内暂停生理状态，取出后恢复 |
| 盒里有鱼肉却不能做饲料 | 是否已隔夜转存5000kcal余粮，是否有活成年蚯蚓 |
| 片鱼副产物比预期少 | 按整鱼克数向下取整，不按肉块数量 |
| 风干鱼不能片肉 | 成品禁止再次风干或片肉，需提前选路线 |
| 罐头没因多放鱼获得基础分 | 基础分全罐只取一次，适性才按件数 |
| 放了很久罐头不涨价 | 本版没有陈化涨价 |
| 药液分成更多针仍然太浓 | 分装不改变浓度，可在药剂台仅补水并重新检查药效 |
| 远航奖励没在背包 | 完成返航后检查鱼舱、货箱与待领取内容 |
