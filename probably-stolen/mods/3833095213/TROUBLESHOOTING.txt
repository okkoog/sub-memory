NEON UNDERTOW 0.15.2 — LOADING HELP

Update, enable, restart
Let Steam finish the download. In the game's Mods menu, select Neon
Undertow and check version 0.15.2, choose Activate or Review and enable,
review the permissions, then fully close and reopen the game. Selecting
a mod or subscribing to it does not by itself enable it.

If using a local copy
manifest.xml, WaterSellerBridge.dll and WaterSellerCollection.dll must
sit directly inside one folder under Probably Stolen/Mods. Two DLLs are
intentional; only WaterSellerCollection contains the mod entry point.
Do not put another enclosing folder between Mods and the mod folder.
A local copy takes precedence over the same Workshop mod. Move an older
local copy outside Mods when returning to Steam's automatic updates.

Activated but no content
0.15.2 fixes the startup check that reported "Mechanic language table
could not load" after the game changed its selected language. Mechanic
is the game's internal text table, not a language or a missing download.
The mod now retries while game text settles, with a 60-second limit.
If game text still cannot load, verify the game's files and send Player.log.

Empty mod list AND broken options/buttons
One supplied log fails in the BASE GAME'S ModLoader.LoadModOrder,
EmporiumOption and KeyBindHelper while ES3 reads saved settings. It says
"Cannot load from file because the data in it is not JSON data, or the
data is encrypted." This occurs before mod initialization. Reinstalling
or splitting Neon Undertow cannot repair that unreadable settings file.
Back up the entire save/settings folder before attempting recovery and
include the exact error in a report to the game developer. Do not delete
playthroughs, replace trust settings with somebody else's, or approve a
mod you do not trust. This mod update does not reset any of those files.

Useful information for a report
- Game version, Neon Undertow version, other enabled mods.
- Workshop or local installation, and whether the issue survives restart.
- The FIRST exception or [WaterSellerPack] FAILED line from Player.log.
- Whether files are actually present in the installed mod folder.

Windows log/save folder (paste in File Explorer's address bar):
%USERPROFILE%\AppData\LocalLow\Questing Goose Studio\Probably Stolen
The log is Player.log; Player-prev.log may contain the previous launch.
