Neon Undertow: Vanilla Overhaul 0.15.2 — startup hotfix

Fixes a startup check that could stop the whole mod with
"FAILED: Mechanic language table could not load."

The game applies its selected language while starting the main menu.
Changing language releases pending text-table requests. The mod now checks
request validity each frame, requests the current language again if needed,
and starts its features only once usable game text is ready. It waits up
to 60 seconds and reports the underlying error if loading still fails.
It does not change the player's language or create a replacement table.

Mechanic is the base game's text table for mechanics and item conditions,
not an additional language or a separate mod dependency.

Both DLLs remain intentional: WaterSellerBridge.dll is a small shared
helper, and WaterSellerCollection.dll contains the mod entry point.
Both are declared in the manifest. Permissions remain runtime code and
reflection; no additional permission is introduced by this hotfix.

Gameplay systems, item IDs, artwork and saved content are unchanged.
The unfinished tool/workshop expansion remains excluded.

Validation: compiled against the installed game API; 14 automated startup
regression scenarios; native capability scan; non-startup runtime and
payload comparison. No fresh in-game test was run for this hotfix.

If it will not load, update to 0.15.2, review/enable the mod, and fully
restart. If the game itself shows empty menus or a SaveFile/ES3 format
error in Player.log, preserve your saves and report that error separately.
This hotfix does not modify or reset game settings or trust records.
