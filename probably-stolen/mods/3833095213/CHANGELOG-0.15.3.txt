NEON UNDERTOW 0.15.3

Removed unused external-mod dependency checks and stale references from
startup messages, Settings, handbooks, documentation and the Workshop page.
No other mods are required or listed as optional dependencies.

Neon Undertow's own Cellar Bench, all 76 brewing recipes, alcohol systems,
bar tools, item identifiers, artwork and saved-data formats are unchanged.
The 0.15.2 startup fix is retained. Permissions are unchanged.

Built against the installed game API and checked with the game's capability
scanner. Compiled-code comparisons verify that gameplay remains unchanged.
This cleanup did not require or receive a fresh in-game test.
