1.5.6-dev.2：枪械开局特性 / Firearms starting traits

+2 军械学徒 / Armorer’s Apprentice
基础打印机、金属与数控模块、电池、袖雀芯片，以及制作一把袖雀的材料。
Starter printer, Metal and CNC modules, battery, Sparrow chip and one pistol's materials.

+2 精工枪匠 / Master Gunsmith
自制本模组整枪的六项基础性能 +15%。
All six base stats of manufactured mod firearms +15%.

+1 熟练装配 / Practiced Assembly
本模组枪械与配件制作进度需求 -20%。
Mod firearm/attachment processing work -20%.

+1 谨慎交割 / Discreet Dealer
出售本模组枪械与配件产生的新增交易案值 -20%。
New arms-sale case values for mod guns and attachments -20%.

-2 旧案未销 / Unsettled Record
新局获得200点基础非法军火案值，受原版特性修正；洗罪后不会补回。
Start with 200 base arms-trafficking case value, subject to native traits. Cleared cases stay cleared.

-2 粗制滥造 / Shoddy Workmanship
自制本模组整枪的六项基础性能 -20%。
All six base stats of manufactured mod firearms -20%.

-1 生疏装配 / Fumbling Assembly
本模组枪械与配件制作进度需求 +25%。
Mod firearm/attachment processing work +25%.

-1 招摇过市 / Conspicuous Dealer
出售本模组枪械与配件产生的新增交易案值 +25%。
New arms-sale case values for mod guns and attachments +25%.

正数消耗特性点，负数提供特性点。性能、速度、交易案值的正负特性分别互斥。
Positive costs spend trait points; negative costs grant points. Each stats, speed and crime pair is mutually exclusive.
特性从新局选择。旧档保持原有特性。完整说明见《御藏名录》末尾两页。
Choose traits in a new game. Existing saves retain their traits. See the final two handbook pages for details.
生产轮次、性能与案值按整数结算。制作性能在模块加成后生效；配件、近战的属性保持原有规则。
Cycles, stats and case values use integer rounding. Firearm quality applies after module bonuses; attachment and melee stats retain their rules.
