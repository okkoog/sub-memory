# 禁忌御藏 · 可能会送命

《深空当铺 / Probably Stolen》模组，版本1.5.11，适用游戏0.46D。包含13品牌77款可拆装腕表、封存典藏、30把模块化枪械、6件高科技近战、工坊服务、夜间商店与专属来客。

使用游戏自带模组加载器。内置中文、英文和俄文，跟随游戏语言；切换语言后重启并读档。1.x存档可继续使用；旧0.x存档不兼容。保留一个启用的模组副本，避免本地版和工坊版同时加载。发布版没有Ctrl+F7开发面板。

## 从哪里开始

柜台下的《御藏名录》收录来客、鉴定图、配方、货源、参考价与局势说明。旧档读档后保留物品真伪、成色、来源及订单记录。已付款订单、已冻结竞价与已接受委托按原合同履行；库存参考价随新版目录更新。

想开修表店，可以选择腕表开局特性，购买工作台、放大镜与检测仪。第3天开放时匠会馆，第5天开放无铭工坊。夜间地图有分页，商店可能在下一页。商品摆在货架上，拖到交易台并按原版流程结账，再点返回。

时匠会馆每天出售一台精密工作台（1,950¢），无铭工坊每天出售一台简易工作台（195¢）。黎雾首次来访时，已有简易台就送精密台，没有工作台就送简易台；已有精密台不重复赠送。精密工作台专用于拆装、适配和改造，打标使用独立打标机。

## 前 5 天怎么玩

- **第 1 天**：翻一遍柜台下的《御藏名录》，看“腕表鉴定”和品牌图鉴，知道每个牌子该看哪里。照常做原版生意，攒点钱。
- **第 3 天**：时匠会馆夜间开门，卖原厂真表、真件、灯牌和精密工作台。阮灯会上门收好看的入门表；送她一块好看的入门表，好感涨得最快。零件贩子也开始上门卖真假混杂的散件。
- **第 4 天**：订表客人开始出现。买一块腕表收售灯牌摆进展示柜，柜里再放一两块表，会招来爱表的路人和表贩。
- **第 5 天**：无铭工坊开门，有翻新仪、补件制造机、打标器和仿件。断轨军械库同时开张，想做军火可以从这里起步，不做也不影响腕表生意。
- **第 7 天前后**：金蝮、赤隼开始来。她们卖来路不明的表和药，只收高级的整把武器。

两条提醒：外行只认卖相，行家一放上秤就会揭穿，打过标的货别卖给她们；欺客赚得太狠，买家第二天会回来追责。

## 腕表生意

- 常规表分机芯、表盘、表壳、表带。用放大镜对照原厂图找破绽；检测仪消耗电量，直接检测散件或整表的真假与真实成色。
- 工作台支持拆装和适配，手册列出六套专属组合。封存典藏按整表鉴定与交易。
- 翻新仪修复旧件；补件制造机按配方消耗材料、电量和加工费。部分金料部件需要金锭，真贵金属仿件仍按仿品交易。
- 打标器可以逐件或整表修改声明。误导买家可能引发追偿、声望损失和犯罪记录。懂行的客人会检查。
- 收售、鉴定、保养、维修四块灯牌摆在展示柜后招揽对应客人。服务报酬按实际完成情况计算。

## 进阶：原厂订货与暗拍

使用表厂联络名片登记13家原厂电话。订货全额预付，确认前会显示费用和余额；付款后不可取消。每品牌每周一批，T1五只起、T2两只起、T3一只起。

高档表（T4/T5）有两道门槛。VIP 是你在这个牌子累计实付的钱，够了才能订。配货额要先订这个牌子的 T1–T3 来攒，订高档表时另外扣除，不能抵货款。另外还要看当周库存。二手渠道没有这些限制。高档库存和货期按批次固定，反复拨号不会重抽。

无名暗拍每周换拍品，可出现典藏、虹冕仿品或高级材料。远程只给可放大的照片；每件只能出价一次，立即冻结全额，次日揭标。落选退款，中拍按自己的报价成交；空间不足时保留待领。日报附刊可查看当周拍品与行情。

## 开始军火经营

第5天起夜访断轨军械库。购买原版3D打印机、金属打印模块、CNC模块、电池、充电器、制作芯片及材料。已有设备可以继续使用。

原版打印机与三档武器制作箱均可使用各档芯片，材料和成品需要放得下。断轨军械库设备货架出售制作箱。T3/T4/T5的基础速度分别为原版的1.5/2/3倍，本模组整枪及近战的制造性能加成为10%/20%/30%，基础耗电为每周期16/24/40kJ，模组空间为48/63/80格。模块和开局特性继续生效。原版打印机材料仓为9×6，高档制作箱有更大的材料、出货与模组空间。给制作设备装好模块和电池，把芯片放入芯片槽，按界面配方放入金属与封装料，留出成品空间。芯片可复用，每次制造消耗材料和电力。做够后取出芯片或原料。封装料是打印军火用的厂牌专用原料，五档使用不同图案，库存占格为2×2，军械库每种每天40份；贵金属及特殊元素按配方使用。

枪械通过原版改装窗口安装对应型号的瞄具、供弹、后托和前端配件，外观与占格同步改变。空间不足时先把武器移到空位。六项属性用于交易、订单及相关玩法。高科技近战使用专属属性与强化材料。

近战按“嵌饰→增幅→核心”逐级强化，六件武器各有四张独立外形图。升级会改变刃形、体量与占格，拆卸按反方向进行。离子核心适配T2及以上，赤辉核心适配T4及以上，渊素核心适配T5。原有组件保留；缺前级时后续强化暂不生效，补齐即可。旧装备周围放不下新版占格时，先移到空处再打开强化窗口。

军火收售、改装订制、重型武器、配件交易灯牌放在展示柜后生效。阎霁、燎音、沈砺、绮鸦、零弦按进度和交情带货，也可携带生产材料。高级芯片、成品和元素有各自的渠道门槛，手册列出来源。

## 来客、黑货与御藏

金蝮、赤隼和白厄收完整高级武器：须同时符合奢侈品与违禁品条件，模组枪械T3起；真实成色分别至少85、75、80。物品提示会显示是否符合收购要求。卖给她们的好武器影响下次战利品。赃物交易保留风险，正规货源用于低风险周转。

送稳生胶囊或使用琥珀棺治疗可以养护白厄。她不收购胶囊；送礼整叠交出，每次赠送增加1点成长，每盒延长3天稳定期。成长与好感解锁更好的货源、暗格和守夜。稳定、好感4、成长3时可谈本周劫拍；选择武器后，确认页显示门槛、成功率、药品和费用。提交的武器、已装配件及消耗不退还；成功后取回实际拍品，真假和磨损保留，并以100%赃物暴露率交付。

金蝮与赤隼的罪证服务通过交情解锁，台词显示费用与冷却；清罪、压低调查和打击治安局各有作用。原版洗罪与正在进行的调查是不同记录，具体以当前面板和服务说明为准。

禁庭香露可邀请应汐渊。符合条件的紧俏表或虹冕赝品也可能引来她；交情与御制组合影响珍藏和服务。琥珀棺、宫镜、御座与神剑都有使用功能，见手册。持有未登记渊素可能触发追索；交还会增加好感，高好感可付费登记，拒绝并确认会结束本局。

## 墙面陈列与夜间供电

双枪架和剑架随剧情赠送，每种每局最多一座。使用安装包后固定在墙上，通过挂位放入或取下武器。展示状态启用防盗或神剑震慑；遮挡状态保护架内物品，暂停展示加成。神剑公开展示时会让普通盘查官退去；挡判罚还需有效维护，每次扣7天维护期，调查清零、案值保留。

渊素、赤辉核及御藏可给合格电池夜间回充，各自有位置、维护和每日额度要求。背包、暗格和普通箱内的电池应先取出，摆到店内合适位置。渊素还能作为初始为空的200kJ慢充电源使用；登记与追索规则照常执行。完整数值见《御藏名录》的供能两页。
