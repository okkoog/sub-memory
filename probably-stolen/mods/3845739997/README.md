# 수사 현황 바 (Crime Status Bar)

Probably Stolen의 보안대 수사 상황을 가게 화면 위에 한 줄로 띄워 두는 모드입니다. 기본 상태에서는 게임 값을 읽기만 합니다. 수사 진행도 멈춤·낮추기·초기화는 설정에서 켰을 때만 동작하는 선택 기능입니다.

## 설치

1. 게임의 `Mods`에 `CrimeStatusBar` 폴더를 놓습니다.
2. 게임을 재시작한 뒤 모드 목록에서 **수사 현황 바**를 켭니다.
3. 가게에 들어가면 화면 위쪽에 바가 나타납니다. 끌어서 옮기면 위치가 저장됩니다.

## 표시하는 것

| 항목 | 뜻 |
|---|---|
| 계급장 | 담당 수사관. 생도, 경관, 형사, 경위, 경감 순으로 높아집니다 |
| 증거 수준 | 0–100 게이지. 25 단위 눈금, 90부터 형 집행 계획, 100이면 수사관이 옵니다 |
| 위쪽 꺾쇠 | 증거가 밤마다 오르는 속도. 겹이 많을수록 빠릅니다 |
| 예상 형량 | 벌금, 수감, 사형 |
| 범죄 합계 | 현재 범죄 기록의 합. 아래쪽 꺾쇠는 밤마다 줄어드는 중이라는 뜻입니다 |
| 형 집행까지 | 지금 속도가 유지될 때 증거가 100에 닿기까지 남은 날 (추정) |
| 불시 점검 | 다음 점검까지 남은 날 |
| 세력 우호도 | 설정에서 켜면 세력별 평판 수치가 같은 줄에 붙습니다 |

상세 표시에서는 수사관 이름, 하루 증감량, 수사 단계, 권고 조치, 범죄 종류별 수치(사건 파일 버튼)를 함께 볼 수 있습니다.

## 조작

- 바를 끌어서 이동
- F8: 간략 → 상세 → 숨김 (설정에서 변경)
- 상세 표시의 **설정** 버튼: 모드 설정 창 열기

## 설정

표시 방식, 언어(11개와 자동), 크기, 배경 불투명도, 세력 우호도(끄기 / 보안대만 / 전체), 불시 점검 표시, 정보원을 이용 중일 때만 점검 표시, 방향 꺾쇠, 범죄 기록이 없으면 자동 숨김, 단축키, 다른 창과 겹칠 때 맨 앞에 표시, 수사 진행도 멈춤, 사건 파일에 수사 조작 버튼 표시, 한 번에 낮추는 증거량, 사건 파일에 세력 우호도 조작 버튼 표시, 한 번에 바꾸는 우호도. 설정 창에서 값을 바꾸면 적용을 누르기 전에도 바에 바로 반영됩니다. 위치는 바를 끌어서 옮기면 저장됩니다.

"정보원을 이용 중일 때만 점검 표시"를 끄면 정보원 서비스 없이도 점검까지 남은 날이 보입니다. 게임이 원래 숨기는 정보입니다.

## 수사 조작 (선택 기능, 0.2.0)

기본은 모두 꺼져 있습니다. 게임 값을 직접 바꾸는 기능이라 쓰면 세이브에 반영됩니다. 여기서 수사 진행도는 바의 증거 수준(0–100)을 말합니다.

| 기능 | 켜는 곳 | 동작 |
|---|---|---|
| 수사 멈춤 | 설정의 **수사 멈춤**, 또는 사건 파일의 버튼 | 새 범죄가 범죄 기록에 더해지지 않고, 밤이 지나도 증거 수준이 오르지 않아 집행관이 오지 않습니다. 기록은 평소처럼 밤마다 줄어듭니다 |
| 증거 수준 낮추기 | 사건 파일의 **증거 수준 -10** 버튼 | 누를 때마다 증거 수준(0–100)을 낮춥니다. 양은 설정에서 1–50 |
| 범죄 기록 낮추기 | 사건 파일의 **범죄 기록 -100** 버튼 | 누를 때마다 혐의 내역의 종류마다 그만큼 낮춥니다. 양은 설정에서 10–1,000 |
| 수사 기록 초기화 | 사건 파일의 **수사 기록 초기화** 버튼 | 증거 수준과 범죄 기록(혐의 내역)을 모두 0으로 되돌립니다. 3초 안에 한 번 더 눌러야 실행됩니다 |

버튼은 설정에서 **사건 파일에 수사 조작 버튼 표시**를 켜고, 상세 표시에서 사건 파일을 열면 맨 아래에 나옵니다.

- 초기화는 게임이 형 집행 뒤에 쓰는 처리와 같습니다(범죄 기록 전부 0, 증거 0, 집행 상태 해제). 0.3.1부터 범죄 기록도 함께 지웁니다.
- 집행관이 이미 출발한 뒤(증거 100)에 낮추거나 초기화하면, 집행관은 와서 증거가 없다며 돌아가고 보안대 우호도가 20 떨어집니다. 게임의 원래 규칙입니다.
- 멈춤은 켠 순간의 값을 상한으로 삼습니다. 범죄를 저지르면 게임이 일단 기록을 올리지만 곧바로 상한으로 되돌립니다. 그때 함께 일어나는 평판 변화나 손님 반응은 막지 않습니다. 증거가 이미 100이면 집행관은 막지 못합니다. (0.3.2)
- **세력 우호도 조작 (0.3.0)**: 설정에서 **사건 파일에 세력 우호도 조작 버튼 표시**를 켜면 사건 파일에 세력마다 내리기(-)와 올리기(+) 버튼이 나옵니다. 한 번에 바꾸는 양은 설정에서 1–50(기본 10)으로 정합니다. 난이도나 특전 배율 없이 적힌 만큼 그대로 바뀌고, 게임이 -200에서 200 사이로 제한하며 특전 해금은 바뀐 수치를 따라갑니다.
- 멈춤을 켜면 바의 증가 속도 자리에 "멈춤"이 나오고 형 집행까지 남은 날은 "-"가 됩니다.

## 알아 둘 점

- 남은 일수는 추정입니다. 밤마다 범죄 기록이 줄거나 새 범죄가 더해지면 달라집니다.
- 수사관, 범죄, 세력, 평판 등급 이름은 게임 번역을 그대로 씁니다. 모드 언어를 게임과 다르게 고르면 두 언어가 섞여 보입니다.
- 게임 0.46D의 코드에 맞췄습니다.
