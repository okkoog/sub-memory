# Probably Starve / 深空当铺：饥荒 0.3.21

适配本机 Steam《深空当铺 / Probably Stolen》0.46D，使用游戏原生 Mod 加载器。内部 ID 继续为 `station_needs`，继承 0.1.x 的独立生存状态和订单。

鼠标移到床铺上，出现灰色“状态”面板：**黄色饱食度、蓝色饮水值**，吃喝收益提示使用相同颜色。标题右侧的白底黑框齿轮打开原生 Mod 设置；也可通过主菜单 → 改装件（Mods）→ 本 Mod 齿轮进入。外出到配给站、垃圾场及其他地点或查看交通地图时，右下角显示食水小图标，悬停后在图标上方展开状态栏；回家后恢复床铺悬停显示。打开设置、食品编辑器、暂停菜单、日结或结局时暂时收起，转场黑屏期间也隐藏。面板离开床铺后保留 2 秒，鼠标在面板上时保持显示，方便点击齿轮；背景和文字不拦截游戏操作。已去掉面板底部的 7788 / 送水 / F7 宣传行。F7 仍仅打开订单。

滑块右侧显示实时数值，水相关参数的数字为蓝色。点击“应用”后参数立即生效，**无需重启**，设置菜单底部有明确说明。特性开关和点数的变更需重新打开新游戏特性页；初始食水数值只在该存档首次启用时使用。安装新版 DLL / 资源文件仍需退出并重新打开游戏。

## 外卖与饮用水调整

外卖按当前市场价报价，包含当前市场事件和一次饥荒涨价，不使用玩家零售加价。普通单品加 20%，普通套餐加 10%；急送单品加 100%，急送套餐加 80%。四档互不叠加，不另收旧配送费，比例均可在设置中调整。报价时按市场总价只向上取整一次。套餐为 5 个营养果、3 罐合成肉或 3 瓶 750 ml 普通水；套餐算一笔订单。电话“选择套餐”和“选择单品”切换商品页，均可切换普通/急送或结束通话。已支付的订单保持原价格；包裹部分送达后，只按未送数量比例退款。

新生成普通水纯度仍为 98%–98.49%，保持本 Mod 的正常饮用判定。污染部分改为 80% 重金属、10% 化学污染、5% 微生物、2% 有机废物、2% 物理污染、1% 矿物，取整余量归入重金属。原版普通滤芯和高级滤芯的孔径均为 22，重金属粒径为 12、化学污染为 2，无法通过这些滤芯去除；净水片的氯消毒也不会去掉重金属。即使微生物和其他杂质完全消除，剩余金属也使纯度低于优质水门槛。专用净水机保留原版处理能力。外卖实际生成水瓶时直接使用此配方，普通、加急和套餐都覆盖。优质水、纯水的生成保留，不重新配制存档中已有的瓶装水；待送达订单下次生成水瓶时使用新版配方，价格不变。此水质规则固定随 Mod 生效，已去掉“普通水更难提纯”设置项，旧的同名配置值不再读取。

## 吃喝与声音

泡面烹饪需要并消耗 300 ml 水，食用默认恢复 800 饱食度、150 ml 饮水值；原版熟面补水标签与本 Mod 默认值同步。食品属性目录会刷新默认值，已有玩家自定义规则保留。拖动提示、工坊中英文文案及操作示意图已同步。

口嚼（ZeroChew）每份恢复 280 饱食度、消耗 50 ml 饮水值；原来按基础价格恢复 224 饱食度，现在提高约 25%。食品属性编辑器的自定义值仍优先生效。

营养果按固体食物处理，菜单为“食用”；基础单价 12、热量 240 的普通营养果恢复 274 千卡，并少量补水 100 ml，吃腻及储备上限仍适用。

对自己拥有的食物右键 → 食用；水与饮品为“饮用”。液体容器按缺水量喝到饮水值上限，水不够时喝完剩余部分，保留容器。袋装配给水一次消耗一整袋，大袋 750 ml、小袋 375 ml；非液体饮品也是每次一份。未泡开的杯面不可食用。隐藏污染仍需原版检测，菜单不提前提示水质。

泥潭合成肉等罐头先开盖、再咀嚼。最终音效固定为**喝水 1、开罐 4 的前两秒、咀嚼 4**。截断处仅加入 5 毫秒淡出，避免爆音；咀嚼声已提高响度。设置保留音效总开关，已删除三个音效编号选择项。原版音量设置仍控制音效响度。音源与 CC0 许可见 `AUDIO-CREDITS.md`。

新增用户选择的三段音效：泡面加水 1 号、吃面 1 号、汽水开罐 4 号的前 3 秒。泡面制作使用注水声，熟泡面食用时使用吸面声；汽水和能量饮料先播放汽水拉环声，再播放饮水声。原有食品罐头仍先开盖再咀嚼，其他食物保持原音效。已开封的液体饮料罐不会因分次饮用反复播放开罐声。六段自定义音效统一由 Mod 音效选项及原版音量控制。

## 开局补给与双击吃喝

新开局默认满饱食度、满饮水值；包括一贫如洗和急需食物开局，赠送物品的排除规则仍保留。只在新局初始化一次，读档、改设置不会为已有存档补满。设置中可关闭满值开局，恢复使用自定义初始值。

饱食度和饮水值都严格高于上限 50% 时，每天首次开店有 70% 概率多吸引一名普通顾客；到达垃圾场时满足门槛，当天可额外挖掘一次。概率只判定一次，领取记录随档保存，读档和重新进入垃圾场不会补回已用次数。奖励可以关闭，门槛、顾客概率、挖掘次数可调。原版残疾和受伤限制保留。状态条在 50% 处增加细竖线，说明纸条也已介绍满值开局及奖励。

饥荒和急需食物的图标同时注册到原版状态页使用的特性 ID 图标表，解决新开局正常而状态页回退默认图标的问题；读档不改写已选特性的存档字段。

双击食用 / 饮用默认关闭，开启后普通双击消耗自己拥有的可食用物品；快捷转移组合键仍用于转移，沿用吃喝冷却。关闭时保留原来的双击查看行为。

开局补给默认开启，赠送 2 瓶装满普通水的水瓶、2 个营养果、2 罐合成肉，三项数量分别可调 0–20，并补齐缺少的食品霓虹牌与饮水霓虹牌。两种牌按各自物品 ID 检查，所选开局已经自带的牌不会重复赠送；也可单独取消赠牌。

新增负面特性 **“急需食物”**，默认 −2 点，点数可在 −10 至 −1 调整，设置中可决定是否开放选择。选择后不领取本 Mod 赠送的整套食水与霓虹牌，原版开局自带物品不受影响；**一贫如洗也不发这套补给**。仅新开局发放一次，旧存档不补发，途中改设置也不追加；物品栏放不下时尝试其他店内位置，仍放不下的数量随档保留，读档或翌日再试。

默认启用“隐藏原版热量，喂食改用饱食度数值”：普通食物和饮品不再显示原版喂食热量，喂养相关读取使用本 Mod 的饱食度数值，包括食品编辑器的自定义值。液体按容器实际剩余量折算，纯水为 0，未熟拉面为 0。专用鱼饲料保留原有喂养用途。关闭此设置可恢复原版热量；不改写物品存档标签，营养公式也不会被替换值反复叠加。

新开局默认发放一张“深空当铺：饥荒 · 提醒纸条”，使用原版纸条物品和阅读界面。内容说明悬停床铺或外出时悬停右下角图标查看食水、状态齿轮 / 主菜单 Mods 齿轮进入设置、饥荒挑战默认不生效，以及如何在设置中取消发放纸条。纸条独立于食水补给，一贫如洗也可收到说明，但没有食水。设置“发放开局说明纸条”控制之后的新开局，旧档不补发；空间不足时保留待发标记，关闭设置可取消待发纸条。标记随档保存，重复事件不重复发放。重新阅读时使用游戏当前语言，不影响原版教程进度。

## 营养公式与其他 Mod 食物

设置最下方新增“检测与编辑食物和饮品”按钮。首次进入存档会建立目录，也可手动重新检测当前启用的原版和 Mod 物品；按名称、ID 或标签搜索，可筛选食物、饮品及已自定义项。目录缓存后，在主菜单也能继续编辑；检测本身需要存档处于加载状态，不向物品栏发放测试物品。

每种物品可设置能否食用 / 饮用、菜单动作、饱食度、饮水值、基础腹泻概率和开罐音效。固体按每份、容器液体按每 750 ml 填写，食水允许 −10000 至 10000，基础概率 0–100%。水质、污染、加料与烹饪风险仍单独保留；未熟拉面和未开封容器仍按原流程处理。

逐项保存后立即生效，所有存档共用。恢复单个物品默认值会删除该规则，重新跟随本 Mod 的营养公式和全局参数。规则保存在游戏存档目录下 `ModData/station_needs/item-overrides.json`，保存前保留 `item-overrides.backup.json`；检测目录为 `food-catalog.json`，更新工坊文件不覆盖这些数据。

`P` 为物品基础单价 `unitValue`，不使用堆叠总价、交易估价或饥荒涨价；`C` 为 `CALORIE_VALUE_TAG` / `add_hunger` 中较高的原有热量。先判定普通水，其次饮品，最后固体食物。各项四舍五入为整数。

| 类别 | 饱食收益（千卡） | 饮水收益（ml） |
|---|---|---|
| 普通水 / 配给水 | 0 | 实际饮用水量；液体按真实水纯度折算 |
| 饮品 | `clamp(3P + 0.1C, 25, 450)` | `clamp(180 + 9P, 200, 700)`；若有容量标签则不超过该容量 |
| 有热量标签的固体食物 | `clamp(0.65C + 0.35×28P, 40, 2400)` | 0 |
| 仅有食物标签的 Mod 食物 | `clamp(28P, 40, 2400)` | 0 |

可识别原版 FOOD / BREVAGE、BEVERAGE / DRINK / ALCOHOL 类型，以及 FOOD_TAG / BEVERAGE_TAG / BREVAGE_TAG / DRINK_TAG、add_hunger / add_thirst 等标签。可饮液体也识别糖、蛋白质、脂肪、酒精、淀粉成分。非水饮品都有少量饱食度；不逐个硬编码 Mod 物品 ID。液体饮品的食物收益按每 750 ml 的比例缩放，补水按实际饮用量；原版非液体饮品每件消耗一份。

| 原版示例 | 基础单价 | 饱食度 | 饮水值 |
|---|---:|---:|---:|
| 果汁 | 14 | 87 | 306 ml |
| 代乳 | 16 | 108 | 324 ml |
| 星湖 / Galaxy Blend | 25 | 120 | 350 ml |
| 泥潭合成肉 | 25 | 765 | 0 |

已有原生酒精效果继续执行。只识别为容器或没有食用标签的未知物品不会自动消耗；特殊 Mod 若使用完全不同的食用接口，仍需单独适配。

## 腹泻

0.3.17 修复正常基础水的背景化学污染物、重金属总量误判：98% 及以上的原版基础水不再仅因这两种成分超过 0.1 ml 就产生风险；明确加料、独立有害成分或实际纯度低于 98% 的水仍按风险处理。泡面烹饪使用相同判定，不新增水质使用提示。

幽灵水按每 250 ml 实际饮用量默认 80% 的风险累计；加料食物按每份默认 80% 累计。两项概率均可在设置中分别调整（0–100%）。旧版未改动的 25% / 35% 默认值组合会一次性更新为 80% / 80%，已有其他自定义概率保留。当天记录暴露，**次日早晨判定**，同日重复触发早晨不会重复判病。多次暴露以 `1−∏(1−p)` 合并，随机进度随存档保存。普通水不重复计算加料食物风险。

腹泻期间继续喝幽灵水或受污染饮品，会立即加重为严重腹泻；正常饮水不会加重，吃受污染的固体食物仍只记录次日患病风险。普通腹泻默认每天额外消耗 100 千卡、300 ml，严重腹泻为 150 千卡、600 ml。严重时采用两种惩罚中较大的数值，避免自定义参数使加重反而减轻惩罚。吃喝恢复量不打折，已移除吸收率设置及物品子菜单中的吸收减益。额外消耗在过夜时与基础消耗一起结算，每晚一次；状态面板显示总每日消耗，并以红字列出病情与附加消耗，**不显示剩余天数**。

每次发病默认随机持续 1–3 天，范围可在 1–14 天内调整；也可取消随机，使用固定病程。加重时至少保留原剩余病程，并按同一范围抽取恢复时间；已经严重时重复饮用不重新抽取。病情、病程与随机进度随存档保存，康复时清除严重状态。旧默认的饮水附加消耗 150 ml 一次性提高为 300 ml，其他自定义数值保留。两种风险、普通 / 严重消耗及病程均可调整。

通过原版向食物注入液体的操作、加料/有毒物品特征或污染成分判断加料风险；本 Mod 会给注入食物留下可随物品保存的标记。其他 Mod 可以添加 `station_needs.adulterated`、ADULTERATED、SPIKED 或 CONTAMINATED_FOOD 标签接入。

## 深空外卖

电话簿“深空外卖”，号码 **7788**。接通后由营业员欢迎并说明配送方式。单品页提供营养果、罐头、750 ml 普通水；套餐页提供 5 个营养果、3 罐合成肉、3 瓶普通水。两页均可切换配送方式或结束通话。结束通话不下单、不扣款。价格随当前市场变动，饥荒倍率已经包含在市场价内，不再叠乘。

普通订单预付下单，第二天**打开橱窗时**送到报纸出现的外侧柜台，不放进背包。柜台满时保留未送部分，腾出空间后 F7 重试，或者退款。关闭电话配送入口不影响已有订单领取/退款。订单按下单时价格预付，改价不补差额。

加急菜单的单品在市场价上加 100%，套餐加 80%，均包含配送；普通单品加 20%、套餐加 10%，四档独立。营业时急送立即放到外侧柜台；关店时保留到本日开橱窗，柜台满时继续保留。普通和加急订单共用每天订单上限，套餐算一单；取消只退未送部分。

0.3.7 修复点击“加急配送”后跳过新菜单的问题：切换时清除原对话的待执行回调，重新开始普通 / 加急菜单，避免原版“继续对话”直接越过菜单根节点。此修复已按原版对话方法核对，尚未进行游戏内点击验证。

## 生存、饥荒与吃腻

默认饱食上限 4000 千卡、水分上限 2000 ml；新开局默认直接补满当前设置的两个上限（默认 4000 / 2000），不影响旧存档；关闭满值开局后使用初始值（默认 3000 / 1500）；过夜消耗 800 / 600；额外百分比消耗和每顾客消耗默认 0。食水不足时过夜可以扣成负数。睡前任一值已为零或负数时弹出警告，取消可继续补给；选择强行睡觉会直接进入饿死或渴死结局，两项均耗尽时优先渴死。设置可关闭该死亡机制。每晚只结算一次。所有参数全存档共用，生存状态、疾病、连续饮食天数、随机数与订单分别随存档保存。

**“饥荒”负面开局特性默认开放选择**，使用带留白的小鸡骨头图标，原版特性界面自动显示为红色。点数默认 **−2**，即选择后获得 2 点特性点数；设置中可在 **−10 至 −1** 调整。开放开关控制该特性的注册与效果，全局饥荒独立保留。点数变更影响之后的新选择，已有存档不重新分配特性点数。

**饥荒挑战默认不生效**：特性开放选择但不会自动勾选，“饥荒生效方式”默认只在选择特性时启用；也可全局开启。若不想使用饥荒，保持“仅选择开局特性时”且不开局选取即可；也可关闭特性入口。旧版“全局启用”设置会保留；旧版“关闭 / 仅 −3 特质”在升级后转为新的特性模式，不强制给未选特性的存档涨价。已有订单按原物品 ID 和支付金额保留，旧鲜肉订单仍可交付或退款。

默认食物饮料 ×3、种子 ×3、水 ×1.25；兑换商店按食物和水的对应倍率涨价，付款、显示和购买条件使用同一价格，避免读档或刷新反复叠乘。食品券面额、兑换所得余额和券本身的交易价值沿用原版，福利券也不再缩减面额；旧的食品券倍率与福利额度设置不再使用。旧版已经发出的券无法区分原生小额券和被缩减的券，因此不自动重写已有券。电话配送继续使用对应食物与水倍率。

吃腻默认关闭。开启后，连续至少 3 天只吃基础单价 ≤25 的廉价食物，第 3 天起每次默认有 35% 概率只获得 50% 饱食收益。较贵食物或整天未进食会打断连续记录。同一天多次进食只算一天；纯饮水不算食物，非水饮品因含热量会计入。概率、价格门槛、天数与收益可调。

## 安装、更新与存档

Steam 版请直接订阅创意工坊条目并等待下载，在 Mods 中启用。已订阅时不要再安装本地副本；游戏会优先本地目录，可能覆盖工坊更新或造成来源变更。本次已将重复本地副本移到项目 backups。

退出游戏后，将成品 `station_needs` 文件夹放入游戏 `Mods`，在 Mods 列表启用并重启。项目 `install.ps1` 可安装到本机默认 Steam 路径，会先备份本 Mod 旧目录到项目 backups。更新保持内部 ID，不与旧版本并存。发行 ZIP 仅包含原创 DLL、配置清单、6 段最终许可音效、2 个原创像素图标、11 份本地化、封面及说明，不包含原版 DLL 或反编译源码。

首次测试请使用独立测试局。请勿与参考 Mod“食物与生存”或其他接管相同吃喝/过夜入口的生存 Mod 同时启用。多人共享状态尚未实现。

与原版一致，尚未保存的当天行为在读档后回滚；本 Mod 不在每次吃喝后强制保存。停用前先领取/退款未送订单，正常过夜保存，再在 Mods 里停用并重启。保留独立 Mod 状态，不改写参考 Mod 数据。创意工坊：https://steamcommunity.com/sharedfiles/filedetails/?id=3833315687。
