# 余烬协议 2.1.9：枪声与魔窟奖励调整

本版面向创意工坊发布。实机测试由玩家进行。

## 本次调整

- 各类枪械均使用单一开火音源。快速点射会接续同一通道，避免手枪、左轮、霰弹枪的长尾音反复叠加。冲锋枪保留随实际开火接续的单通道处理，停止射击、换弹或离开战斗时停止连射音源。换弹仍使用独立的原版枪械音频。
- 深入魔窟首关伪人基础生命值为100，每提高一关增加50：100、150、200……。不恢复爆头弱点。
- 通关首关奖励9～11件，每提高一关增加2件：第二关11～13件、第五关17～19件。奖励从模组、电子零件、金属锭、打印耗材、电线、节点和工具等池中随机抽取，单件仍有5%概率抽取特殊模组。
- 奖励先放入携带的背包，放不下时自动送回店铺的玩家侧桌面物品栏。桌面也放不下的部分记入待送清单，腾出空间后自动补送，随存档保存。不会放到顾客交易栏或橱窗。
- 大批奖励分批送达，每批最多16件；等待补送不会阻止退出狩猎。放弃普通待领物资不会删除魔窟待送奖励。

## 保留的玩法

魔窟通关进度保留、每晚最多通关一关、每关三波、三点生命、波次间绷带恢复均保持。弹药补给各口径6份/300资金，不售卖弹匣；半匣补给、R换弹、打空自动换弹、随枪保存余弹保持不变。独立测试工具版本仍为0.1.1，在店铺按F8打开。

## 安装与测试

退出游戏后，将压缩包中Mods里的EchoProtocol文件夹复制到游戏Mods目录，再启动确认版本2.1.9。

建议检查：
1. 冲锋枪长按、松开、换弹；手枪和左轮快速点射；霰弹枪开火。确认没有不断累积的多层枪声，且换弹声正常。
2. 首关敌人100血，下一关150血；首关通关9～11件奖励。
3. 背包满时奖励送回店铺桌面，桌面也满时保留待送数；回店腾空间后应补送。
4. 仍有待送奖励时保存、回主菜单并重新加载，确认继续补送且不重复发放。
