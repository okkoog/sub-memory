[b]원본 모더가 해당 오류를 수정하기 전까지 사용하는 비공식 임시 호환 패치입니다.[/b]
Faction Reputation Expansion 원본 모드가 반드시 필요합니다. 원본 모더가 수정한 버전이 나오면 수정 내역을 확인한 뒤 이 임시 패치를 비활성화하거나 제거해 주세요.

[h2]어떤 문제를 고치나요?[/h2]
Faction Reputation Expansion의 도둑 상인 재고·상자 배치 순서를 처리하는 코드(ThiefCrateFirstPatch.ReorderStock)가 현재 게임에 포함된 Harmony에 없는 문자열 판별 함수 LoadsConstant(CodeInstruction, string)를 호출하는 호환 문제를 보정합니다.
이 코드가 실행되면 MissingMethodException이 발생하여 해당 재고 처리 과정이 중단될 수 있습니다.

[h2]어떻게 고치나요?[/h2]
게임 실행 중 FRE가 보관하는 문자열 판별 함수를 동일한 의미의 비교 함수로 교체합니다. 명령이 ldstr인지와 문자열이 BM_RELIABLE인지 직접 확인하므로, 누락된 Harmony 함수를 호출할 필요가 없습니다.
원본 모드 DLL이나 게임·Harmony DLL을 덮어쓰지 않는 별도 모드입니다. 재고 순서 처리의 나머지 로직, 평판 수치, 아이템 데이터 및 저장 파일은 이 패치에서 수정하지 않습니다.

[h2]사용 방법[/h2]
1. Faction Reputation Expansion 원본과 이 패치를 함께 구독하고 활성화합니다.
2. 게임을 완전히 종료한 뒤 다시 실행합니다.
3. 기존 FactionReputationExpansion_1.5.3_HarmonyFix 전체 수정본을 사용 중이라면 게임 종료 후 Mods 밖으로 옮기고 원본 모드로 돌아와 주세요.
4. 같은 FactionHarmonyCompat의 수동 설치본과 창작마당 버전을 중복 설치하지 마세요.
한국어팩은 이 오류 수정의 필수 조건이 아닙니다.

[h2]확인 범위[/h2]
원본 FRE 1.5.6 환경에서 실제 사용 후 로그를 확인했습니다. 원본과 패치의 정상 실행이 기록되어 있으며, 확인한 최근 로그에서 LoadsConstant 오류 및 이 패치의 적용 실패 기록은 발견되지 않았습니다.
실제 DLL을 불러온 함수 교체·판별·복구 검사와 현재 게임의 모드 검사도 통과했습니다. 모든 플레이 상황이나 다른 모드의 오류 해결을 보장하는 패치는 아닙니다.
