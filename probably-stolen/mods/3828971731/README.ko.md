# 세력 평판 확장 한국어 지원

2026-11-05 / 원본 Faction Reputation Expansion 1.4.1 / 창작마당 3828971731
한국어 팩 0.7.5.16-dev

이 폴더의 원본 모드 DLL·그림·원문 설명서는 창작마당 원본 그대로입니다. 원본 파일을 고치지 않고 별도 ProbablyStolen_KoreanPack으로 번역합니다.

## 설치

1. 창작마당에서 원본 세력 평판 확장 모드를 활성화합니다.
2. `KoreanSupport/ProbablyStolen_KoreanPack_0.7.5.16.zip`을 게임의 `Mods/ProbablyStolen_KoreanPack` 폴더 안에 풀어 기존 한국어 팩을 갱신합니다. 압축 안의 manifest.xml·DLL·Localization 폴더가 해당 폴더 바로 아래에 있어야 합니다. 한국어 팩 중복 설치는 피하세요.
3. 게임 언어를 한국어로 설정하고 한국어 팩을 활성화한 뒤 게임을 완전히 재시작합니다.

다른 모드를 번역한 기존 CSV와 카드·회사·시작 특성 보완을 포함한 전체 한국어 팩입니다. 원본 모드를 이 폴더에서 수동 설치한다면 원본 파일만 게임 Mods의 별도 폴더로 복사하고, KoreanSupport는 원본 모드 폴더 안에 설치하지 않아도 됩니다.

## 번역 범위

세력별 평판 단계·혜택·실패 상태·의뢰 조건·보상·연락처 대화·신생 동맹·카르텔·신생 핵심 조정 및 최신 추가 효과·설정 안내를 포함합니다. 내장 번역표와 코드의 영어·중국어 별도 문구를 함께 추출했습니다. 코드에서 직접 정의한 최신 단계와 효과도 추가했습니다.

원문 매핑 2,079개(중국어·영어·서식 별칭 포함)를 한국어 팩 자체 CSV에 추가했습니다. 내부 삽입 표식 `{类别}`, `{短缺}` 등은 원본의 문장 조합을 위해 유지합니다. 숫자·가격·쿨다운·게임 진행·세이브 ID는 번역으로 변경하지 않습니다.

## 적용 방식과 검증

한국어 팩에서 이 모드의 지역화 함수와 표시용 문자열 반환, 화면 출력 48개 메서드를 연결했습니다. 원본 DLL을 교체하거나 저장 데이터를 고치지 않습니다. 한국어가 표시되는 자체 텍스트에는 게임의 한국어 글꼴을 사용하고 숫자 전용 텍스트의 글꼴은 유지합니다.

- 고정 원문·실제 숫자를 넣은 조합 등 번역 검사 4,152건 일치, 빈 출력·동적 값 유실 없음.
- 화면 호출 48개 메서드의 인자·반환형 검사 통과.
- 모드 로더 검사: 기존 reflection-external 권한만 필요, 차단 항목·오류 없음.
- 카드 1,673건, 회사 현재 버전 1,029건, 시작 특성·범위 16건 회귀 검사 통과.
- 원본 모드 7개 파일의 SHA-256 동일.

이 수치는 추출한 문장과 적용 코드 검사 결과입니다. 실제 게임에서 모든 세력·이야기·효과·실패 분기를 플레이한 완역 판정은 아닙니다. 세부 검증 데이터와 한국어 팩 소스를 KoreanSupport에 함께 보관합니다.

## 한국어 팩 소스 빌드

`KoreanSupport/KoreanPack.csproj`에 .NET Framework 4.8 타깃 팩이 필요합니다. `dotnet build KoreanPack.csproj -c Release -p:GameManagedDir="<게임 경로>/Probably Stolen_Data/Managed"`로 게임 제공 참조 DLL을 지정하세요. 게임·제3자 참조 DLL은 한국어 지원 폴더에 포함하지 않습니다.
