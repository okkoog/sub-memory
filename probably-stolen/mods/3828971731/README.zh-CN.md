# 势力声望扩展 v1.5.3

## 更新说明

mod 将优化存档存储方式。本版本为存档迁移版本，请尽可能加载一次你所有正在游玩的旧存档，以避免正式版本时本 mod 相关存档数据丢失。
修复新生同盟预约电话卡顿、不显示冷却的 bug。

## 安装

在主菜单“模组”中启用并重启游戏。常规版使用官方存档数据接口，不申请额外权限。

本地安装：关闭游戏，将整个 `FactionReputationExpansion` 文件夹放入游戏根目录的 `Mods` 文件夹；清单应位于 `Mods/FactionReputationExpansion/manifest.xml`，DLL 与清单同级。正式版不需要 MelonLoader。不要同时加载旧版 DLL 或多个同 ID 副本；本地同 ID 副本会优先于工坊版本加载。

## 更新与转移

更新前备份原版存档及存档目录下的旧 `FactionReputationExpansion` 文件夹。退出游戏后替换发布文件，保留存档。自行添加的语言文件也请备份并保留，翻译方法见 `LOCALIZATION.md`。

旧档首次更新需使用“旧档迁移版”，允许其文件权限，在保有正确进度的电脑上逐个读取需要保留的存档并正常保存。退出游戏后，换回常规无权限版。迁移版与常规版使用同一模组ID，只能保留一个。未转换的旧档会提示先迁移，不会静默建立空白进度。新开存档可直接使用常规版。

转换完成后，扩展声望、委托、永久核心效果和自定义物品随官方 ModData 写在当前原版存档内，常规版不再读写旧侧文件夹。换机时等待 Steam 云同步完成，或手动复制对应原版存档；载入历史存档会恢复该时间点的扩展进度，不会被本机较新的侧文件覆盖。仅复制 MOD 文件无法迁移进度。转换并验证前请保留旧侧文件备份。

默认存档目录：`%USERPROFILE%/AppData/LocalLow/Questing Goose Studio/Probably Stolen`。

## 卸载

启用 MOD 时正常保存并退出，再停用 MOD 并重启游戏。本地安装可删除 `Mods/FactionReputationExpansion`，工坊安装可取消订阅。

正常保存后，原版声望保持原生范围。卸载并完整重启时，新增声望阶段、联络人、服务及自定义物品不会显示或占格；已获得的原生物品与金钱保留，核心加成停止生效。原版会忽略存档内的隐藏 MOD 数据，这些记录仍可能随云存档保留。

重装后可恢复隐藏的声望、已获得的永久效果和自定义物品。若卸载期间曾用原版重新保存，未完成委托、预约、未结款项及待选效果作废；已拥有的自定义物品会放回仓库，仓库满则保留隐藏记录并在下次读档时重试。损坏或高于当前版本的数据会进入保护模式，不会被空白记录覆盖。
