**作者**：TAS-4715-2　|　**版本**：2.1.8　|　**适用游戏**：Probably Stolen（**正式版 / Mono**）

> ### ⚠️ 2.0.x 是架构迁移版本线，安装方式变了
>
> 正式版已改用 **Mono + 游戏内置的官方 Mod 加载器**（不再需要 MelonLoader），
> 因此本 MOD 从「单个 DLL」变成「**一个文件夹**」，安装位置也变了 ——
> 请把 `Va11HallA` 整个文件夹放进 `<游戏目录>\Mods\`，而不是把 DLL 丢进 Mods 根目录。
> 详见 [二、安装](#二安装)。

> **本版本只适用于正式版（Mono）。** 旧的 Demo（Il2Cpp / MelonLoader）**不适用** ——
> 官方 Mod 加载器只在正式版里提供。
>
> **进度不迁移**：1.1.x 的进度存在 `Mods/Va11Halla_Persist_Data.json`，
> 2.0.x 改用官方「按存档保存」的数据（随游戏存档槽走），**不会读取旧文件**
> → 升级后剧情 / 教学进度从零开始，**但你的游戏存档本身完全不受影响**。

> ✅ **不写游戏存档里的物品数据，完全支持旧存档中途加入。**
> 本 MOD 的进度数据存在**官方 ModData**（属于当前存档槽的一部分，随游戏正常保存/读取），
> 且用「**装上 MOD 的那一天 = MOD 第 1 天**」的 MOD 纪元判定剧情 —— 所以**新旧存档都可直接装上开玩**，
> 剧情从装 MOD 后的第 1 天完整开始（Jill 会主动登门），**不需要开新档**。

## 零、语言支持 / Language

本 MOD **自带完整的中英文案**——界面、24 款饮品、23 位顾客、Jill 与 Dana 的剧情、26 页配方书全部有中英两套，
**不需要额外安装语言补丁**。

语言跟随游戏本体的设置：

1. 把游戏语言切到 **English** → MOD 内所有文案变为英文；
2. 切回中文 → 恢复中文（中文表现与 2.0.3 完全一致）；
3. **生效时机**：切换后需要**重新进店**（或重启游戏）才应用 —— 这是游戏本体的机制，不是 MOD 的限制。

> 英文模式下若看到形如 `client_dorothy_order`、`story_jill_v1_s1_o1_lines` 的**带下划线键名**，
> 说明该条漏翻。MOD **故意不回退中文**——英文环境使用无中文字形的西文字体，回退中文只会显示空白。
> 请把键名截图反馈，方便精确定位。

**English** — This mod ships complete Chinese and English text: the UI, all 24 drinks, 23 clients,
Jill and Dana's story, and the 26-page recipe book. No separate language patch is needed.

The language follows your game setting. Switch the game to **English** for English text; switch back
for Chinese (Chinese behaves exactly as in 2.0.3). The change takes effect when you **enter the shop
again** (or after a restart) — that is base-game behaviour, not a mod limitation.

> In English mode, a string like `client_dorothy_order` or `story_jill_v1_s1_o1_lines` means that
> entry is missing its translation. The mod deliberately does **not** fall back to Chinese: the English
> locale uses a Western font with no CJK glyphs, so Chinese text would render as blanks.
> Please report the key name so it can be fixed precisely.

## 二、安装

1. 确认你玩的是 **正式版**（游戏目录里有 `Probably Stolen_Data\Managed\Assembly-CSharp.dll`；
   正式版自带官方 Mod 加载器，**不需要** MelonLoader）。
   若目录里有 `GameAssembly.dll` / `MelonLoader` 文件夹，说明是旧的 Demo 版 ——
   **本 MOD 不适用**（官方 Mod 加载器只在正式版里提供）。
2. 把压缩包里的 **`Va11HallA` 整个文件夹**复制到 `<游戏目录>\Mods\` 下，最终结构为：

   ```
   Mods/
   └── Va11HallA/
       ├── manifest.xml
       ├── Va11HallA.dll
       ├── preview.png        ← 「模组」菜单里选中本模组时显示的预览图
       ├── Localization/      ← zh.csv / en.csv（中英文案；缺了它英文会显示键名）
       └── Sounds/            ← 5 个调酒台音效
   ```

   > ⚠️ 不要只把 DLL 丢进 `Mods\` 根目录 —— 官方加载器只认**带 `manifest.xml` 的子文件夹**；
   > 也不要把 `Sounds` 挪到别处（加载器**不递归扫描**子目录）。

3. 启动游戏 → 主菜单进「**模组**」菜单 → 找到 **VA-11 Hall-A同人MOD/VA-11 Hall-A Fan MOD** → 点「**启用**」。
   本 MOD 不声明任何额外能力，启用时不会弹安全确认框。
4. 启用后游戏会提示需要重启生效，重启即可。

> **本地开发提示**：启用过一次之后，该模组的详情面板会出现「**开发者模式**」按钮。
> 打开它以后，每次重新编译都会直接加载、不必重新审核。

> **日志与控制台**：按 **F8** 打开游戏内置控制台即可看到本 MOD 的加载与运行日志
> （`[Va11HallA] ...`）。
> 常规流程日志（到场 / 上酒 / 教学推进）**默认静默**，需要排查时在
> 「模组」菜单里给本模组点齿轮 → 打开「**输出调试日志**」。
> 警告与错误**始终输出**，不受该开关影响。

> **其他设置**（模组菜单 → 本模组 → 齿轮）：
> 「输出调试日志」、「立绘整体缩放」（改后需重启）。
>
> **开发者 / 测试用**：本 MOD 的调试面板**没有快捷键**，入口在游戏自带的开发菜单里 ——
> 前提是游戏根目录放着 `dev.txt`（这也是 F8 控制台的前提），然后按 **F9 → Command →
> 「Va11HallA 调试面板」** 打开/收起。普通玩家没有 `dev.txt` 就看不到这个菜单，也不会被误触。

## 三、快速开始

1. **第 1 天开店后**，Jill 会主动登门；通过对话决定是否加入 B.T.C
2. 选择「加入」后，会先问你是否要**进行 MOD 玩法教学**：
   - 「**进行教学**」→ 现场调两杯酒测试，两杯都通过才发认证
   - 「**跳过**」→ 不调酒，**直接发调酒台与认证**（适合玩过原作或本 MOD 的老玩家）
3. 「**B.T.C 调酒师认证**」发到手后，把它放进**展示柜**，顾客就会开始上门
4. **双击调酒台**打开调酒界面：材料 → 调制 → 上酒 → 在确认窗口点「确认交付」

## 四、调酒流程

### 4.1 打开调酒台

1. 第 1 天 Jill 登门时选择「**加入**」→ 柜台会出现 **B.T.C 调酒台**（3×2 格）
   （教学全部通过、或选择「跳过」后，还会额外获得 **B.T.C 认证**）
2. **双击调酒台**即可打开调酒界面
3. 关闭方式：界面右上角 **X**、按 **Esc**、或**点击界面之外**

界面布局：

| 区域 | 内容 |
|---|---|
| 中上方 | 五种材料的计量格（每种显示当前份数）与总量指示 |
| 上排 | 操作按钮：加冰、陈化、配方书 |
| 中间 | **调制**按钮（点击开始/停止摇和） |
| 中下 | 成品预览（贴图 + 饮品名） |
| 底部 | 五种材料的 **+** 按钮 |

### 4.2 加材料与上限

| 材料 | 说明 |
|---|---|
| **Adelhyde** | 阿德海德 |
| **Bronson Extract** | 布朗森萃取液 |
| **Powdered Delta** | 德尔塔粉末 |
| **Flanergide** | 弗兰吉派 |
| **Karmotrine** | 卡莫定（多数配方为「任选」） |

**上限规则**：单种材料最多 **20** 份；全部材料合计最多 **20** 份。超过上限的点击会被拒绝。

### 4.3 加冰 / 陈化

- **加冰**：部分配方要求（如 Cobalt Velvet 需要，Beer 不需要）
- **陈化**：部分配方要求（如 Brandtini 需要，Beer 不需要）
- 两者都是**开/关**切换，界面上的指示图标会同步显示
- 是否需要用错会影响匹配，请对照第五节配方表

### 4.4 调制（摇和）

1. 点「**调制**」开始摇和，调酒壶会左右摇晃
2. **连续摇满 5 秒**后达到「**调和（Blended）**」状态，摇晃频率会明显加快（视觉提示）
3. 点「**停止**」结束摇和，系统开始匹配配方

> 匹配是**精确匹配**：材料份数、加冰、陈化、是否调和都必须与配方完全一致。

### 4.5 杯型规则

| 杯型 | 做法 | 售价 |
|---|---|---|
| **标准杯** | 按配方 1:1 的量 | 原价 |
| **大杯** | 把配方里**每种材料的量都翻倍**（含固定的 Karmotrine） | **原价 ×2** |

**重要**：只有 **20 款**饮品能做大杯。以下 **4 款做不出大杯**（翻倍会超过 20 的材料上限），**只能做标准杯**：
**Marsblast、Piano Man、Piano Woman、Zen Star**

### 4.6 上酒与交付

1. 匹配成功后点「**上酒**」，成品会放到你的柜台上
2. 如果此刻**有顾客在等**（普通顾客或剧情点单顾客），会弹出确认窗口：
   **把 X（标准杯/大杯）交给顾客？**
3. 点「**确认交付**」→ 系统检查台面上的饮品**品类与杯型是否都对**
   - 都对：**收款**，饮品被收走，顾客给出好评
   - 不对：**不收款**，提示看看调酒指南
4. 点「**上错了，重做**」→ **清空柜台上所有 mod 饮品**，顾客**保留原来的需求**，你可以重新调酒再交付

> **「上错了，重做」是本 MOD 唯一的清台入口。** 交付确认窗口**不能按 Esc 关闭**，
> 就是为了强制你从「确认交付 / 上错了，重做」二选一 —— 两者都会把台面处理干净，
> 不会因为「先放一边」而让残留的错杯卡住后续判定。
> 注意它会清掉柜台上**全部**的 mod 饮品（不只刚才那杯），一次调多杯时请留意。

> 顾客的需求有 **50% 概率要求大杯**（只对能做大杯的饮品抽取）。
> **大杯需求必须用大杯交付**，标准杯不算命中。

### 4.7 配方书（B.T.C 调酒指南）

- 打开：调酒界面**上排的按钮**（配方书）
- 共 **26 页**：第 1 页是前言、第 2 页是名词说明，之后是 24 张配方卡
- 底部「**上一页 / 下一页**」翻页
- **配方书开着时，你仍然可以继续操作调酒台**（点调酒台不会关掉配方书）
- 点配方书之外的地方才会关闭它

## 六、剧情分支

> ✅ **1.1.0 的剧情流程已完整实测通过**（剧情来访、点单教学、第 7 天再访、剧情终止、
> Dana 两次来访、交付确认窗口的清台全路径均逐条验证）。
> 若你仍遇到异常（对话不出现、立绘不替换、界面卡住、顾客不动等），
> 请先把「输出调试日志」打开（见「二、安装」）复现一次，再按 **F8** 打开游戏内置控制台，
> 把 `[Va11HallA]` 开头的日志一并保存下来。

### 6.1 事件流程总览

```
【第 1 天】Jill 来访（首次）
      ├─ 玩家可先提问（3 个可选问题），问完后继续
      └─ 做出决定：
           加入 → 弹出确认窗「是否要进行mod玩法教学？」
                    ├─ 进行教学 → 逐轮调酒（2 轮），全过才发认证
                    └─ 跳过     → 直接播收尾，同时发调酒台 + 认证
                  两种情况都记录加入日 J
           拒绝 → 无变化，七天后 Jill 再来一次

【第 7 天】Jill 再次来访（同一次来访的第二次到场，仅「尚未加入」时会触发）
      ├─ 开场白换成「我回来了 / 我再问一次」，之后同样是提问 → 决定
      └─ 做出决定：
           加入 → 同第 1 天（同样先问「是否进行教学」，再走对应分支）
           拒绝 → 剧情终止（本存档不再推进）

【加入后 J+3】Dana 来访
      └─ 辣翅二选一（吃 / 不吃），之后进入同一段收尾

【加入后 J+7】Jill 以顾客身份来访（点单）

【加入后 J+8】Dana 以顾客身份来访（点单）
```

> 第 1 天与第 7 天是**同一次来访**（到期日写成 `第1天, 第7天`），只有开场的**第一段台词**不同
> （写成 `第1天台词: / 第7天台词:`，与到期日字面一致），后续提问与选项**完全共用**。
> 判定上：「拒绝」= 消耗一个到期日、几天后再来；在最后一个到期日仍拒绝 = 剧情终止。

### 6.2 点单教学（Jill 的「加入」流程）

答应加入后不会立刻拿到认证 —— 会先弹出确认窗，问你要不要走一遍调酒测试。

**第一步是确认窗**：弹出「**是否要进行mod玩法教学？**」——

> 如果你已玩过 va11 原作或者已经在其他存档玩过本 mod 可考虑选择跳过。

| 选择 | 结果 |
|---|---|
| **进行教学** | 进入下面的两轮调酒测试 |
| **跳过** | 不调酒，**直接播收尾**，并**同时把调酒台和认证发到柜台** |

选了「进行教学」后：

| 轮次 | 要求 | 教学点 |
|---|---|---|
| 第 1 轮 | `sugar_rush`（大杯） | 打开调酒台、看配方与说明页 |
| 第 2 轮 | `moonblast`（标准杯即可） | 需要**调和**的饮品（摇酒壶剧烈晃动后停止） |

- 每轮先播 Jill 的**开场**与**需求** → 你调好酒放上台面 → 点「确认交付」
- 对了 → 进下一轮；**错了可以无限重试**（Jill 会提示「再看一眼配方和说明」）
- **每轮开考前台面会自动清空**：上一轮或重做留下的饮品不会干扰本轮的判定
- 两轮全过 → Jill 播「收尾」并把**认证**发到柜台上 → 本次来访完成、记录加入日 J
- **教学轮次不计钱、不结账**（纯演示）
- **中途直接用原版送客** → 不发认证、来访不完成 → 下次开店 Jill 会再来、从头教

> 教学只放行「调酒台」；**认证是在教学全部通过后才发放的**。
> 选「跳过」时会**同时补发调酒台与认证**，效果与「全过」完全一致。

### 6.3 天数规则

| 来访 | 触发条件 |
|---|---|
| Jill 第 1 次 | **第 1 天 / 第 7 天**（绝对天数，两个到期日，**仅未加入时**） |
| Dana 第 1 次 | **加入日 J 之后第 3 天**（J+3） |
| Jill 第 2 次 | **加入日 J 之后第 7 天**（J+7，点单型） |
| Dana 第 2 次 | **加入日 J 之后第 8 天**（J+8，点单型） |

**核心规则**：「第 N 天」只在**尚未加入**时检查；「J+N」只在**已加入**后检查。
所以**一旦加入，第 7 天那次追问会自动跳过**，剧情改按 J 往后推进。
`J` = 你选择加入的那一天（第 1 天加入则 J = 1）。

### 6.4 剧情终止

**终止条件**：在 Jill 那次来访的**最后一个到期日仍然拒绝** —— 也就是
（1）第 1 天拒绝（Jill 说会过几天再来）；（2）**七天后（第 7 天）再拒绝一次**。
（等价说法：连续两次拒绝。）

**终止后**：Jill 与 Dana **都不会再以剧情人物身份出现**；**不会有第三次询问**（不可逆）；
**普通顾客机制完全不受影响**，调酒台与已获得的道具继续可用。

> 补充：若你通过**控制台、存档修改**等方式**自行获得了「B.T.C 调酒师认证」**，
> 即使剧情已终止，**Jill 仍会作为普通顾客上门点单** —— 只是不再有新剧情。

### 6.5 其他规则

| 规则 | 说明 |
|---|---|
| 一天一位 | **一天只会出现一位剧情人物** |
| 优先于普通顾客 | 剧情日当天**不会再有普通顾客**上门 |
| 未选择 | 对话中**直接用原版送客** = 视为**当天拒绝**（自动采用当前选项块的最后一项结果） |
| 错过不补 | 当天没接待，来访**不算完成**，**下次开店会重新触发** |
| 点单型来访 | 与普通顾客流程一致：播报需求 → 上酒 → 确认交付 → 收款 → 送客 |

## 十、常见问题

**Q：加了材料但计量格没变？**　A：该材料已达单种上限（20）或总量上限（20）。

**Q：配方对但交付失败？**　A：检查**杯型**。需求是大杯时，标准杯不算命中；反之亦然。

**Q：总是匹配不到配方？**　A：匹配是精确的，请确认材料份数、加冰与陈化状态、是否需要调和全部一致。

**Q：顾客一直不来？**　A：确认展示柜里放了「**B.T.C 调酒师认证**」，且当前不在剧情日。

**Q：加入之后，为什么第 7 天 Jill 没来？**　A：第 7 天是那次来访的第二个到期日，只在「尚未加入」时才会用到；你已加入，这次来访已完成，接着走的是 J+7 那次（点单型）。

**Q：Dana 一直不来？**　A：Dana 的来访是 **J+3 / J+8**，需要先加入并经过对应天数。

**Q：我在对话里直接送客了？**　A：等同**当天拒绝**，自动采用该选项块最后一项的结果。（若正在**点单教学**中送客 → 不发认证、来访不完成，下次开店 Jill 会从头再教一遍。）

**Q：教学里调错了酒怎么办？**　A：无惩罚，Jill 会提示「再看一眼配方和说明」，重新调一杯再点「确认交付」即可，可**无限重试**。（点「上错了，重做」会先清空台面，不会让错误的酒残留。）

**Q：教学中要付钱吗？**　A：不用。教学轮次**不计费、不结账**，纯粹是 Jill 的测试。

**Q：交付确认窗口能按 Esc 关掉吗？**　A：不能。这是有意设计 —— 必须从「确认交付 / 上错了，重做」里选一个，确保台面一定被结算或清空。

**Q：剧情会不会影响普通顾客？**　A：剧情日当天不出普通顾客；剧情**终止后普通顾客照常**。

**Q：能装在已经玩了一半的旧存档上吗？**　A：可以，**直接装就能用**。本 MOD 只往当前存档槽写入官方 ModData，不改动原有字段；旧存档加载时会自动为它新建一段空数据，剧情按「**装 MOD 那天 = MOD 第 1 天**」从第 1 天完整开始（Jill 会主动登门），**不需要开新档**。

**Q：装/卸这个 MOD 会弄坏我的存档吗？**　A：不会。进度存在当前存档槽的**官方 ModData** 里，属于游戏自己管理的字段；卸载后本体原有数据原样保留，只是那一段 MOD 数据不再被读取（可忽略，无害）。

  任何失败都只记日志、**绝不把异常抛给游戏**。
- **内存即权威**：启动时一次性读入整个文件，运行时只改「当前档」那一段，落盘时**全部段整体写回** ——
  写文件不依赖读文件，绝不会「只读到当前档 → 覆盖掉别的存档」。
- **落盘时机**：Harmony 补丁挂在 `PlayerStore.SaveGame()` 之后，与本体存档**同一时刻**写入，
  不会出现「MOD 记了进度、游戏却没存」的错位。
- **旧档 / 换档兼容**：读档、开新档时用 `Bind(store, force:true)` 强制重新绑定；
  某个 runID 的段不存在 → 视为「新档」或「旧档首次装 MOD」→ 新建空段，**旧存档可直接装上，无需开新档**。
- 技术细节：`PerSaveState` 的对外 API 与键名前缀（`va11halla.`）**保持不变**，只替换了后端实现，
  上层（进度 / 剧情 / 点单）无需任何改动。
