The font is a modified version (instance and subset) of Noto Sans KR under the SIL Open Font License 1.1 (OFL.txt); it
keeps the name Noto Sans KR, which is not a Reserved Font Name. It is a TextMeshPro fallback via core 1.2.1 PackFonts:
the game's Korean fonts load only on its own Korean branch, so without it Hangul in the mod list (manifest Name and
Description) and the language menu label shows as missing glyphs while another UI language is active. With ko-KR
selected the game's Korean fonts still come first.
