# Probably Stolen — 번역키 대조 최우선 규칙

작성: 2026-11-11 (KST)
상태: 사용자 지시 / 이후 번역 모드 신규 키·업데이트 검사에 **최우선 적용**

## 대조 시작 순서 (필수)
1. **원본 모드의 자체 한국어 Localization부터 연다.** 먼저 `mods/<워크샵ID>/Localization/ko.csv`를 찾고, `ko-KR.csv` 등 한국어 로케일 변형과 `manifest.xml`의 Localization 설정도 검사한다. `pskb__<ID>.csv` 존재 여부만으로 번역 누락을 판단하지 말 것.
2. 자체 `ko.csv`가 있으면 원본 `en.csv` / `zh.csv`와 **키 집합을 비교**한다. 누락 키가 있으면 '원본 모드 자체 한국어 번역 부족'으로 분류하고, 충분하면 '자체 한국어 지원 — 통합팩 추가 번역 불필요'로 분류한다.
3. 자체 한국어 파일이 없거나 실제로 부족한 모드만, 한국어팩 `번역 모드/Localization/pskb__<ID>.csv`와 원본 로컬키를 비교한다. 원본에 신규/누락된 K 키, 한국어팩에만 남은 키, 단순 버전 변경을 구별한다.
4. 원본 모드의 GitHub 복제 폴더에 `ko.csv`가 보이지 않더라도 기존에 사용자가 자체 한국어 지원을 확인한 모드를 곧바로 '통합 한국어팩 미등록'으로 분류하지 말 것. **GitHub 복제본의 누락/동기화 문제**로 먼저 확인하고 '확인 필요'를 명시한다.
5. 사용자 승인 없이 다른 모드 DLL·CSV는 변경하지 않는다.

## 고정 예외: 스택 수납 (Item Storage)
- 워크샵 ID: `3829085054`, 내부 모드 ID: `Dream_Item_Storage`.
- **사용자 확인: 스택 수납은 원본 모드의 `ko.csv`를 통해 한국어를 지원한다.**
- 따라서 통합 한국어팩에 `pskb__3829085054.csv`가 없다는 이유로 '한국어 번역 파일 미등록' 또는 '번역 작업 필요'로 보고하지 않는다.
- 이후 모든 키 조사 시 `mods/3829085054/Localization/ko.csv` 확인을 최우선으로 시도한다.
- **2026-11-11 GitHub `main` 복제본의 `mods/3829085054/Localization/`에는 `en.csv`, `zh.csv`만 확인됨.** 이는 사용자의 자체 한국어 지원 확인과 파일 목록이 불일치하는 상태다. `ko.csv`가 현재 GitHub 복제본에 있다는 뜻으로 과장하지 말고, 원본/동기화 상태 확인 대상으로 표기한다.
